편집 설정

이 브라우저에 GitHub 토큰을 저장하면 글 페이지에 내 생각 쓰기 버튼이 생기고, 아래에서 새 메모를 쓸 수 있어요. 저장은 소스 저장소에 바로 커밋되고, 배포가 끝나면(1~2분) 사이트에 보여요.

토큰

GitHub → Settings → Developer settings → Fine-grained tokens. 저장소는 tech-blog 하나만, 권한은 Contents: Read and write. 토큰은 이 브라우저에만 저장돼요.

새 메모

저장소의 memos/ 에 올라가고, 다음 blog run 때 쓴 그대로 영어로 번역해 게시해요.

태그 후보 (3)

Qwen 이 글을 쓰며 사전에 없다고 제안한 태그예요. 여러 글에 걸칠 만한 것만 승인(사전에 추가 + 제안한 글에 붙임), 한 논문에서만 쓰는 좁은 용어는 거절. 승인한 태그는 다음 blog run 때 관련된 기존 글에도 자동으로 붙어요. 상위 태그나 이름을 바꿔 승인해도 되고, 이미 있는 태그를 고르면 그 태그로 합쳐요.

  • method/safety-filter · 글 1개: Pushing Dexterity and Safety for In-Hand Object Pose Reaching That Works Remarkably Well

  • method/world-action · 글 1개: Vision-Language-Action or World-Action? Just Action Models

  • task/food-slicing · 글 1개: SliceIt! - A Dual Simulator Framework for Learning Robot Food Slicing

올린 메모

저장소 memos/ 에 있는 메모. 아직 게시 전이면 지우면 게시되지 않아요. 이미 게시된 글은 글 페이지의 "글 삭제"로 지워요.
