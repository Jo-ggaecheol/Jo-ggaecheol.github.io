1. Overall Flow

LLM: tokenizer → embedding → [attention → MLP] × N → norm → lm_head → next token
VLM: image → ViT(14px) → 2×2 merge + adapter → [image/text vectors] → LLM → text

Sentences to remember

  1. Information transfer between tokens happens only in the token mixer (attention).
  2. The MLP is the storage, and attention is the transport path. If ingredients don't arrive, the MLP cannot produce an answer.
  3. Thanks to skip connections, all layers share the same space, allowing vectors to be retrieved and read from any intermediate point.
  4. The KV cache is not a frequency-based lookup table; it is a mechanism that avoids recalculating the K and V of past tokens.
  5. Image tokens are not words but out-of-vocabulary vectors. The LLM only receives vectors in the first place.
  6. "The ability to see" and "the ability to speak in coordinates" are different.
  7. The statement that borders can be discarded is an assumption about the data, not a property of the model.

2. Easily Confused Concepts

Common Misconception Accurate Understanding
The KV cache caches V for frequently occurring Q and K It is unrelated to frequency. It avoids recalculating the K and V of past tokens during a single sequence generation
Learned positional information can function like attention Positional vectors do not contain the content of other tokens, making this structurally impossible
The MLP-Mixer approach was tried in language and failed MLP-Mixer was introduced for images in 2021. It is accurate to say "it does not fit language well by structure"
Hardware compensated for the computational cost of attention It had good compatibility with GPUs due to parallel computation, and it also led in accuracy and training time in 2017
Similarity is compared using PCA PCA is a visualization tool. Similarity is measured by cosine, etc.
What is plotted in PCA are generated tokens They are the hidden states of input tokens after passing through each layer
Images are converted into language tokens They become vectors of the same size, but they do not turn into words from the vocabulary
Words like "stop" are attached to image patches This is merely a result measured by logit lens; the vectors inside the model are continuous values
The adapter converts vision information into language information It matches the size and formats it for the LLM to read. The change where it is read as words occurs while passing through the LLM layers

3.2 Tokenizer and Embeddings

  • Token count examples: 8 for simple English questions, 14 for difficult English questions, 34 for Korean questions
  • Korean is split at the byte level, so a single character spans multiple tokens, and decoding one by one shows �.
  • Neighboring word examples
    • Seoul → Tokyo, 서울 (Seoul), Beijing, Beirut, Bangkok
    • Galaxy → galaxy, axy, galaxies, Nexus, cosmos, Milky
  • Embeddings capture "which words are related," but since there is only one vector per word, they cannot capture "what is being asked in this question." The single Galaxy vector mixes the meanings of smartphone and galaxy.

3.4 Position Information Methods

Method Model Mechanism Characteristics
Absolute PE GPT-2 h0 = wte[token] + wpe[position] wpe is trained only for 1024 positions, so it cannot process longer inputs
RoPE Qwen2.5 Rotates Q and K by position in attention Acts on relative distance; disappears if attention is turned off
Recurrence Qwen3.5's linear attention Reads tokens sequentially while updating state Knows the order without inserting position separately

RoPE Intuition: If you rotate the vectors at positions 3 and 5 by 3θ and 5θ respectively, the dot product changes according to the angle difference 2θ. This allows the model to know the relative distance.

Recurrence: S_t = f(S_t-1, x_t). The reading order itself remains in the state.

3.5 Block Anatomy

Attention Calculation Order

Q, K, V projection → RoPE rotation → GQA expansion → q·k/√d → causal mask → softmax → V weighted average → o_proj
  • Q: What I am looking for
  • K: What I have
  • V: Content to pass if selected
  • Position info: Enters via rotation of Q and K
  • GQA: Several KV heads are shared by multiple query heads (In Qwen2.5-7B, 4 KV heads are shared by 28 query heads)

MLP (FFN, Feed-Forward Network)

  • The MLP inside a transformer is usually called FFN.
  • It calculates separately for each token with the same weights. It does not mix between tokens but mixes channels within a single token.
  • Qwen uses SwiGLU: silu(gate·x) ⊙ (up·x). It can create AND-type combinations that turn on strongly only when two features are present together.

3 Reasons Skip Connections Are Needed

  1. Because ∂h_l+1/∂h_l = I + ∂branch, gradients are transmitted to deep layers.
  2. The basic operation is identity, so each block only needs to learn the correction amount.
  3. All layers read and write in the same space as a shared bus, allowing the output to be decomposed into a sum of components.

Direct Logit Attribution (DLA): Divides the final logit difference into contributions from the embedding and each layer's a_l, m_l. Example: Embedding + Σa + Σm = 10.75, actual logit(Seoul) − logit(Tokyo) = 10.69

Knockout: Blocking a specific token from sending information

Blocking the transmission of "South Korea" also turns off Seoul neurons. For MLP to compose the answer, attention must bring the ingredients.

Attention sink

  • The last token attends heavily to the meaningless first token (e.g., average 0.84 based on max value among heads).
  • Since the Softmax sum must be 1, this is where leftover weights accumulate when there is nothing else to attend to.

3.6 Through the layers

Why look at layer level: Because we need to know at what depth information arises to decide where to fix it. Thanks to skip structures, intermediate vectors can also be read by the same classifier.

Logit lens: Passes intermediate layer vectors through final norm and lm_head to see which word they are read as. Since top1 in intermediate layers often contains strange tokens, it is more accurate to look at the rank curve of the correct token.

The layer where the correct answer becomes rank 1

  • Each block adds a little rather than overwriting the main line.
  • Even the same " Galaxy" diverges as it passes through layers depending on whether the preceding sentence refers to a smartphone or space.

3.7 Linear probe

"The Galaxy has X, but the iPhone does not." and "The iPhone has X, but the Galaxy does not." have the same token composition, differing only in order.

Task pooling layer 0 Best
A: Is Pixel mentioned? mean 1.00 1.00 @L0
A: Is Pixel mentioned? last 0.67 1.00 @L1
B: Does the side with the feature belong to Galaxy? mean 0.50 1.00 @L1
B: Does the side with the feature belong to Galaxy? last 0.50 1.00 @L4
  • Why layer 0 for Task B is exactly 0.50: Different correct answers are attached to the same input vector, so no classifier can do better than guessing. The representation has lost information.
  • The last token is just . at layer 0, but after passing through a few layers, it becomes a summary of the sentence.

3.8 Causal mask

A mechanism that covers the upper triangle (future tokens) of the attention score matrix with -inf, making the weights 0 after softmax. Each token sees only itself and the past.

        The  capital  of
The      O     X      X
capital  O     O      X
of       O     O      O
  • Why it is needed: During generation, future tokens do not exist yet. During training, the model must also be prevented from seeing the answer in advance.
  • What is gained: KV cache
  • What is lost: Cannot modify earlier tokens by looking at later content.

3.9 KV cache

Principle: With a causal mask, past tokens do not see future tokens. Therefore, the hidden states and K, V of past tokens do not change even when new tokens arrive.

Comparison of using and not using it. In the case of generating by inputting South, Korea following the prompt The capital of

Step Input (No cache) Input (With cache) No cache q·k With cache q·k
1 The capital of (3 tokens) The capital of (3 tokens) 6 6
2 The capital of South (4 tokens) South (1 token) 10 4
3 The capital of South Korea (5 tokens) Korea (1 token) 15 5
Total 12 tokens 5 tokens 31 15 
if use_cache:
    past, inp = out.past_key_values, nxt   # Next time, only 1 new token
else:
    inp = seq                              # Next time, the entire sequence

Summary

  • Q is not stored. This is because the outputs for past tokens have already been calculated.
  • It is stored for every layer and KV head.
  • Since it skips identical calculations rather than approximating, the output remains the same.
  • The first token (TTFT) does not get faster because the entire prompt must be processed.
  • This cache is used only within a single generation process by default. Reuse across requests is a separate feature called prompt caching.

Terminology

  • Context or sequence is more accurate than "token window." Context window refers to the maximum length a model can handle.
  • Two meanings of decoder
    • Structure: A model that only looks at the past using a causal mask. GPT and Qwen are decoder-only models.
    • Stage: Decoding, where tokens are generated one by one after the first token. This is distinct from prefill, which processes the prompt.
  • This does not apply to bidirectional encoders like BERT. This is because new tokens change the hidden states of past tokens as well.

3.10 Hybrid Structure (Qwen3.5's Gated DeltaNet)

  • Out of 24 layers, 18 are linear attention, and 6 layers (layers 3, 7, 11, ... 23) are full attention
  • State update: S_t = α_t S_t-1 + β_t (v_t − α_t S_t-1 k_t) k_tᵀ (α: forgetting, β: write strength)
  • A causal conv1d of length 4 immediately before mixes the adjacent tokens.
  • Benefit: Memory and step cost are independent of context length
  • Potential drawback: Since the past is compressed into a fixed size, the ability to accurately retrieve distant past information may weaken. Keeping full attention every 4th layer serves as a mitigation.
  • Knockout requires blocking both paths to be effective.
  • Cache memory is divided into "fixed state + KV proportional to length."

3.11 Why Was Attention Innovative?

Why it cannot be replaced by learned positional information: h_i = token_i embedding + position_i vector does not contain the content of other tokens, and MLPs only process their own token. This is a structural issue, not a matter of training volume. The Filler control group provides evidence.

MLP-Mixer learns position-based pathways for mixing tokens (learning with fixed weights "how much to move from position 3 to position 7"). While this works well for images with a fixed grid, it is structurally ill-suited for languages where the target of not varies from sentence to sentence.

Method Information Flow Limits
RNN Sequentially compresses into a fixed-size state Distant past becomes faded, and parallel processing is difficult
CNN Passes information between nearby neighbors Requires stacking many layers to see far away
Attention Directly references any token Computation and memory scale with sequence length

4 Advantages

  1. The pathway changes based on content (q·k is recalculated for each input). This is the biggest difference.
  2. Shares the same weights, so it can be used regardless of sequence length.
  3. Reaches distant tokens in one step.
  4. Centered on matrix multiplication, enabling parallel computation and pairing well with GPUs.

Note

  • The 2017 Transformer was not merely made usable due to hardware; it had higher accuracy than translation models of the time while also having shorter training times.
  • Computational costs remain today, manifesting as KV cache memory and prefill time. Discarding image tokens is an attempt to reduce this cost.
  • Attention is not the only answer. Skip connections and large-scale data also contributed, and alternatives like Gated DeltaNet are emerging.

4. RL Terminology

A policy is a function that selects the next action based on the information seen so far.

Term Input Transformer Equivalent
Markov policy Current state s_t Model using only embeddings
Memoryless policy Current observation o_t Model with only MLPs
History-conditioned policy o_1 ... o_t Model with attention
Residual policy learning Base policy + correction h + block(h)
  • POMDP: A type of problem, not a policy. It describes situations where only part of the true state is visible. It is like being unable to determine what is being asked based solely on the last token Galaxy.
  • Atari policy: Not a special type of policy, but a policy for playing Atari games. Since a single frame does not reveal the ball's velocity, recent frames are overlaid (frame stacking).
  • Difference between Markov and memoryless: They are the same if the full state is visible, but different if only part is visible. Embedding models are strictly closer to memoryless.
  • MLP + PE model: Equivalent to a policy that attaches only time t to the observation. Time information does not replace memory.
  • Projection layer: A layer that moves vectors to a space of different size. In RL, it is placed between the encoder and the policy, serving the same role as an adapter.
  • KV cache vs. LSTM hidden state: RNNs compress the past into a fixed size, while KV caches store it without compression, causing the size to keep growing.

5. Methods for Comparing Vectors

PCA is a visualization tool, not a similarity measure. Reducing 3584 dimensions to 2 discards a lot of information and is not the optimal comparison method.

Logit lens Which word it reads as Tracking semantic changes across layers
Dot product, Euclidean distance Direction and magnitude General vector comparison
t-SNE, UMAP Visualization Examining high-dimensional structure

Image tokens are much longer than words (95 vs 1 for a 3B model), so in raw PCA, words cluster at a single point. Therefore, we also look at PCA with lengths normalized to 1.

6. VLM

6.1 Terminology

Term Meaning
Patch A piece of the image cut into 14×14px squares
ViT Vision Transformer. A transformer that treats patches like tokens
Adapter A small MLP (merger) that converts ViT output to the LLM input size
OCR Reading text from images
Localization Pointing out object locations. Usually answered with bbox coordinates
Sink token A token that receives a lot of attention regardless of the question
Prefill The stage where the entire prompt and image tokens are processed initially to fill the KV cache
M-RoPE A method of splitting RoPE into three directions: time t, vertical h, and horizontal w

6.2 From Image to Tokens (Qwen2.5-VL-7B Example)

336×448 image
→ 14px patch 32×24 = 768 pieces
→ pixel_values (768, 1176)   one patch = 2 frames × 3 channels × 14 × 14
→ patch embedding: 1176 → 1280
→ ViT 32 layers: 1280 → 1280 (attention between patches)
→ Concatenate 4 neighbors: 5120
→ adapter MLP: 3584 (LLM size)
→ LLM tokens 16×12 = 192 pieces
  • One LLM token is 28×28px.
  • Up to pixel_values, there are no learning parameters. Since it only involves cutting and flattening, reassembling it yields the original.
  • Why a still photo has 2 frames: To use the same Conv3d as for video, the same photo is inserted twice.
  • Why row order is not horizontal line order: To place the four 2×2 patches to be merged consecutively, making the merge a simple reshape.
  • In the input line, the 192 slots of <|image_pad|> are replaced by the 192 rows of adapter output.

6.3 Images Have No Dictionary

Word:"cup" → lookup in dictionary → 3584-dimensional vector Image:4 patches → ViT → adapter → 3584-dimensional vector
→ LLM → vector → lm_head → word probability
  • The LLM body receives vectors, not words.
  • The dictionary is used only for input word lookup and output lm_head.
  • Word input is one of about 150,000 items, but adapter input/output are continuous values, so there is no selection from a list.

Input Example

<user> <vision_start> [192 image vectors] <vision_end> Where is the cup in this photo? <assistant>

6.4 Adapter

  • Operation: Concatenates 4 neighboring patches to create a 5120-dimensional vector, then converts it to 3584 dimensions via MLP.
  • Size (based on 3B): adapter 37M, ViT 630M(6%), LLM 3.1B(1%)
  • Principle: Trained together. Without teaching "this vector is stop," the LLM produces vectors that are easy to read as it learns to get the correct answer.
  • Image tokens are not close to any word. The cosine similarity with the closest word is at a random level (approx. 0.08).

6.5 Positional Information

"Position" means which row and column of the image that patch or token was in. It enters through two paths.

Path What is inserted Where
M-RoPE (t, h, w) numbers Rotation angle in LLM attention. Not added to the vector
Position imprinted by ViT Not directly writing "row 3," but an approximate position formed within the vector while passing through ViT Vector content
  • Linear probe: R²≈0 before ViT, R² 0.6~0.7 after ViT and adapter, error tokens 1~2 pieces
  • Text tokens have equal t, h, w values, while image tokens receive the row and column of the grid.
  • Text after the image restarts counting from "maximum image position + 1." Thus, even with a large image, the question is not pushed far away in terms of position.

Shuffling Before and After ViT

Action Analogy Left Figure Accuracy
Before ViT Shuffles image tiles before feeding them to ViT Writing notes while looking at a torn and shuffled photo 0.50
After ViT ViT sees the original, then only shuffles the vector order Only shuffling the order of notes that say "I am on the left" 3B 1.00, Qwen3.5 0.70

6.6 Attention within an image

Stage Who sees whom
Inside ViT patch ↔ patch (no question yet)
Inside LLM text ↔ text, image ↔ image, question → image

Due to the causal mask, question tokens after the image can see the image, but image tokens cannot see the subsequent question.

What if we insert the image again after the question?

[image] question [image] is technically possible, and the second image token can see the question.

  • Cost: Image tokens double, increasing attention cost by up to 4x.
  • Risk: This input format was not seen during training, so its effectiveness cannot be guaranteed.
  • Why it's not strictly necessary: Question tokens and answer-generating tokens can already see the image, so no information is lost.
  • Method with similar purpose: Controlling visual processing itself via language. FiLM is a representative example, used by RT-1.

6.7 Logit lens on image tokens

  • Layer 0 produces meaningless tokens. As we move to later layers, the content of that slot emerges as a word (e.g., robot in the ROBOT slot, stop in the signboard slot, sky in the sky slot).
  • Words are not actually attached. This is a measurement result from reading intermediate vectors through lm_head, and vectors inside the model are continuous values.
  • Characters are translated into character fragment tokens, but positions like "row 12, column 7" cannot be translated into any word.

6.8 Why OCR works well

It reads characters that are 1/3 the size of one token side. The 2×2 merge happens after ViT captures details at 14px intervals into vector channels, so a single token contains the shapes of multiple characters.

Four reasons

  1. The output is directly LLM tokens, so no conversion is needed.
  2. Training data contains many documents, signs, and UI screens.
  3. Linguistic knowledge (prior) corrects errors. That's why actual words are readable at smaller sizes than random strings.
  4. Original resolution can be used as-is (dynamic resolution).

Robot perspective: Reading labels, dashboards, and screen text is suitable for VLMs. However, for random serial numbers, the prior does not help, so resolution determines accuracy. If OCR fails, try increasing resolution (max_pixels) before changing the model.

6.9 Why Localization is weak

"Seeing ability" and "ability to speak in coordinates" are different.

  1. Characters map directly to output words, but positions do not translate that way.
  2. Coordinates must be spoken as numeric tokens like 3, 1, 2, and this method must be learned separately from training data.
  3. Therefore, it is constrained by the data distribution. 3B achieved IoU 0.87 on COCO photos but only 0.19 on simple shapes.
  4. The error in position information is at the level of 1-2 tokens.

Additional notes:

  • The coordinate convention is also determined by training data. Qwen3.5-0.8B answered with 0~1000 normalized coordinates on COCO, but pixel coordinates on shapes.
  • Relative position is harder than absolute position because it requires finding each position and then comparing them.
  • Small objects are covered by fewer tokens and are therefore more frequently mislocalized.
  • Improvement methods: A head that regresses position from hidden states, or utilizing attention maps

What if we split patches finer? Patch size is fixed during training and cannot be changed arbitrarily. Instead, increasing resolution yields a similar effect.

  • Helpful cases: When details are lacking, such as small text or small objects
  • Unresolved cases: When the cause lies in the training data, such as coordinates in shape scenes

6.10 Attention maps

  • Question word tokens look at the target's location in intermediate layers. If the object in the question changes, the attention blob moves accordingly.
  • The attention of the last token does not point well to locations. Interpreting this as "where the model looked" is incorrect.
  • Sink tokens are mainly background tokens in the top row or corners, capturing about 20% of image-side attention.
  • In ViT, there is research that separately places register tokens for such purposes (Darcet et al., 2024).
  • Lift: Indicates how many times higher the attention inside the correct bbox is compared to its area. 1 means random; larger values indicate more focus on the correct answer.

6.11 Token count and cost

Component Cost relative to token count n
MLP Proportional to n
Prefill attention Proportional to n²
Total Prefill Between n and n²
  • It is a polynomial, neither logarithmic nor exponential.
  • If resolution is doubled in width and height, tokens increase by 4x, and prefill increases between 4x and 16x.
  • One cycle of 50Hz control is 20ms. If image processing takes 100ms, it can only run at 10Hz.

6.12 Discarding image tokens

  • Premise: People take photos with the subject in the center (center bias). Therefore, even if the outer 75% is discarded, p(yes) for central objects is largely maintained.
  • If an object is at the edge, discarding the periphery fails. This is not a property of the model but an assumption about the data. It does not hold for robot wrist cameras.
  • Selecting via question attention maintains performance in both cases even when keeping only 25%.
  • Random 25% also holds up quite well because objects span multiple tokens, so some remain.
  • Token discarding and pixel erasing yield nearly identical results. The amount of edge information leaking into central tokens is small.

FastV

  • Idea: Run only the first few layers of the LLM, select image tokens to discard using attention from around layer 2, then compute the remaining layers.
  • Criterion: Instead of directly judging "irrelevance," it discards tokens that received little attention. There is no guarantee that receiving little attention always means a token is unnecessary; there are also tokens that receive a lot of attention but are meaningless, like sinks.
  • If you first run the entire forward pass to select tokens, time is not saved. FastV actually reduces the computation of the later layers.

7. From VLM to Robot

7.1 Why go through an LLM?

It is not strictly necessary. Many policies, such as Diffusion Policy and ACT, generate actions directly from image features.

Benefit Cost
Direct combination with language instructions Latency increases proportional to token count
Leverages pre-trained linguistic and common-sense knowledge Precise position, force, and velocity may become blurred
Attention that shifts focus based on the query Large and heavy architecture

The input side of many VLAs like π0 resembles a VLM, but the output is an action rather than words. Since some policies are designed without language, not all VLAs share the same structure.

7.2 Does reducing the coupling between language and images make it faster?

Partially yes. However, the main culprit for cost is image tokens, not language. Language tokens are typically in the tens, while image tokens range from hundreds to thousands, so removing only language does not significantly increase speed. The key is not passing a large number of image tokens through a large LLM at every control cycle.

Method Benefit Drawback
Run the large model slowly and the small policy quickly Fast control cycles High-level decisions update slowly
Compress language into a single vector to modulate visual processing (FiLM) Use language conditioning without an LLM Reduced expressiveness for complex instructions
Cache image and language processing results, repeating only the action part (π0 approach) Reduced cost of action sampling Recalculation required if the image changes
Predict actions for multiple steps at once (action chunking) Reduced inference frequency Slower response to changes
Reduce image tokens (resolution, FastV) Reduced prefill Potential loss of fine-grained information

7.3 Using multiple cameras

  • Advantages: Compensates for occlusions, provides fine-grained view from wrist cameras
  • Cost: 2 cameras × 4 frames means 8x tokens, up to 64x attention cost
  • Geometric relationships between cameras are not automatically provided and must be learned separately.
  • If the front image changes every cycle, the subsequent KV cache cannot be reused.

7.4 Flow matching

A generative method that learns a velocity field to move noise to the correct action.

  • Training: Learns to match the velocity x1 - x0 at points x_t = (1-t)x0 + t·x1 on the straight line connecting noise x0 and the correct answer x1.
  • Inference: Starts from noise, moves for several steps following the predicted velocity, and outputs an action.
  • Points on the straight line are not the correct answer. They are merely intermediate points used for training.
  • Method to avoid the averaging problem: Instead of taking an average, it arrives at either the left or right side depending on which noise it started from. The average appears in the velocity learning step at each point, not as the action itself.

Is it okay to narrow the space with predefined actions? Yes. This is an approach actually used, and the key is first choosing which action to perform, then only averaging or fine-tuning within that scope.

Method Mechanism
Behavior Transformer (BeT) Groups actions using k-means, classifies the group, and regresses a small offset
VQ-BeT Learns groups using VQ
Action primitive Selects a pre-made action and predicts only the parameters
  • Advantages: Easy and stable training, easily prevents crashing into obstacles by averaging left and right.
  • Disadvantages: Difficult to perform actions outside of definitions, and combinations explode exponentially with many joints.

7.5 Robot action output: Numeric tokens vs. action head

Fast low-level control uses an action head; slow high-level planning uses text.

Reasons for choosing an action head:

  1. Speed: If one joint value like 0.123 takes about 5 tokens, 7 joints require at least 35 tokens. At 50Hz, it must be generated within approximately 0.57ms per token.
  2. Precision: As in bbox experiments, the accuracy of numeric tokens is heavily influenced by the training data distribution.
  3. Format: Joint values are inherently continuous, but converting them to numeric strings can lead to large value differences from single-digit errors.

Numeric tokens are human-readable and do not require model modification, making them suitable for slow high-level planning ("pick up this object", target point).

9. Pop Quiz (with Answers)

Click a triangle (▶) or a question to expand the answer.

LLM

Q1What are Q, K, and V respectively, and in what order is the attention output calculated?

Answer: Q is what I am looking for, K is what I have, and V is the content passed along when selected. The calculation order is: Q, K, V projection → Rotary Positional Encoding (RoPE) → q·k/√d → causal mask → softmax → weighted average of V → output projection.

Q2Why is Δlogit 0 when attention is turned off for two questions that share the same last token?

Answer: Because attention is the only operation that transfers information between tokens, the output of the last token is determined solely by itself. Even if you change the preceding content entirely, the result remains the same.

Q3In GPT-2's MLP + PE, Δ is approximately 1.0. What is the basis for saying that the question content was not incorporated?

Answer: The filler control group. Even if you replace the question with " the the ... Galaxy" and only match the length, the output difference is 0. Δ arose solely from the positional difference of the last token.

Q4Why can learned positional embeddings not replace attention?

Answer: Because token_i embedding + position_i vector contains no content from other tokens, and since MLPs are independent per token, there is no pathway for content to enter. This is a structural issue, not a matter of training volume.

Q5Where do absolute PE and RoPE apply, and why does turning them off yield different results?

Answer: Absolute PE is added to the input vector and flows through all layers, so removing it changes the distribution from the first layer, causing significant collapse. RoPE acts only as rotation of Q and K in attention, so even when turned off, content matching remains, resulting in relatively less collapse.

Q6What experiment supports the idea that "MLP is storage, and attention is the transport pathway"?

Answer: Knockout. Blocking the transmission of South·Korea tokens drops p(Seoul) from 0.977 to 0.006, and the Seoul neuron activation retention rate falls to 15%. Blocking control group tokens keeps it at nearly 0.933 and 97%. If the material does not arrive, the MLP cannot compose the answer.

Q7What are three reasons skip connections are necessary? Why does a learned model collapse if even one is cut?

Answer: The reasons are gradient transmission, learning only the modification amount via identity default behavior, and shared space and contribution decomposition among layers. Because subsequent layers were trained assuming that previous content remains intact on the main line, cutting even one causes collapse.

Q8Why do we examine vectors layer by layer? In Logit lens, why look at the rank curve of the correct answer rather than top1?

Answer: Because we need to know at what depth information is generated to decide where to fix. Intermediate representations are not yet aligned with the output vocabulary, so it is normal for top1 to appear strange; therefore, changes in the rank of the correct token are more reliable.

Q9For two sentences with identical token composition but different order, why is the accuracy of identifying the "side with function" using layer 0 mean-pooling exactly 0.50?

Answer: Averaging makes both sentences become the same vector, yet the correct answers are different. When different correct labels are attached to the same input, no classifier can perform better than random guessing.

Q10Why is judging vector similarity using PCA inappropriate? What should be used instead?

Answer: PCA is a visualization tool for dimensionality reduction, and reducing to 2D discards much information. Similarity should be measured in the original dimensions using cosine, etc., and linear probes should be used to verify the contained information.

Q11Why is KV cache possible, and why does it not fit BERT?

Answer: Due to the causal mask, past tokens do not see future tokens, so even when a new token arrives, the past hidden states and K, V do not change. BERT is bidirectional, so a new token changes the hidden states of past tokens, making it impossible to reuse stored values.

Q12What is wrong with explaining KV cache as "a technique for storing frequently occurring values"? Why is Q not stored?

Answer: It has nothing to do with frequency. It stores all K and V of tokens that have passed within a single sequence to avoid recalculating them. The output of past tokens is already calculated, so there is no need to use Q again, hence it is not stored.

Q13Following a 4-token prompt, two more tokens are input to process three stages. What are the number of tokens processed and the count of q·k operations for the model with and without cache?

Answer:

Number of tokens processed q·k count
No cache 4+5+6 = 15 10+15+21 = 46
With cache 4+1+1 = 6 10+5+6 = 21
Q14What is the KV cache size per token and the memory for 10,000 tokens in a model with 12 layers, 8 KV heads, head_dim 64, and float32?

Answer: 2 × 12 × 8 × 64 × 4B = 49,152B = 48KB, which is approximately 469MB for 10,000 tokens.

Q15Why does the first token not get faster even with KV cache?

Answer: Because there are no stored values initially, the entire prompt must be processed. This prefill stage fills the cache.

Q16What is an attention sink and why does it occur?

Answer: It is a token that receives a lot of attention regardless of content. Since the softmax sum must be 1, remaining weights accumulate when there is nothing to look at.

Q17Compared to full attention, what does Gated DeltaNet gain and what might it lose?

Answer: Memory and step cost become independent of length. However, since it compresses the past into a fixed size, its ability to accurately retrieve distant past information may weaken, so full attention is kept in some layers.

Q18Distinguish between Markov policy, memoryless policy, history-conditioned policy, and POMDP.

Answer: A Markov policy decides based on the current state, a memoryless policy decides based on the current observation without memory, and a history-conditioned policy refers to past observations as well. POMDP is not a policy but a type of problem where only part of the state is visible.

Q19What was the biggest reason Attention was revolutionary? How does it differ from MLP-Mixer?

Answer: The information path changes for each input depending on the content. MLP-Mixer's paths are fixed based on position, which does not fit well with languages where the positions of relationships vary from sentence to sentence.

VLM

Q20In a 28px token model, what are the number of patches and LLM tokens for a 672×672 image? How many numbers are in one patch?

Answer: There are 48×48 = 2,304 patches and 24×24 = 576 tokens. One patch consists of 2 frames × 3 channels × 14 × 14 = 1,176 numbers.

Q21Words have a dictionary, but how do image tokens enter the LLM?

Answer: Without dictionary lookup, vectors calculated by ViT and the adapter are inserted into the <|image_pad|> position. Since the LLM body only receives vectors, it can process them as long as the dimensions match.

Q22Why is the statement "The adapter translates images into words" inaccurate?

Answer: The adapter's output is not close to any word (cosine similarity is at random level); it merely resizes the data into a format readable by the LLM. The transformation that makes it read as words happens as it passes through the LLM layers.

Q23Does a logit lens map showing stop on an image patch mean the model attached a word?

Answer: No. It is a measurement result of reading intermediate vectors through lm_head, and the vectors inside the model remain continuous values.

Q24What are the results and implications of using a random adapter, shuffling token order, replacing with a single average, or removing the image?

Answer:

Condition Result Implication
Random adapter Invents non-existent objects The LLM can only read the format of the adapter
Shuffle order Mostly correct Tokens individually carry content
Single average Captures the gist but cannot read text The gist is distributed, while details reside in specific tokens
Remove image Answers that there is no image (3B) Contrasts with hallucinations when unreadable vectors are present
Q25What are the two paths through which positional information enters? Why do position questions persist even if shuffled after ViT?

Answer: The rotation angles of M-RoPE and the approximate positions embedded in the vector content by ViT. Even if shuffled after ViT, it persists because each vector already carries positional information. If shuffled before ViT, the image itself changes, causing a collapse to the level of taking a photo.

Q26Can image tokens see subsequent questions? Can question tokens see the image?

Answer: Due to the causal mask, image tokens cannot see subsequent questions, but question tokens can see preceding images.

Q27How are characters smaller than a token read? What are the 4 reasons why OCR works well?

Answer: Before the 2×2 merge, ViT packs 14px-level details into vector channels, so multiple character shapes fit into one token. The reasons are that the output is directly LLM tokens, abundant training data, correction by language priors, and input at original resolution.

Q28Why can a model that finds objects well in COCO photos not find simple shapes?

Answer: It is not because the eye cannot see them, but because the method of expressing coordinates as number tokens is constrained by the training data distribution. Shape scenes lie outside that distribution.

Q29Can the localization problem caused by training data be solved just by increasing resolution?

Answer: It cannot be solved. Resolution is effective for problems lacking detail (small text, small objects), but the problem of not having learned how to express coordinates remains.

Q30How does the attention of question word tokens differ from that of the last token?

Answer: Question word tokens look at the target location in intermediate layers. The last token attends heavily to fixed tokens at edges or backgrounds, so interpreting this as "where the model looked" is incorrect.

Q31If resolution is doubled in width and height, how do tokens and prefill change? What is the scaling of token count and time?

Answer: Tokens increase by 4 times, and prefill increases between 4 and 16 times. MLP scales polynomially proportional to n, while attention scales proportional to n².

Q32What is the premise for discarding 75% of outer tokens? When does it fail?

Answer: The premise is center bias, where photo information is concentrated in the middle. It fails if objects are at the edges, and the assumption itself does not hold for videos with different distributions, such as robot wrist cameras.

Q33What is the difference between selecting tokens via attention after a full forward pass and FastV?

Answer: Running a full forward pass first does not save time. FastV discards tokens using attention from earlier layers and runs only the remaining layers with reduced tokens, making it actually faster.

Robot Applications

Q34If there are 2 cameras × 4 frames, how many times do tokens and attention cost increase?

Answer: Tokens increase by 8 times, and attention cost increases by up to 64 times.

Q35Is removing language the key to increasing control cycle frequency?

Answer: No. Language tokens are few, and image tokens are the main culprit for cost. The key is not passing many image tokens through a large LLM every cycle; methods include model cycle separation, FiLM, result caching, action chunking, and token reduction.

Q36Why do robot policies put images into LLMs? Is it necessary?

Answer: It is to achieve combination with language instructions, utilization of pre-trained knowledge, and attention that changes what to look at depending on the question. It is not essential; many policies like Diffusion Policy or ACT directly output actions.

Q37What is the problem with simple regression when the correct answer is either a left turn or a right turn? How is flow matching different?

Answer: Simple regression averages the two, potentially leading to a collision with obstacles. Flow matching moves along a velocity field from noise and arrives at one of the actions depending on the starting noise.

Q38In flow matching training, what is the point x_t on the straight line and what does it aim to predict?

Answer: It is an intermediate training point constructed as x_t = (1-t)x0 + t·x1. The model is trained to predict the velocity x1 - x0 at this point.

Q39What are the key advantages and disadvantages of narrowing the action space using predefined motions?

Answer: First, a motion is selected, and then averaging or fine-tuning is performed only within that scope (e.g., BeT). The disadvantage is that it is difficult to perform actions outside the defined set, and the number of combinations increases significantly when there are many joints.

Q40For 7-joint continuous control at 50Hz, should you choose numeric tokens or an action head?

Answer: An action head. If each joint value requires about 5 tokens, more than 35 tokens must be generated within 20ms, requiring approximately 0.57ms per token, and precision is also dependent on the training distribution. Numeric tokens are more suitable for slower high-level planning.
