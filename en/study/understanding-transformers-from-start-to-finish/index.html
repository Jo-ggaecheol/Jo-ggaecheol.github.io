01Why Transformers Were Introduced

Understanding language is ultimately about knowing which words are related to which other words.

"The animal did not cross the road because it was too tired."
To understand "it," you must connect it back to "the animal."

The RNN, which was widely used in the past, reads a sentence word by word in sequence. It is similar to continuously overwriting a summary on a single notepad; as sentences get longer, it forgets earlier content, and because it must finish processing one word before moving to the next, it is slow.

The idea behind the Transformer (2017, Attention Is All You Need) is simple. Let every word directly see all other words at once. Determining where and how much to focus is called attention.

RNNTransformer
Reading methodSequentially, word by wordAll at once
Relation to distant wordsGradually forgottenDirectly connected via attention
SpeedDifficult to parallelizeParallelizable (suitable for GPUs)

02Tokens and Embeddings

Since computers can only process numbers, a step is needed to convert sentences into numbers.

"나는 고양이를 좋아해" (I like cats)
  ↓ Tokenization      ["나", "는", "고양이", "를", "좋아", "해"]
  ↓ Token ID     [312, 45, 8821, 67, 1590, 23]
  ↓ Embedding      [[0.2, -1.3, 0.8, ...], ...]   (768 numbers per token)
  • Token: A piece of text handled by the model. Frequent words are kept larger, while rare ones are split into smaller pieces (e.g., BPE).
  • Token ID: Just a locker number; close numbers do not imply similar meanings.
  • Embedding: A token converted into a vector carrying meaning. If meanings are similar, the vectors are close. The meaning of each number is not defined by humans but determined through learning.
  • The implementation is a single table of size (number of tokens × 768). Retrieving the row corresponding to an ID yields that token's vector.

03Self-Attention (Q, K, V)

This is the process where each word looks at other words in the sentence and adjusts its own vector to fit the context. To use a library search analogy, each word simultaneously plays three roles.

RoleAnalogyMeaning
Query (Q)The search term typed into the search barI need this kind of information
Key (K)Keywords on a book coverI have this kind of information
Value (V)The actual content of the bookIf you pick me, I will give you this

Example: "배를 타고 바다로 갔다" (I went to the sea by boat) shows the result of comparing the Q of "boat" with the K of each word.

Attention(Q, K, V) = softmax(QKᵀ√dk) V

The reason it is called "self" is that Q, K, and V all come from the same sentence.

04Multi-Head Attention

In "철수가 어제 공원에서 산 빨간 공을 던졌다" (Chulsoo threw the red ball he bought at the park yesterday), "던졌다" (threw) wants to know who (Chulsoo), what (ball), and when (yesterday) simultaneously. A single attention pass averages these relationships, blurring them.

So we run attention in parallel across multiple heads. Each head has its own W_Q, W_K, W_V to capture different relationships, and the division of roles emerges naturally through learning.

Input (768)
 ├─ Head 1  (64) ─┐
 ├─ Head 2  (64) ─┤
 ├─ ...           ├─ Concatenate (12 × 64 = 768) → W_O → Output (768)
 └─ Head 12 (64) ─┘

Splitting 768 into 12 parts of 64 each keeps the total computation similar to a single attention pass. Since both input and output are 768, multiple layers can be stacked.

05Positional Encoding

Since attention looks at all words at once, it doesn't know the order. "Dog bites man" and "Man bites dog" look like the same bag of words. So we inject order information separately.

Final Input = Token Embedding + Positional Encoding (Both are size 768, so they can be added directly)

If we input 1, 2, 3 as-is, the values become large and overwrite word meanings. The original paper uses sin/cos waves with different frequencies. Like the second, minute, and hour hands of a clock, looking at multiple wave values together uniquely determines the position. Values are always between -1 and 1.

MethodDescriptionUsed in Models
sin/cos (Fixed)Calculated by formula, not learnedOriginal paper
Learned Positional EmbeddingsLearns vectors for each position via a lookup tableBERT, GPT-2
RoPERotates Q and K by the position instead of addingLLaMA and other modern LLMs

07Encoder · Decoder · Masking

The original paper was a translator. It consists of an encoder that reads and understands the source text and a decoder that writes the translation one word at a time.

Masking: No Peeking into the Future

During training, the entire correct sentence is fed in. If it could look ahead, it would simply copy the answer. Therefore, each word is allowed to see only itself and previous words. Replacing future positions in the attention scores with −∞ results in 0 after softmax.

TypeStrengthsRepresentative Models
Encoder-onlyUnderstanding · ClassificationBERT
Decoder-onlyGenerationGPT, LLaMA, Claude and most other LLMs
Encoder + DecoderTransformation (translation, summarization)T5, BART

08Learning and Generation

From Vectors to the Next Token

The vector at the final position (768) → output matrix (768 → vocabulary size) → scores per token (logits) → softmax → probabilities → pick one. This is the reverse of embedding.

Selection Methods and Temperature

Greedy always picks the top candidate, while sampling draws according to the probabilities. Temperature is a knob that adjusts the probability distribution.

Generation: Sampling One Token at a Time and Feeding It Back

"Repetition"WhereContent
N layers (Q4)Inside the modelBlock 1 → Block 2 → … (per prediction step)
Generation loopOutside the modelSample token → append → run again
Training step (Q5)During trainingPredict → compute error → update weights

Learning: Predicting the Next Token (Q2, Q5)

  1. All weights (embeddings, W_Q·W_K·W_V·W_O for every layer, FFN, output matrix) start randomly.
  2. The massive amount of text written by humans serves as both the problem and the answer. No separate labels are needed.
  3. Thanks to masking, a single sentence allows prediction for all positions simultaneously.
  4. The lower the probability assigned to the correct token, the larger the error (cross-entropy).
  5. Backpropagation sends the error backward from the output layer → Block N → … → embeddings, slightly adjusting all weights simultaneously.
  6. After repeating this hundreds of thousands to millions of times, embedding meanings, attention relationships, head roles, and per-layer functions emerge naturally.
  7. Subsequently, fine-tuning (SFT), RLHF, etc., refine it into a conversational assistant. The structure remains the same; only the weights change.

Q&AQuestions & Answers

Questions I asked myself while studying. Try to recall the answer first, then expand.

Q1Is there a special reason for the embedding dimension of 768?Stage 2 · Tokens and Embeddings
  • There is no mathematical significance. It is a hyperparameter (d_model) chosen by humans.
  • It became famous because BERT-base and GPT-2 small use it.
  • Larger dimensions improve expressiveness, but there is a trade-off with increased computation and memory usage.
  • Practical reason: It must be divisible by the number of heads (12 heads × 64 = 768). Multiples of 64 or 128 are efficient for GPU operations.
  • Other models: BERT-large 1024, LLaMA-7B 4096, GPT-3 12288.
Q2Are matrices like W_Q, W_K, and W_V pre-trained by a larger model? Using human-written text?Stage 3 · Self-Attention
  • They are not created by another model. These matrices are the Transformer's own parameters.
  • Initially, they are random. They are refined via backpropagation by repeatedly performing "next token prediction" on large amounts of human-written text → pre-training.
  • The embedding table, W_Q/W_K/W_V, and subsequent layers are all learned together (end-to-end).
  • Once training is complete, the values are fixed. When using the model (inference), only computation is performed. → Figure 13
Q3Is the Q·K value called attention?Stage 3 · Self-Attention

Only partially correct. The name differs at each stage.

StageNameMeaning
Q·Kᵀ / √d_kAttention scoresRaw relevance scores
After softmaxAttention weightsRatios that sum to 1. The "attention map" usually refers to this
Weights × VAttention (entire operation)Result: Context-aware vector
Q4Does "repeating attention N times (for loop)" mean heads process in parallel, i.e., the same attention repeats to find positions?Stage 4 · Multi-Head Attention
  • No. Two concepts are mixed up here. → Figure 6
  • Heads: Run side-by-side (in parallel) within the same layer. They are independent of each other.
  • N repetitions: This refers to stacking N layers (blocks) vertically. It is a sequential structure where the output of one layer becomes the input of the next, hence written as a for loop.
  • Each layer has different weights. It does not run until convergence but passes through a fixed number of times.
  • The intuition that it "gradually finds positions" is correct regarding layers. Lower layers tend to capture syntax and adjacency, while upper layers capture semantics and reference relationships.
x = embed(tokens)
for layer in layers:   # ← "N repetitions" (layers)
    x = layer(x)       #   Heads inside are computed simultaneously
Q5If each layer has its own W_Q etc., where were those values learned?Stage 5+ · Q2 Re-question
  • All layers are learned simultaneously in one go during pre-training. They are not trained separately per layer.
  • One training step: Forward pass (Layer 1 → … → Layer N → Prediction) → Error calculation → Backpropagation (Layer N → … → Layer 1) → Simultaneously update weights for all layers. → Figure 13
  • Why values differ per layer: Initial random values are different, and the inputs received and positions vary, leading to different roles.
  • Who does it: The company or research team building the model trains for weeks to months using thousands of GPUs. The result is a weight file.
Q6Is residual connection adding the residual, i.e., adding back the original attention?Stage 6 · Transformer Block
  • The big picture is correct, but the original and residual are reversed. → Figure 8
  • Output = x + Attention(x)
  • x = The original input entering the block. It is the original that comes via the skip connection and is added.
  • Attention(x) = The change amount calculated by the layer = residual.
  • Residual = The difference of "Output − Input". The layer learns how much to change, not the entire result.
  • The same applies after FFN: x + FFN(x). Also known as skip connection or shortcut, it became famous from ResNet (2015).

✓Confusing Concepts

  • Embedding Dimension (d_model): It is a hyperparameter and a GPU-friendly size divisible by the number of heads. Q1
  • Source of Weights: The model itself learns them all at once via pre-training, not a separate model. Q2 · Q5
  • Attention Terminology: Distinguished as scores / weights / attention output. Q3
  • Heads vs Layers: Heads are parallel and independent, while "N repetitions" means stacking layers with different weights sequentially. Q4
  • Residual Connection: Original = Input x, residual = Change amount created by the layer. Q6
