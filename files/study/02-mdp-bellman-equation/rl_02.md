## 1. 큰 그림: 한 층씩 쌓기

```
Markov chain (S, P)  →  MRP (+R, γ)  →  MDP (+A, π)  →  최적성 (max)
  상태가 저절로 흐름      흐름에 점수가 붙음     내가 흐름을 조종함     가장 잘 조종하기
```

| | 상태 전이 | 보상 | 행동 | 묻는 질문 |
|---|---|---|---|---|
| Markov chain | P(s'\|s) | ❌ | ❌ | 장기적으로 어디에 머무나 (μ\*) |
| MRP | P(s'\|s) | R(s) | ❌ | 이 상태는 장기적으로 얼마나 좋은가 (V) |
| MDP | p(s'\|s, a) | R(s, a) | ✅ | 이 정책은 얼마나 좋은가 (V^π, Q^π) |
| 최적성 | p(s'\|s, a) | R(s, a) | ✅ | 가장 좋은 정책은 무엇인가 (V\*, Q\*, π\*) |

bandit(01)은 상태가 1개이고 P = [1]인 가장 단순한 경우다.

## 2. Markov chain

### 정의
상태열 S₀, S₁, …가 다음을 만족하면 Markov chain이다.

$$P(S_{t+1}=s' \mid S_t, S_{t-1}, \dots, S_0) = P(S_{t+1}=s' \mid S_t)$$

**Markov 성질**: 현재를 알면 과거는 미래 예측에 도움이 안 된다. 과거가 무관하다는 게 아니라, 과거의 정보가 **이미 현재 상태에 다 담겨 있다**는 뜻이다.

전이 확률이 시간과 무관하면(**time-homogeneous**) 행렬 하나로 쓴다. "어제의 규칙 = 오늘의 규칙"이다. 고정된 건 규칙 P이고, 상태 분포는 계속 변할 수 있다 (Q1).

$$P_{ss'} = P(S_{t+1}=s' \mid S_t=s), \qquad \sum_{s'} P_{ss'} = 1$$

### 예: 로봇 2-상태 체인

| 현재 \ 다음 | 작업(W) | 충전(C) |
|---|---|---|
| 작업(W) | 0.9 | 0.1 |
| 충전(C) | 0.5 | 0.5 |

### 분포의 시간 발전
분포를 행벡터 μ_t로 쓰면 μ_{t+1} = μ_t P, 따라서 μ_t = μ₀Pᵗ다. n스텝 전이는 Pⁿ이고, Chapman–Kolmogorov 식 P^{m+n} = P^m P^n이 성립한다.

μ₀ = (1, 0)이면 μ₁ = (0.9, 0.1), μ₂ = (0.86, 0.14), μ₃ = (0.844, 0.156), …

### 정상분포
한 번 더 전이해도 변하지 않는 분포다. 고유값 1의 왼쪽 고유벡터다.

$$\mu^* = \mu^* P$$

**들어오는 흐름 = 나가는 흐름** (global balance, Q4). 예에서 0.1·μ_W = 0.5·μ_C → **μ\* = (5/6, 1/6)**. 로봇은 장기적으로 시간의 83%를 작업한다.

쌍마다 흐름이 같을 필요는 없다(detailed balance는 더 강한 조건). 1→2→3→1로만 도는 체인도 정상분포 (⅓, ⅓, ⅓)를 가진다.

### 언제 존재하고, 유일하고, 수렴하나 (유한 상태)

| 조건 | 의미 | 보장 |
|---|---|---|
| irreducible | 모든 상태끼리 서로 도달 가능 | 정상분포가 유일 |
| + aperiodic | 정확히 주기적으로만 돌아오지 않음 | 어떤 μ₀에서든 μ_t → μ\* |

- 둘 다면 **ergodic**: "시간 평균 = 분포 평균". 한 궤적만 오래 따라가도 μ\*를 추정할 수 있다.
- 수렴 속도는 두 번째 고유값 |λ₂|가 정한다. 오차 ∝ |λ₂|ᵗ. 예에서 λ₂ = tr(P) − 1 = 0.4.
- 반례 (Q3): 주기적 P = [[0,1],[1,0]]은 영원히 진동한다. 흡수 상태가 두 개인 체인은 수렴하지만 출발점에 따라 도착지가 다르다.

### 현실은 시간 균질이 아니지 않나 (Q2)

| 현실 | 모델 |
|---|---|
| 규칙 자체가 시간에 따라 변함 | 시간 비균질 체인 P_t, nonstationary MDP |
| 머무는 시간이 들쭉날쭉 | semi-Markov, 연속시간 Markov chain |
| 센서가 일부만 보여줌 | POMDP (10장) |
| 숨은 파라미터(마찰, 질량) | hidden-parameter MDP, meta-RL |

비정상성은 대개 **상태에 빠진 변수**다. 모터 온도, 배터리, 마모를 상태에 넣으면 다시 시간 균질이 된다.

## 3. 🤖 Markov는 상태 표현의 성질이다

**던진 공의 사진 한 장** (Q5):
- 위치만 있으면 올라가는 중인지 내려가는 중인지 모른다. 이전 사진이 도움이 된다 → **Markov가 아니다**.
- (위치, 속도)를 상태로 잡으면 이전 사진이 줄 정보가 없다 → **Markov다**.

같은 세상이라도 **상태를 어떻게 정의하느냐에 따라** Markov이기도 하고 아니기도 하다.

- 로봇팔: 관절각 θ만으로는 Markov가 아니고, (θ, θ̇)면 2차 동역학에서 Markov다.
- 원칙: 상태 = 미래 예측에 필요한 과거의 **충분통계량**. 과거를 상태에 붙이면(state augmentation) 무엇이든 Markov로 만들 수 있다.
- DQN이 Atari 프레임 4장을 쌓는 이유, 로봇 정책이 관측 history를 받는 이유가 이것이다.

## 4. 에피소드와 종료 상태

**에피소드**: 초기 상태 S₀ ~ μ₀에서 시작해 종료 상태에 도달할 때(시각 T, 확률변수)까지의 궤적 하나 (Q7).

```
S₀, A₀, R₁, S₁, A₁, R₂, …, S_T   → 리셋 → 다음 에피소드
```

- 종료가 있으면 **episodic task**, 끝이 없으면 **continuing task**(γ < 1로 합을 유한하게).
- **흡수 상태**: 종료 후 "자기 자신으로만 가고 보상 0"인 가상 상태. 이렇게 보면 episodic과 continuing을 같은 무한합 식으로 다룰 수 있다.

### 예: 물체 들어 올리기 (Q9)

| 용어 | 이 태스크에서 |
|---|---|
| step | 제어 주기 1번 (20Hz면 0.05초) |
| state | 관절각·각속도, 그리퍼, 물체 pose |
| action | 관절 목표값 또는 토크 |
| μ₀ | 리셋할 때 물체를 랜덤 위치에 놓음 |
| terminal | 성공(z ≥ 30cm), 실패(떨어뜨림, 충돌, 관절 한계) |
| truncation | 200 step 안에 못 끝내서 강제로 끊음. **종료가 아니다** |

- **"높이가 안 바뀌면 끝"이 아니다.** 들고 가만히 있는 것도 아직 움직일 수 있는 평범한 상태다. 종료는 태스크 설계자가 **정의**한다.
- **truncation ≠ termination**: gymnasium이 `terminated`/`truncated`를 따로 주는 이유다. 시간 제한으로 끊긴 상태의 가치를 0으로 두면 학습이 틀어진다 (05, 07에서 다시).
- bandit은 "한 번 당기기 = 길이 1의 에피소드"로 볼 수 있다. 상태는 확률 1로 자기 자신으로 돌아오고, 무작위성은 보상에만 있다 (Q8).

## 5. MRP: return, 할인율, 가치 함수

$$\text{MRP} = (\mathcal S, P, R, \gamma), \qquad R(s) = \mathbb E[R_{t+1} \mid S_t = s]$$

### Return

$$G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}, \qquad G_t = R_{t+1} + \gamma G_{t+1}$$

재귀식 G_t = R_{t+1} + γG_{t+1}에서 Bellman 방정식이 나온다.

### 할인율 γ: 얼마나 먼 미래까지 볼 것인가 (Q11)

딱 잘리는 게 아니라 가중치 γᵏ로 부드럽게 줄어든다.

| γ | 10스텝 뒤 가중치 | 반감기 (ln 0.5 / ln γ) | 유효 시야 1/(1−γ) |
|---|---|---|---|
| 0.5 | 0.001 | 1스텝 | 2스텝 |
| 0.9 | 0.35 | 6.6스텝 | 10스텝 |
| 0.99 | 0.90 | 69스텝 | 100스텝 |

γ < 1을 쓰는 이유: ① 끝없는 과제에서도 |G| ≤ R_max/(1−γ)로 유한 ② 먼 미래는 불확실 ③ "빨리 끝내라"는 압력 (12장 문제 2). γ = 0이면 바로 다음 보상만 본다(bandit).

### 가치 함수

$$V(s) = \mathbb E[G_t \mid S_t = s]$$

01의 q\*(a)가 "팔 a의 평균 보상"이었다면, V(s)는 "상태 s에서 출발한 평균 장기 수익"이다.

### Bellman 방정식

$$V(s) = \mathbb E[R_{t+1} + \gamma G_{t+1} \mid S_t = s] = R(s) + \gamma \sum_{s'} P_{ss'}\, V(s')$$

E[G_{t+1} | S_{t+1}=s'] = V(s')가 되는 데에 **Markov 성질**이 쓰인다.

**지금 가치 = 바로 받는 보상 + γ × 다음 상태 가치의 평균**

### 행렬로 한 번에 풀기

$$V = R + \gamma P V \;\Rightarrow\; V = (I - \gamma P)^{-1} R$$

- γP의 고유값 크기가 모두 γ 이하라 I − γP는 항상 가역이다.
- 비용 O(n³). 상태가 많으면 반복 V ← R + γPV를 쓴다 (9장).

### 숫자 예
02-1 체인에 작업 보상 1, 충전 보상 0, γ = 0.9를 붙이면 다음과 같다.

$$V_W = 1 + 0.9(0.9V_W + 0.1V_C), \quad V_C = 0.9(0.5V_W + 0.5V_C) \;\Rightarrow\; V_W \approx 8.59,\; V_C \approx 7.03$$

- 충전 중이어도 V_C ≠ 0: 곧 작업으로 돌아가서 벌 것까지 반영된다. **V는 미래까지 포함한 평가다.**
- 정상분포와의 연결: 스텝당 평균 보상 μ\*_W = 5/6, 시야 10스텝 → V ≈ 8.3 근처. γ → 1이면 (1−γ)V(s) → μ\*·R.

### target이 또 나왔다
우변 **R + γV(s')**는 05 TD의 target이다. 01에서 "target만 바뀐다"고 했던 그 target이고, 이번엔 **자기 추정치 V(s')를 포함한다**(bootstrapping).

### 큰 흐름: 미래 보상이 지금의 판단이 되기까지 (Q12)

```
① 평가 : 미래 보상을 끌어와 지금 상태의 점수 V(s)로 만든다      ← MRP (5장)
② 선택 : 행동마다 "그 뒤에 갈 상태의 점수"를 비교한다          ← MDP의 Q(s,a) (7장)
③ 개선 : 더 좋은 쪽을 고르도록 정책을 바꾼다                  ← 03 DP
   ↺ 정책이 바뀌면 점수도 바뀐다 → ①로 = GPI
```

복도 S0–S1–S2–S3–G (G 도착 시 +1, 정책 "항상 오른쪽"):

| | S0 | S1 | S2 | S3 |
|---|---|---|---|---|
| γ = 0.9 | 0.729 | 0.81 | 0.9 | 1 |
| γ = 0.5 | 0.125 | 0.25 | 0.5 | 1 |

G에서만 준 보상이 **뒤로 번져서** 목표 쪽으로 오르막인 지형이 생긴다. 그러면 매 칸에서 오르막 쪽만 고르면 된다. 먼 계획 문제가 **한 스텝짜리 선택 문제**로 바뀐다. γ가 작으면 멀리서는 목표가 거의 안 느껴진다.

## 6. 보상 설계: shaping과 hacking

### Reward shaping (Q10)
"성공 +1, 나머지 0"(sparse)이면 랜덤 로봇은 평생 0만 보고 아무것도 못 배운다. 중간 단계마다 힌트 보상을 얹는다.

| 단계 | 힌트 보상 |
|---|---|
| 손이 물체에 가까워짐 | + (거리 감소량) |
| 파지 성공 | +0.5 |
| 물체 높이 증가 | + (상승량) |
| 30cm 도달 | +10 (진짜 목표) |

힌트가 목표와 어긋나면 **최적 행동 자체가 바뀐다.** 안전한 형태는 **potential-based shaping**(Ng et al., 1999)이다.

$$F(s, s') = \gamma\Phi(s') - \Phi(s) \;\Rightarrow\; G' = G - \Phi(s_0)$$

망원급수로 소거되어 상수 하나만 빠지므로 정책 사이의 순위가 안 바뀐다.

### Reward hacking
에이전트는 의도가 아니라 **숫자**를 최대화한다. 보상이 의도의 불완전한 대리 지표면 허점을 판다.
- **29cm에서 떠 있기**: 매 스텝 z 보상 + 성공 시 종료면, 성공 직전에 오래 떠 있는 게 이득
- **물체 세우기**: z를 물체 중심 높이로 재면 긴 물체를 세우기만 해도 올라감
- **CoastRunners** (OpenAI, 2016): 결승 대신 아이템 재생성 구역을 빙빙 돎
- **시뮬레이터 버그**: 물리 엔진 충돌 오류로 튀어 오르며 "전진"
- **RLHF**: 보상 모델의 취향(긴 답, 아부)을 파고듦 (10)

reward hacking은 학습이 실패해서가 아니라 **최적화가 성공해서** 생긴다 (8장). 학습된 행동은 반드시 영상으로 확인한다.

### 무한대 보상, exponential 보상은? (Q13)

| 시도 | 문제 |
|---|---|
| 성공 보상 ∞ | 성공 확률이 0만 아니면 모든 정책의 V = ∞ → 정책을 비교할 수 없다. 수치적으로 inf/NaN |
| 아주 큰 유한값 | 보상 전체를 c배 해도 최적 정책은 그대로다. 중요한 건 **비율**. 너무 크면 shaping이 묻혀 sparse와 같아지고 return 분산이 커져 불안정 → 실전은 오히려 reward scaling / clipping(DQN [−1, 1]) |
| exp(z) (위로 무한히 커짐) | 바닥 근처 신호가 거의 0이라 초반 학습이 안 되고, 꼭대기 근처 스텝당 보상이 커져 떠 있기 hacking이 심해진다 |
| exp(−‖오차‖²/σ) (오차 커널) | **좋은 exponential**. (0, 1]로 유계, 목표에서 1. 보행 로봇 속도 추종 보상 등에서 표준 |

들어 올리기라면: 성공 시 **종료 + 적당한 보너스**, 스텝당 **시간 패널티**, 높이는 **potential-based**로.

## 7. MDP: 정책, V^π, Q^π

$$\text{MDP} = (\mathcal S, \mathcal A, p, R, \gamma), \qquad p(s' \mid s, a), \quad R(s,a) = \mathbb E[R_{t+1} \mid S_t=s, A_t=a]$$

### 정책
π(a|s) = P(A_t = a | S_t = s). 확률적일 수도, 결정적(a = π(s))일 수도 있다. MDP는 Markov이므로 **현재 상태만 보는 정책으로 충분**하다 (POMDP에서는 깨짐).

### 정책을 고정하면 MDP는 MRP가 된다 (Q6)

$$P^\pi(s' \mid s) = \sum_a \pi(a|s)\, p(s'|s,a), \qquad R^\pi(s) = \sum_a \pi(a|s) R(s,a) \;\Rightarrow\; V^\pi = (I - \gamma P^\pi)^{-1} R^\pi$$

- 상태와 동역학 p는 **환경이 정한다**. 우리가 고르는 건 정책이다.
- **정책을 고른다 = 어떤 Markov chain을 만들지 고른다.** 좋은 정책은 보상 높은 상태에 오래 머무는 체인을 만든다.
- "수렴"은 두 가지다: ① 학습의 수렴(정책이 더 안 바뀜 → 체인 고정 → 학습 곡선 평평) ② 고정 정책 아래 분포의 수렴(μ_t → d^π → 스텝당 보상 안정). 곡선이 평평해도 최적 보장은 없다.

### V^π와 Q^π

$$V^\pi(s) = \mathbb E_\pi[G_t \mid S_t = s], \qquad Q^\pi(s,a) = \mathbb E_\pi[G_t \mid S_t = s, A_t = a]$$

| | 질문 | 비유 |
|---|---|---|
| V^π(s) | 이 상태에서 앞으로 π를 따르면 얼마를 버나 | 이 **칸**의 점수 |
| Q^π(s,a) | 이 상태에서 **일단 a를 하고** 이후 π를 따르면 | 이 칸에서 **이 문으로 나가는** 점수 |

V만 있으면 행동을 비교하려고 p(s'|s,a)가 필요하다. Q는 행동별 점수를 직접 들고 있어서 **모델 없이** 고를 수 있다 → Q-learning(05), DQN(07).

### 관계식과 Bellman expectation 방정식

$$V^\pi(s) = \sum_a \pi(a|s)\, Q^\pi(s,a), \qquad Q^\pi(s,a) = R(s,a) + \gamma \sum_{s'} p(s'|s,a)\, V^\pi(s')$$

$$V^\pi(s) = \sum_a \pi(a|s)\Big[R(s,a) + \gamma \sum_{s'} p(s'|s,a) V^\pi(s')\Big]$$

$$Q^\pi(s,a) = R(s,a) + \gamma \sum_{s'} p(s'|s,a) \sum_{a'} \pi(a'|s')\, Q^\pi(s',a')$$

```
       s            ← V(s)
    ╱  │  ╲         π(a|s)로 평균       (내가 고르는 부분)
   a₁  a₂  a₃       ← Q(s,a)
   │╲
   s' s'            p(s'|s,a)로 평균    (환경이 정하는 부분)
                    ← V(s')
```

### 숫자 예: 복도에 행동 붙이기
행동 ←/→, 결정적 이동, S0에서 ←는 제자리, S3에서 → 하면 +1 받고 종료, γ = 0.9. **랜덤 정책** π(←) = π(→) = 0.5를 V^π = (I − γP^π)⁻¹R^π로 풀면 다음과 같다.

| | S0 | S1 | S2 | S3 |
|---|---|---|---|---|
| **V^π** | 0.275 | 0.336 | 0.472 | 0.712 |
| Q^π(s, ←) | 0.247 | 0.247 | 0.302 | 0.425 |
| Q^π(s, →) | **0.302** | **0.425** | **0.641** | **1.000** |

- 검산 (S1): Q(→) = 0.9 × 0.472 = 0.425, Q(←) = 0.9 × 0.275 = 0.247, V = 평균 0.336 ✓
- **랜덤 정책의 Q만 봤는데 모든 칸에서 →가 크다.** "Q가 큰 행동을 고르자"로 바꾸면 바로 "항상 →" = 최적 정책. 이게 **policy improvement**다 (증명은 03).

### Advantage

$$A^\pi(s,a) = Q^\pi(s,a) - V^\pi(s)$$

"이 행동이 평소보다 얼마나 나은가". S1에서 A(→) = +0.089, A(←) = −0.089. 08 policy gradient와 PPO의 GAE가 이걸 쓴다.

### 용어: PPO, POMDP (Q14)
- **PPO** (Schulman et al., 2017): advantage가 양수인 행동의 확률은 올리고 음수면 내리되, 새/옛 정책 확률비를 [1−ε, 1+ε]로 clip해서 한 번에 너무 크게 안 바뀌게 한다. 로봇 보행과 RLHF의 표준 (09).
- **POMDP**: 진짜 상태 대신 관측만 보는 MDP (10장).

## 8. 최적성: V\*, Q\*, Bellman optimality

### 정의

$$V^*(s) = \max_\pi V^\pi(s), \qquad Q^*(s,a) = \max_\pi Q^\pi(s,a)$$

유한 MDP에는 **모든 상태에서 동시에 최선인 결정적 정책 π\***가 항상 존재한다.

### 기호 정리 (Q15, Q16)

| 기호 | 읽기 | 뜻 |
|---|---|---|
| Q^π | 큐 파이 | 정책 π(지금 습관)를 따를 때의 **진짜** 점수 |
| Q\* | 큐 스타 | 이후 **최적으로** 행동할 때의 **진짜** 점수 (= Q^{π\*}) |
| Q | 큐 | 알고리즘이 들고 있는 **추정치** (표, 신경망) |
| Q′ | 큐 프라임 | 별개 표기. 다음 상태의 Q(s′, a′) 또는 DQN target network |

항상 Q^π(s,a) ≤ Q\*(s,a)다.

### 예: 출근길 (보상 = −분)

```
            고속도로 10분        시내 20분
  집(A) ──────────────→ 갈림길(B) ──────────→ 회사
    │                         └──── 우회 8분 ──→ 회사
    └──────────── 국도 25분 (직행) ────────────→ 회사
```

습관 π: B에서 늘 시내로 간다.

| A에서 | Q^π (B에서 습관대로) | Q\* (B에서 최선) |
|---|---|---|
| 고속도로 | −30 | **−18** ✅ |
| 국도 | **−25** ✅ | −25 |

- Q^π는 이후 습관이 섞여 있어서 **첫 선택까지 오판**하게 만든다.
- Q\*는 "이후엔 최선"을 전제하므로 **각 지점에서 argmax만 하면 전체 최적**이다.
- Q^π로 Q\*를 찾아간다: B에서 Q^π(우회) = −8 > Q^π(시내) = −20 → 습관 수정 → 재평가하면 A에서도 고속도로 → 더 안 바뀌면 Q\*.

### Q\*만 알면 최적 행동은 공짜다

$$\pi^*(s) = \arg\max_a Q^*(s,a)$$

한 스텝만 보고 고르면 된다. 미래는 이미 Q\*에 압축되어 있다.

### Bellman optimality 방정식
내가 고르는 부분의 **평균이 max로** 바뀐다. 환경 부분(p에 대한 평균)은 그대로다.

| | Expectation (π를 따름) | Optimality (최선) |
|---|---|---|
| V ↔ Q | V^π(s) = Σ_a π(a\|s) Q^π(s,a) | V\*(s) = **max_a** Q\*(s,a) |
| Q ↔ V | Q^π = R + γ Σ p V^π | Q\* = R + γ Σ p V\* |

$$V^*(s) = \max_a \Big[R(s,a) + \gamma \sum_{s'} p(s'|s,a) V^*(s')\Big]$$

$$Q^*(s,a) = R(s,a) + \gamma \sum_{s'} p(s'|s,a) \max_{a'} Q^*(s',a')$$

| 알고리즘 | target | 출처 |
|---|---|---|
| bandit | R | γ = 0, 상태 1개 |
| TD(0) | R + γV(s') | Bellman expectation |
| Q-learning | R + γ max Q(s',·) | **Bellman optimality** |

### 최적성 원리
**최적 경로의 뒷부분도 그 자체로 최적이다.** 서울→부산 최단 경로가 대전을 지나면, 그 안의 대전→부산 구간도 최단이어야 한다. 그래서 "지금의 최선 = 이번 한 수 + 도착지에서의 최선".

### 왜 행렬 한 번으로 못 푸나
max는 비선형이다. 어떤 행동이 최선인지가 V\*에 달려 있고, V\*는 또 어떤 행동이 최선인지에 달려 있다. 그래서 **반복**으로 푼다.

| 방법 | 아이디어 | 섹션 |
|---|---|---|
| Value iteration | V ← max_a [R + γ p V] 반복 | 03 |
| Policy iteration | 평가(선형 풀이) → max로 개선 → 반복 | 03 |
| Linear programming | max 조건을 부등식 제약으로 | 참고 |

### 숫자 예
복도 V\* = (0.729, 0.81, 0.9, 1). S1에서 검산하면 max(0.9 × 0.729 = 0.656, 0.9 × 0.9 = 0.81) = 0.81 ✓. 랜덤 정책의 V^π(S1) = 0.336은 평균이지 최댓값이 아니라서 이 방정식을 만족하지 않는다 → 최적 판별 기준.

### 🤖 연결
- 연속 시간·연속 상태 버전이 최적 제어의 **HJB 방정식**. 선형 시스템 + 이차 비용이면 V\*가 이차식 → **LQR** (03).
- **최적은 "주어진 보상에 대해" 최적이다.** 보상이 떠 있기를 이득으로 만들면 최적 정책은 정확히 떠 있기다.

## 9. Contraction: 왜 반복하면 반드시 수렴하나

### Bellman 연산자
점수표 V를 받아 한 스텝 갱신한 점수표를 내놓는 "기계"다.

$$(T^\pi V)(s) = \sum_a \pi(a|s)\Big[R + \gamma \sum_{s'} p\, V(s')\Big], \qquad (T^* V)(s) = \max_a \Big[R + \gamma \sum_{s'} p\, V(s')\Big]$$

Bellman 방정식 = **고정점**: V^π = T^π V^π, V\* = T\*V\*.

### 수축

$$\|V - U\|_\infty = \max_s |V(s) - U(s)|, \qquad \boxed{\|TV - TU\|_\infty \le \gamma \|V - U\|_\infty}$$

기계를 한 번 통과할 때마다 **두 추측 사이의 거리가 γ배 이하로 줄어든다.**

### 증명
- T^π: |(T^πV − T^πU)(s)| = γ|Σ P^π_{ss'}(V − U)(s')| ≤ γ‖V − U‖∞. R은 빼면 사라지고, P의 행은 가중 평균이라 최댓값을 넘지 못한다.
- T\*: 추가로 |max f − max g| ≤ max |f − g|. **max는 비선형이지만 수축성을 깨지 않는다.**

### Banach 고정점 정리

| 보장 | 의미 |
|---|---|
| 고정점 유일 | V^π, V\*는 각각 하나뿐 |
| 어디서 시작해도 수렴 | V₀를 0으로 잡든 100으로 잡든 |
| 속도 | ‖V_k − V\*‖ ≤ γᵏ ‖V₀ − V\*‖ |

### 알고리즘

```
Policy evaluation (선형 풀이)          Value iteration
  V = solve(I − γP^π, R^π)              V ← 0
                                       repeat:
Policy evaluation (반복)                   for s: V_new(s) = max_a [R(s,a) + γ Σ p(s'|s,a) V(s')]
  V ← 0                                   if ‖V_new − V‖∞ < ε: break
  repeat: V ← R^π + γ P^π V                V ← V_new
                                       π(s) = argmax_a [R(s,a) + γ Σ p V]
```

### 숫자 예: 복도 value iteration (γ = 0.9)

| k | V₀ = 0에서 | V₀ = 10에서 | 최대 차이 |
|---|---|---|---|
| 0 | (0, 0, 0, 0) | (10, 10, 10, 10) | 10 |
| 1 | (0, 0, 0, **1**) | (9, 9, 9, 9) | 9.0 |
| 2 | (0, 0, **0.9**, 1) | (8.1, …) | 8.1 |
| 3 | (0, **0.81**, 0.9, 1) | (7.29, …) | 7.29 |
| 4 | (**0.729**, 0.81, 0.9, 1) ✅ | (6.56, …) | 5.83 |
| 7 | 그대로 | (4.78, …) | 4.05 |

- 0에서 시작: 보상 1이 **반복마다 한 칸씩 뒤로 번진다.**
- 10에서 시작: 터무니없는 낙관도 매번 0.9배씩 깎이며 같은 답으로 내려온다.
- 차이 ≤ 10 × 0.9ᵏ. 이론대로다.

### γ와 수렴 속도

$$k \approx \frac{\ln(1/\varepsilon)}{1 - \gamma}$$

| γ | 오차 1%까지 반복 수 |
|---|---|
| 0.9 | ~46 |
| 0.99 | ~460 |
| 0.999 | ~4600 |

먼 미래를 볼수록 느리다. 정보가 먼 미래에서 지금까지 번져 오는 데 그만큼 걸린다. γ = 1이면 수축이 보장되지 않는다(반드시 종료되는 에피소드형처럼 별도 조건 필요).

### 이후와의 연결

| 섹션 | 역할 |
|---|---|
| 03 DP | value iteration = T\* 반복, policy evaluation = T^π 반복 |
| 05 TD, Q-learning | 연산자를 **샘플 하나로 근사**한 버전 + 01의 증분 업데이트 |
| 06 함수 근사 | "연산자 → 근사 공간으로 투영"에서 **수축성이 깨질 수 있다** → deadly triad |

## 10. 🤖 로봇에서 보면: 연속 공간, POMDP, 제어 주기와 γ

### 연속 상태·행동
수식은 그대로고 합이 적분이 된다.

$$V^*(s) = \max_{a \in \mathbb R^m} \Big[R(s,a) + \gamma \int p(s'|s,a)\, V^*(s')\, ds'\Big]$$

| 문제 | 이유 | 해결 |
|---|---|---|
| 표로 저장 불가 | 7축 팔 = 14차원, 축당 10칸이면 10¹⁴칸 (차원의 저주) | 함수 근사 (06) |
| 같은 상태 재방문 없음 | 연속 공간 | 일반화 (06) |
| max_a 불가 | 행동이 무한 | actor가 max 대신 (08, 09) |
| 정책이 분포를 출력 | 확률적 정책 | 가우시안 + tanh squashing (08) |

### POMDP

$$\text{POMDP} = (\mathcal S, \mathcal A, p, R, \gamma, \Omega, O(o \mid s))$$

에이전트는 s 대신 o ~ O(o|s)만 본다. 예: 손이 물체를 가림, 센서 노이즈, 질량·마찰을 모름, 미끄러짐 같은 접촉 상태.

**belief state**: 지금까지 본 것을 종합한 "진짜 상태는 어디쯤일까"의 분포.

$$b'(s') \propto O(o \mid s') \sum_s p(s' \mid s, a)\, b(s)$$

- 예측(동역학) → 보정(관측) 구조. **Kalman filter**가 선형·가우시안 경우의 정확한 해다.
- b를 상태로 보면 다시 MDP(belief MDP). 하지만 분포 자체가 상태라 정확히 풀긴 어렵다.
- 기억 없는 정책이면 확률적 정책이 결정적 정책보다 나을 수 있다 (MDP에서는 성립 안 하던 일).

| 실전 해법 | 아이디어 |
|---|---|
| history 쌓기 | 최근 관측 k개 + 이전 행동 (DQN 프레임 4장) |
| 순환 신경망 | LSTM/GRU/Transformer = 학습된 belief |
| 추정기 + 정책 | EKF 추정치를 정책에 입력 |
| asymmetric actor-critic / teacher–student | 시뮬에서 critic(teacher)은 진짜 상태, actor(student)는 관측만. sim-to-real 보행의 표준 (09) |

### 제어 주기와 γ

$$H_{\text{초}} \approx \frac{\Delta t}{1 - \gamma}, \qquad \gamma_{\text{new}} = \gamma_{\text{old}}^{\ \Delta t_{\text{new}} / \Delta t_{\text{old}}}$$

| 제어 주기 | γ | 시야 |
|---|---|---|
| 50 Hz | 0.99 | 2초 |
| 200 Hz | 0.99 | 0.5초 ⚠️ |
| 200 Hz | 0.9975 | 2초 ✅ |

- 주기를 바꾸면 γ도 바꿔야 한다.
- 빠른 주기는 credit assignment가 어려워지고 수렴도 느려진다(∝ 1/(1−γ)).
- 실전은 **계층 구조**: RL 정책 ~50Hz로 관절 목표값 → PD 제어기 ~1kHz로 토크. frame skip도 같은 발상.

## 11. 전체 정리 & 다음 섹션 연결

```
Markov chain ──(+R, γ)──→ MRP ──(+A, π)──→ MDP ──(max)──→ 최적성
  P, μ*                 V = (I−γP)⁻¹R     V^π, Q^π          V*, Q*, π* = argmax Q*
  Markov 성질            선형, 한 번에 풀림   정책 고정 = MRP     비선형 → 반복
                                                               ↓
                                  contraction: 유일한 답으로 수렴 (γᵏ)
                                                               ↓
                                  🤖 연속(→06, 08), POMDP(→belief), Δt와 γ
```

| 방정식 | 형태 | 푸는 법 | 이후 알고리즘 |
|---|---|---|---|
| Bellman expectation | 선형 (평균) | 역행렬 / T^π 반복 | policy evaluation (03), TD (05) |
| Bellman optimality | 비선형 (max) | T\* 반복 | value iteration (03), Q-learning (05), DQN (07) |

**꼭 가져갈 세 가지**
1. **Bellman 방정식 = 지금 가치 = 보상 + γ × 다음 가치.** 먼 미래를 현재 상태의 점수로 압축해서, 긴 계획을 한 스텝 선택으로 바꾼다.
2. **정책을 고정하면 MDP는 MRP(선형)**, 최선을 고르면 max가 들어가 비선형이 된다. 그래도 둘 다 γ-수축이라 반복하면 유일한 답으로 간다.
3. **Markov는 상태 표현의 성질**이다. 상태 설계, 보상 설계, γ와 제어 주기 선택이 모두 문제 정의의 일부다.

→ **03 동적 계획법**: p를 안다고 가정하고 policy iteration / value iteration으로 실제로 풀어본다. Bellman ↔ HJB, LQR.

## 12. 확인 문제

**문제 1.** 02-1 체인에서 충전→작업 확률을 0.5에서 0.1로 바꾸면 μ\*와 |λ₂|는?
> μ\* = (½, ½), λ₂ = 0.8. 한 상태에 오래 머무는 "끈적한" 체인이 되어 섞이는 속도가 느려진다. 짧은 궤적으로 장기 평균을 추정하면 오차가 크다.

**문제 2.** 자율주행차의 상태를 "현재 카메라 이미지 한 장"으로 잡으면 Markov인가?
> 아니다. 속도, 가려진 물체를 알 수 없다. 프레임 여러 장, 속도·IMU, RNN 같은 belief 표현을 추가해야 한다.

**문제 3.** 5장 예에서 γ = 0이면 V_W, V_C는? 들어 올리기에서 "성공 +1, 나머지 0, γ = 1"이면 무슨 문제가 생기나?
> V = R = (1, 0). 충전이 미래 작업으로 이어진다는 가치가 사라진다. 두 번째는 언제 성공하든 G = 1이라 빨리 할 이유가 없다. γ < 1이면 k스텝 뒤 성공의 가치가 γᵏ라 빨리 끝낼수록 좋다(또는 스텝당 시간 패널티).

**문제 4.** 정책이 결정적이면 V^π(s)와 Q^π(s, π(s))의 관계는? V만 학습하면 행동을 고르는 데 무엇이 더 필요한가?
> 같다. V만 있으면 환경 모델 p(s'|s,a)가 필요하다(계획: 03, 10). 모델이 없으면 Q를 직접 배운다(05, 07).

**문제 5.** 복도에서 γ = 1이면 V\*와 최적 정책은? Q\*(s, a₁) = Q\*(s, a₂)면 최적 정책은 하나뿐인가?
> 모든 칸에서 V\* = 1. 헤매다 도착하는 정책도 최적이 되어 빨리 갈 이유가 사라진다. 두 번째: 최적 정책은 여러 개(섞는 확률적 정책도 최적)지만 V\*는 유일하다(9장).

**문제 6.** 9장 value iteration에서 V₀ = 0이 정확히 4번 만에 끝난 이유는?
> 전이가 결정적이고 경로 길이가 최대 4로 유한하다. k번 반복 = k스텝 앞까지의 최적값이 정확히 계산된다. 확률적 전이나 순환이 있으면 무한히 근사해 간다.

**문제 7.** 100Hz, γ = 0.98로 잘 동작하던 정책을 25Hz로 낮추려면 γ는? 질량을 모르는 들어 올리기에서 현재 관측만 보는 정책과 1초 history를 보는 정책 중 어느 쪽이 유리한가?
> γ = 0.98⁴ ≈ 0.922, 시야는 둘 다 0.5초. history 쪽: 같은 힘에 물체가 얼마나 올라오는지로 질량을 추론할 수 있다(belief 역할). meta-RL, RMA의 아이디어.

## 13. 질문 & 답변

### Q1. (Markov chain) 전이확률이 시간과 무관하다는 건 어제와 오늘의 전이확률이 같다는 의미야?
- 맞다. P(S_{t+1}=s'|S_t=s)가 t에 의존하지 않는다. 같은 상태에서 출발하면 언제든 같은 규칙으로 다음 상태가 뽑힌다.
- 주의: "상태 분포 μ_t가 매일 같다"는 뜻이 아니다. 규칙 P가 고정이고 분포는 계속 변할 수 있다.

### Q2. (Markov chain) 이건 이상적인 가정 같은데, 실제 물리세계는 안 그럴 것 같다. 그걸 반영한 모델도 있어?
- 있다. 시간 비균질 체인(P_t), nonstationary MDP, semi-Markov, 연속시간 Markov chain, POMDP, hidden-parameter MDP / meta-RL.
- 핵심 관점: 비정상성은 대개 **상태에 빠진 변수**다. 모터 온도, 배터리, 마모를 상태에 넣으면 다시 시간 균질이 된다. 시간 t를 상태에 넣어도 된다.
- 🤖 실전에서는 정확한 모델 대신 domain randomization(여러 P에 강건한 정책), 온라인 적응, 관측 history 입력으로 대응한다.

### Q3. (Markov chain) 분포의 시간 발전이라는 건 어떤 Markov chain이든 다 수렴한다는 뜻이야? 수렴 조건이 있다는 뜻이야?
- 시간 발전은 μ_{t+1} = μ_tP로 분포가 매 스텝 바뀐다는 사실일 뿐이다. 수렴은 별도 조건이 필요하다.
- 유한 상태: irreducible + aperiodic이면 어떤 μ₀에서든 유일한 μ\*로 수렴한다.
- 반례 ① 주기적 P = [[0,1],[1,0]]: 영원히 진동. ② 흡수 상태 두 개: 수렴은 하지만 시작점에 따라 도착지가 다르다.

### Q4. (정상분포) 정상분포는 한 번 더 전이해도 안 변하니까, 빠져나가는 흐름과 들어오는 흐름이 같다는 거지?
- 맞다(global balance). 모든 상태에서 들어오는 흐름 총합 = 나가는 흐름 총합. μ\* = μ\*P를 상태별로 풀어 쓴 것이다.
- 쌍마다 같을 필요는 없다(detailed balance는 더 강한 조건). 1→2→3→1 순환 체인도 정상분포는 균등하다.

### Q5. (Markov 성질) "Markov는 상태 표현의 성질" 설명이 어렵다. 더 쉽게 설명해줘.
- 던진 공의 사진 한 장(위치만)으로는 올라가는지 내려가는지 모른다. 이전 사진이 도움이 된다 → Markov가 아니다.
- (위치, 속도)로 잡으면 이전 사진이 줄 정보가 없다 → Markov다.
- 같은 세상인데 상태 정의에 따라 Markov이기도, 아니기도 하다. 그래서 상태 설계가 RL 문제 설정의 일부다. 정보가 부족하면 과거 관측을 붙인다(프레임 스택, RNN).

### Q6. (MDP 미리보기) RL은 policy를 만드는 학습인데, 그 policy가 결국 Markov chain의 상태와 전이확률을 찾는 거야? 보상이 수렴한다는 건 체인 구조가 더 이상 안 변한다는 뜻이야?
- 절반 맞다. 상태와 동역학 p(s'|s,a)는 환경이 정한다(model-based RL은 이를 추정한다).
- 정책을 정하면 P^π(s'|s) = Σ_a π(a|s)p(s'|s,a)라는 체인이 생긴다. **정책 선택 = 만들어질 체인을 고르는 것.** 좋은 정책은 보상 높은 상태에 오래 머무는 체인을 만든다.
- 수렴은 두 가지: ① 학습의 수렴(정책 고정 → 체인 고정 → 곡선 평평), ② 고정 정책 아래 분포의 수렴(μ_t → d^π). 곡선이 평평해도 최적 보장은 없다.

### Q7. (에피소드) 에피소드의 정확한 정의가 뭐야?
- 초기 상태 S₀ ~ μ₀에서 종료(흡수) 상태에 도달할 때(시각 T, 확률변수)까지의 궤적 하나. 끝나면 리셋한다.
- 종료가 있으면 episodic task, 끝이 없으면 continuing task(γ < 1).
- 함정: 시간 제한으로 끊긴 것(truncation)은 종료가 아니다. gymnasium의 terminated/truncated 구분. 끊긴 경우 V(s_T)를 0으로 두면 안 된다.

### Q8. (bandit) 그러면 bandit은 상태가 하나고, 확률에 따라 다시 자기 자신으로 돌아오는 구조야?
- 상태 1개는 맞다. 다만 **확률 1로 항상** 자기 자신으로 돌아온다(P = [1]). 전이에는 무작위성이 없다.
- 무작위성은 보상에만 있다. 행동은 보상만 바꾸고 다음 상태는 못 바꾼다. "한 번 당기기 = 길이 1의 에피소드"로 볼 수도 있다.

### Q9. (에피소드) 한 에피소드는 태스크 한 번을 끝내고 완료(흡수) 상태로 오면 끝나는 거야? 로봇이 물체를 들어 올릴 때, 올린 높이가 안 바뀌면 흡수 상태라 끝나는 거고?
- 큰 그림은 맞다: 리셋 → 시도 → 종료 조건 = 에피소드 1개.
- 수정: "높이가 안 바뀜"은 종료가 아니다. 들고 가만히 있는 것도 여전히 움직일 수 있는 평범한 상태다. 종료는 설계자가 정한다: 성공(z ≥ 30cm), 실패(떨어뜨림, 충돌).
- 흡수 상태는 수학적 장치(종료 후 자기 자신으로만 가고 보상 0). 시간 제한은 truncation.
- 함정: 매 스텝 z 보상 + 성공 시 종료면, 목표 바로 아래에서 떠 있는 게 이득일 수 있다(reward hacking).

### Q10. (보상 설계) reward shaping과 reward hacking이 뭐야?
- **shaping**: sparse 보상만으로는 학습이 안 되니 중간 보상(접근, 파지, 높이)을 더해 길을 안내하는 것. 목표와 어긋나면 최적 정책이 바뀐다. 안전한 형태는 potential-based F = γΦ(s') − Φ(s) (정책 순위 불변).
- **hacking**: 에이전트는 의도가 아니라 숫자를 최대화한다. 예: 29cm에서 떠 있기, 물체 세우기, CoastRunners 보트 빙빙 돌기, 시뮬 물리 버그, RLHF 아부.
- 대응: 보상은 단순하게, 종료 조건 명확히, 학습된 행동은 영상으로 확인.

### Q11. (할인율) 할인율은 얼마나 먼 미래(스텝)까지 고려할지 정하는 거야?
- 맞다. 다만 딱 잘리지 않고 γᵏ로 부드럽게 줄어든다. γ = 0.9면 10스텝 뒤 0.35, 22스텝 뒤 0.1. 대략 1/(1−γ)스텝 앞까지 본다.
- 반감기 = ln 0.5 / ln γ (0.9 → 6.6스텝, 0.99 → 69스텝).

### Q12. (큰 흐름) 미래까지 얻는 보상이 지금 상태에 반영되는 거야? 정책을 바꾸는 거야? 어떤 행동을 할지 정하는 거야? 큰 예시로 설명해줘.
- 셋 다 맞고 순서가 있다. ① 평가: 미래 보상을 끌어와 V(s)로(Bellman) ② 선택: 행동마다 갈 상태의 점수 비교(Q) ③ 개선: 그대로 정책 수정 → 다시 ① (GPI).
- 복도 예: G 도착 +1, γ = 0.9, "항상 오른쪽" → V = 0.729, 0.81, 0.9, 1. 보상이 뒤로 번져 오르막 지형이 생기고, S1에서 왼쪽(0.729) vs 오른쪽(0.9) → 오른쪽.
- γ = 0.5면 0.125, 0.25, 0.5, 1 → 멀리서는 목표가 거의 안 느껴진다.
- 🤖 로봇은 "30cm 도달 +10"이라는 미래를 V(s)로 압축해 두고, 매 순간 점수가 높아지는 쪽만 고른다.

### Q13. (보상 설계) 30cm 도달 시 점수를 무한대로 주거나, 높이에 따라 exponential로 주면 어때?
- 무한대: 성공 확률이 0만 아니면 모든 정책의 V = ∞ → 비교 불가. 수치적으로 inf/NaN.
- 아주 큰 유한값: 보상 전체를 c배 해도 최적 정책은 그대로. 중요한 건 비율. 너무 크면 shaping이 묻히고 분산이 커져 불안정 → reward scaling, clipping.
- exp(z): 바닥 근처 신호가 약해 초반 학습이 느리고, 꼭대기 근처에서 떠 있기 hacking이 심해진다.
- 좋은 exponential: 오차 커널 exp(−‖오차‖²/σ) ∈ (0, 1]. 보행 로봇 속도 추종 보상 등에서 표준.
- 떠 있기 방지: 성공 시 종료 + 보너스, 스텝당 시간 패널티, potential-based shaping.

### Q14. (용어) PPO랑 POMDP가 뭐야?
- **PPO** (Proximal Policy Optimization, 2017): policy gradient 계열. advantage가 양수인 행동의 확률은 올리고 음수면 내리되, 확률비를 [1−ε, 1+ε]로 clip해서 한 번에 너무 크게 안 바뀌게 한다. 로봇 보행, RLHF의 표준 (09).
- **POMDP**: 진짜 상태 대신 관측 o ~ O(o|s)만 보는 MDP. 카메라 가림, 센서 노이즈, 안 보이는 질량·마찰. belief state b(s)로 바꾸면 다시 MDP. 실전은 history, RNN.

### Q15. (최적성) "Q\*만 알면 다 안다"고 했는데, Q와 Q\*(큐프라임?)가 각각 뭘 의미해? 큰 예시로.
- 표기: Q\*는 "큐 스타" = 최적. Q′(프라임)은 다음 상태의 Q나 target network를 가리키는 별개 표기.
- Q^π(s,a): 지금 a를 하고 이후 **현재 습관**대로. Q\*(s,a): 지금 a를 하고 이후 **최선**으로.
- 출근길: 습관 π는 갈림길 B에서 늘 시내(20분). A에서 고속도로(10분) vs 국도(25분). Q^π(고속도로) = −30 < Q^π(국도) = −25로 국도가 나아 보이지만, Q\*(고속도로) = −18이 정답.
- Q^π는 이후 습관 때문에 첫 선택까지 오판하게 할 수 있다. Q\*는 이후 최선을 전제하므로 argmax만 하면 된다.
- B의 습관을 Q^π로 고치고(우회 −8 > 시내 −20) 재평가하면 A의 판단도 바뀐다 → Q\*.

### Q16. (최적성) 그러니까 Q와 Q\* 기호의 의미는 "보통의 점수" vs "최적 행동을 할 때의 점수" 차이야?
- 맞다. 셋으로 구분하면 정확하다: Q^π = 정책 π를 따를 때의 진짜 점수, Q\* = 최적으로 행동할 때의 진짜 점수(= Q^{π\*}), Q = 알고리즘의 추정치(표, 신경망).
- 항상 Q^π ≤ Q\*. 논문/코드에 위첨자 없는 Q는 대개 "지금 학습 중인 추정치"다. 01의 Q(a)도 q\*(a)의 추정치였다.

## 14. 헷갈렸던 개념 체크리스트

- [x] **시간 균질**: 규칙 P가 고정. 분포 μ_t는 변해도 된다 (Q1)
- [x] **비정상성 = 빠진 상태 변수**: 온도, 마모, 시간을 상태에 넣으면 다시 균질 (Q2)
- [x] **수렴은 조건부**: irreducible + aperiodic. 주기적이면 진동, 가약이면 시작점 의존 (Q3)
- [x] **정상분포 = 흐름 균형**: 들어오는 흐름 = 나가는 흐름 (Q4)
- [x] **Markov는 상태 표현의 성질**: 공 사진 한 장 vs (위치, 속도) (Q5)
- [x] **정책 선택 = 체인 선택**: 동역학은 환경, 정책은 내가. P^π = Σ π p (Q6)
- [x] **에피소드와 종료**: 종료는 설계자가 정의. truncation ≠ termination. 높이가 안 변한다고 종료가 아님 (Q7, Q9)
- [x] **bandit 전이는 확률 1로 제자리**: 무작위성은 보상에만 (Q8)
- [x] **shaping vs hacking**: 길 안내 vs 숫자의 허점 파기. potential-based면 안전 (Q10)
- [x] **γ = 부드러운 시야**: 가중치 γᵏ, 시야 ≈ 1/(1−γ) (Q11)
- [x] **평가 → 선택 → 개선**: 미래 보상이 V로 번지고, Q로 고르고, 정책을 바꾼다 (Q12)
- [x] **보상 크기보다 비율과 모양**: ∞ 불가, 유계 커널 exp(−오차²) (Q13)
- [x] **Q^π / Q\* / Q**: 습관의 진짜 점수 / 최선의 진짜 점수 / 내 추정치. Q′는 별개 (Q15, Q16)
