Gemini 4 Argon 시뮬레이션에서 배운 동작을 현실로 옮기는 법

Gemini 계열 로봇 제어 모델 Argon의 시뮬레이션 벤치마크 성능과 Real-to-Sim·시스템 식별을 통한 실전 전이, 클라우드 추론 기반 하이브리드 제어를 다룬다.

핵심 요지

  • Gemini 계열의 ‘아르곤(Argon)‘은 LLM 기반 로봇 제어 벤치마크에서 오퍼스(21개), 아스트라(24개)보다 78개 태스크 중 36개를 성공하는 최상위 성능을 보였고, 실제 환경 제로샷 제어와 사람의 피드백을 반영한 자가 개선 시연도 제시했다[1][2][3].
  • Real-to-Sim 자동화와 시스템 식별(게인·댐핑·마찰 계수 등 물성값 추정)은 로봇 연구의 병목으로 꼽히며, AI가 이 과정을 수행하면 연구 가속화가 기대된다[4][5].
  • LLM이 엔드이펙터 좌표나 관절값을 직접 출력하는 방식과 클라우드 인퍼런스는 ‘다크 팩토리’처럼 단일 서버가 공장 로봇을 제어하는 가능성을 제시한다[6][7][8][9].

요약

LLM 기반 로봇 제어의 기술적 전환

과거 RT-1, RT-2, OpenVLA 등은 디스크리트 액션 토큰으로 파인튜닝해도 성능이 낮았지만, 현재는 LLM이 텍스트 토큰 형태로 좌표 값을 출력하고 IK를 풀어 로봇을 제어하는 방식이 유효하다[10][11]. 아르곤은 엔드이펙터 좌표뿐 아니라 로봇 몸체별 관절 값(Q-pose)도 직접 출력할 수 있다[12]. 시뮬레이터의 78개 고난도 태스크에서는 오퍼스 21개, 아스트라 24개, 아르곤 36개 성공으로 아르곤이 최상위였다[13].

로보커브 벤치마크에서는 아르곤의 성능이 가장 높고 가격은 싼 편이지만 속도는 느린 편이며, 아스트라는 빠르지만 비싸고 오퍼스는 중간 포지션이다[14]. 실제 환경에서는 시각 좌표만 제공하면 제로샷으로 로봇을 제어할 수 있고, Spot은 캔을 쓰레기통에 넣는 이동·밸런싱 태스크를 스스로 수행했다[15][16]. YAM 같은 특정 로봇 모델은 학습 데이터에 포함되어 있어 더 정확한 조종이 가능할 수 있고, 처음 보는 환경에서는 최신 LLM이 스펙만 주면 관절값을 조절해 물체를 잡는 일반화도 보인다[17][18].

Real-to-Sim 자동화와 자가 개선 루프

Real-to-Sim에서는 실제 텔레오퍼레이션 영상을 바탕으로 시뮬레이션을 재현한 뒤, 게인·댐핑·마찰 계수 등 물성값을 맞춰야 한다[19][20]. 이 물성값 맞추기는 시스템 식별이라 불리며 로봇 연구자 중에서도 가장 힘든 노가다 과정으로 꼽힌다[21]. 시뮬레이션과 실제 움직임의 차이를 반복 확인하며 값을 바꾸는 과정을 AI가 수행할 수 있어, 로봇 연구 가속화가 기대된다[22][23].

민속놀이 던지기 데모에서는 사람 동작을 보여준 뒤 Real-to-Sim을 구축하고, AI가 마찰 계수 등을 계산해 실제 환경에서 루프를 돌리며 학습했다[24][25]. AI는 허벅지를 치는 실수를 반복했으나 사람의 피드백(‘허벅지 친다’)을 듣고 자가 개선하는 과정이 보였고, 몇 바퀴 루프를 돌린 뒤 7번 연속 성공했다[26][27]. Real-to-Sim이 쉬워지면 변형 물체 처리가 가능해질 수 있고, 자가 루프가 형성되면 유체 시뮬레이션 등 어려운 물리 문제도 해결할 가능성이 열린다[28][29].

클라우드 추론과 하이브리드 제어 구조

LLM 기반 로봇 제어는 엣지 디바이스가 아니라 클라우드 인퍼런스를 통해 가능해질 수 있으며, 이는 물리적 지능이 반드시 로컬에서 처리되어야 한다는 기존 관념을 뒤집는다[30]. 자율주행이 테슬라 하드웨어 등 엣지에서 처리되는 것과 달리, LLM 기반 로봇 제어는 클라우드에서 가능할 수 있고 향후 자율주행에도 적용될 수 있다[31]. ‘다크 팩토리’ 개념에서는 단일 클라우드 인퍼런스 서버가 공장 전체의 로봇을 컨트롤하면 더 완벽한 제어가 가능하다[32].

Dream-1 같은 WAM은 움직임 중 손이 떨리는 현상이 보였고, LLM 계열 모델은 나머지 손이 아예 움직이지 않는 경향이 있다[33]. Dream-1은 속도가 빠르지만, LLM 기반 구조는 호출과 움직임이 반복되어 느려서 정교한 조작이나 빠른 반응성이 필요한 태스크에는 현재 한계가 있다[34]. LLM의 핵심 능력은 처음 보는 물체에 대해 스스로 추론하여 조작하는 것이다[35]. WAM 출력을 Argon에 전달해 보정하거나 VLA로 드리프트를 제어하는 등 두 방식을 결합하는 연구가 진행 중이며, 하이브리드 구조가 향후 등장할 것으로 예상된다[36][37][38].

이질적 센서 모달리티 통합

비전·텍스트 외의 촉각 등 센서 값은 종류가 다양하고 디멘션·개수·외형이 달라 통합 처리가 어렵다[39][40]. A사 비전 기반 tactile sensor와 B사 압력 기반 tactile sensor처럼 하드웨어가 이질적이더라도, 특성 설명 매뉴얼과 few-shot 샘플을 LLM에 주면 해당 작업을 잘 수행할 수 있다[41]. 따라서 센서 신호를 에이전트가 해석하는 방법만 알려주면 비전/텍스트 외 모달리티도 처리 가능할 것으로 예상된다[42].

활용 관점

아래는 영상 내용을 바탕으로 한 활용 관점 분석(추론)이며, 영상에서 직접 말한 내용이 아니다.

VLA (Vision-Language-Action)

  • 액션 표현 방식 재설계: 엔드이펙터 6자유도, 관절값(Q-pose), 액션 청크(jchunk) 등 출력 방식을 태스크별로 비교해 보고[43][44][45], 서랍 열기 등 복잡한 접촉 동역학에는 low-level policy를, 단순 조작에는 LLM 추론을 우선하는 하이브리드 아키텍처를 설계할 수 있다[46][47].
  • 데이터 생성 파이프라인: 아르곤 같은 느린 LLM을 오프라인에서 실행해 시뮬레이션 내 VLA 학습용 데이터셋을 미리 만들어 빠른 모델 학습에 활용할 수 있다[48][49]. 다만 텔레오퍼레이션 데이터 없이 원하는 수준의 작업이 가능할지는 아직 의문이므로, 초기에는 텔레오퍼레이션 보조 데이터로 검증하는 단계부터 시작해 볼 수 있다[50][51].

World model / World action model

  • Sim-to-Real Gap 축소: Real-to-Sim에서 게인·댐핑·마찰 계수 등 물성값을 AI가 반복 추정하는 시스템 식별 모듈을 구축하고[52][53], 시뮬레이션 결과와 실제 움직임의 차이를 확인하는 워크플로우를 적용해 볼 수 있다[54].
  • 정책 보정 도구 활용: Dream-1 같은 WAM의 빠른 추론 결과를 LLM에 전달해 보정하거나, VLA로 드리프트를 제어하는 방식을 프로토타입으로 구현해 볼 수 있다[55]. 스펙ulative decoding처럼 LLM과 VLA를 조합해 로봇 컨트롤 효율을 높이는 실험도 가능하다[56].

로보틱스 일반

  • 클라우드 기반 군집 제어: 단일 클라우드 인퍼런스 서버가 공장 내 여러 로봇의 태스크를 분배하는 ‘다크 팩토리’ 프로토타입을 구축하고, LLM 호출·움직임 반복으로 인한 지연과 제어 궤적 품질을 비교해 볼 수 있다[57][58][59].
  • 이질적 센서 통합: 비전 기반·압력 기반 tactile sensor처럼 디멘션·개수·외형이 다른 하드웨어의 매뉴얼과 few-shot 샘플을 프롬프트로 주입하는 인터페이스를 정의하고, 에이전트가 센서 값을 해석하는 성공/실패 사례를 축적해 볼 수 있다[60][61].

더 볼 것

  • 벤치마크 점수의 실질적 의미: BenchCAD나 Artificial Analysis Index 점수가 실제 공간 이해력이나 로봇 조작 능력과 얼마나 상관관계가 있는지, 특히 벤치 공개 이후 모델일수록 유리해지는 ‘벤치 맥싱’ 영향을 어떻게 보정해야 하는지 추가 검증이 필요하다[62][63].
  • 촉각 센서 통합의 구체적 구현: LLM이 촉각 데이터를 해석한다는 주장은 매뉴얼 제공과 few-shot 학습에 기반하고 있으나[64], 실시간 제어 주기에서 이질적인 센서 데이터 스트림을 처리하는 지연·호환성 문제는 영상에서 충분히 다루지 않았다.
  • RL 환경의 Verifiability: 아르곤의 성능 향상이 프리트레이닝인지 RL인지 명확하지 않고[65], RL을 위해서는 verifiable한 자기 개선 환경 구축이 핵심 병목이라고 언급되었다[66]. 자체 시뮬레이터 보유가 유리하다는 언급은 있으나[67], 이를 실제로 구현하는 구체적인 방법론이나 성공 사례는 제시되지 않았다.
