DexFormer: Cross-Embodied Dexterous Manipulation via History-Conditioned Transformer

DexFormer는 과거 관측을 조건으로 하는 트랜스포머 정책을 사용해, 절차적으로 생성한 다양한 손 형태에서 학습된 단일 정책이 새로운 민첩한 손에 제로샷으로 전이되는 크로스-엠보디먼트 조작 방법을 제시한다.

TL;DR

DexFormer는 morphology identifier나 per-embodiment decoder 없이 history-conditioned Transformer로 이질적인 로봇 손 제어를 학습한다. 절차적으로 생성한 300개 손 변형체에서 학습해 LEAP, Allegro, Rapid canonical hand로 zero-shot transfer를 검증한다. 평균 성공률은 77.50%로 LSTM 58.72%, GRU 44.29%보다 높고, 실세계 LEAP에서도 증류 정책으로 그랩을 수행한다.

문제 정의

이 논문은 서로 다른 자유도(DoF), link length, mass, inertia를 가진 robot hand embodiment eee가 관측되지 않는 상황에서 하나의 policy πθ\pi_\thetaπθ​로 dexterous grasping 제어를 수행하는 문제를 다룬다. 각 episode마다 object o∈Oo \in \mathcal{O}o∈O와 embodiment e∈Ee \in \mathcal{E}e∈E를 샘플링하며, 정책은 morphology-agnostic으로 동작해야 한다. 목표는 다음 RL objective이다.

max⁡θEe∼p(E),o∼p(O),τ∼πθ[∑t=0TγtR(ot,at)]\max _ {\theta} \mathbb {E} _ {e \sim p (\mathcal {E}), o \sim p (\mathcal {O}), \tau \sim \pi_ {\theta}} \left[ \sum_ {t = 0} ^ {T} \gamma^ {t} R (o _ {t}, a _ {t}) \right]θmax​Ee∼p(E),o∼p(O),τ∼πθ​​[t=0∑T​γtR(ot​,at​)]

여기서 embodiment eee는 정책 입력에 명시적으로 제공되지 않는다. 따라서 정책은 손의 형태와 동역학을 별도 identifier나 embodiment별 decoder head가 아니라 학습된 표현에서 처리해야 한다.

핵심 아이디어

핵심 직관은 손의 형태와 동역학을 별도 입력으로 주지 않고, 최근 관측-행동 히스토리에서 정책이 스스로 추론하게 하는 것이다. 같은 해부학적 기능을 가진 관절을 canonical index로 정렬하면, 서로 다른 DoF를 가진 손도 하나의 액션 스페이스에 매핑된다. 이후 Transformer가 causal attention으로 과거 토큰을 읽고 현재 행동 분포를 생성한다. 이 구조 덕분에 학습된 정책은 canonical hand뿐 아니라 unseen morphology variants에도 zero-shot으로 적용될 수 있다.

History-conditioned Transformer

정책은 고정 길이 history window를 입력으로 받는다.

학습 및 배포

학습은 Isaac Lab에서 수행되며, 주요 결과는 4096 parallel environments와 40k episodes 설정에서 보고된다. Automatic Domain Randomization(ADR)을 사용해 정책 성능이 향상됨에 따라 노이즈 수준을 점진적으로 증가시킨다. 랜덤화 대상은 joint positions, joint velocities, fingertip states, point-cloud observations, gravity이다. 분산 학습에서는 각 GPU가 local rollout과 forward pass를 계산하고, backpropagation 단계에서 all-reduce로 gradients를 평균화해 모든 device의 weights를 동기화한다.

실세계 배포에는 offline distillation을 사용한다. Expert demonstration 2000 episodes를 기록하고, observation dimension 158을 가진 student MLP를 학습시킨다. Student learning rate는 0.001이고 optimizer는 Adam이다. 실세계 제어에서는 arm joint-space controller가 1000 Hz, policy evaluation이 10 Hz로 동작한다.

History length ablation에서는 1-step 대비 5-step이 평균적으로 더 좋았다. 전체 평균은 1-step 73.00%, 5-step 77.50%였다. 다만 RAPID에서는 5-step이 1-step보다 낮아지는 경우가 관찰됐다. canonical 기준 RAPID는 77.59%에서 71.69%로, variants 기준은 82.75%에서 77.09%로 감소했다.

Training embodiment diversity ablation에서는 25k episodes 설정에서 100 hands가 가장 좋았다. 전체 평균은 25 hands 80.18%, 50 hands 79.34%, 100 hands 84.09%였다. 이는 morphology randomization의 다양성이 일반화에 중요함을 보여준다.

Parallel environments scalability ablation에서는 30k episodes, 3 GPU 설정에서 parallel environment 수를 증가시켰다. canonical 평균은 1024/GPU 69.24%, 2048/GPU 74.41%, 4096/GPU 78.07%였고, variants 평균은 70.84%, 75.58%, 81.21%였다. 다만 RAPID canonical은 4096/GPU에서 74.34%에서 69.72%로 감소하는 불안정성이 관찰됐다.

Joint locking 실험에서는 distal flexion 관절과 low-leverage MCP abduction 관절 잠금은 상대적으로 경미한 성능 저하를 보였다. 반면 basal flexion과 thumb CMC 잠금은 현저한 성능 저하를 유발했다. 모든 impaired variants는 canonical zero-shot 성능보다 낮거나 동등했으며, 4-second execution window가 2-second window보다 높은 성공률을 보여 일부 보상 효과가 있었다.

실세계 평가에서는 Franka arm과 LEAP hand를 사용해 증류된 DexFormer 정책을 배포했다. object별 success rate와 평균 실행 시간은 다음과 같다.

한계

  • 물체 기하학과 질량 다양성이 부족해 object-level generalization이 제한된다.
  • High-DoF embodiment인 RAPID에서 zero-shot 성능 저하가 관찰된다.
  • Isaac Lab 제약으로 인해 kinematic topology가 다른 embodiments는 별도 GPU에서 학습해야 하며, mixed buffer나 centralized gradient accumulation을 지원하지 않는다.

비판적 검토

강점

  • 형태 식별자 없이 히스토리만으로 크로스-엠보디먼트(cross-embodiment) 제로샷 전이(zero-shot transfer)를 시도한다 — DexFormer는 명시적인 morphology identifier(모폴로지 식별자)나 per-embodiment decoder head를 쓰지 않고, 과거 관측-행동 쌍을 조건으로 하는 히스토리-조건부 트랜스포머(history-conditioned Transformer)로 morphology와 dynamics를 실시간 추론한다는 점에서 기존 single-embodiment policy와 차별화된다 (근거: 1절, Fig. 3).
  • 베이스라인(baseline) 비교와 구성 요소 아블레이션(ablation)이 비교적 체계적이다 — LSTM/GRU 베이스라인과 함께 history length, training embodiment diversity, parallel environment 규모에 대한 결과를 표로 제시하고, joint locking robustness까지 검증한다 (근거: Table II–V, Fig. 7).
  • 시뮬레이션 제로샷 전이와 실세계 증류 평가를 모두 포함한다 — 절차적으로 생성된 morphology variants에서 unseen variants 평가뿐 아니라, Franka+LEAP 실세계 설정에서 offline distillation 후 물체별 성공률과 DoF 감소 변형체까지 정성/정량으로 보여준다 (근거: 4절, 6절, 부록 B, Table VI, Fig. 13–15).
  • 공유 액션 스페이스와 보상 설계가 명시적으로 정의된다 — 기능적 역할 기반 canonical finger action space atFa_t^FatF​와 arm action atAa_t^AatA​를 결합하고, 접근/그랩/자세 추적 보상을 Table I에서 수식으로 정리해 방법의 가독성이 높다 (근거: 2절, Table I, Fig. 2).

약점·의문

  • 크로스-엠보디먼트 관련 최신 베이스라인과 직접 비교가 부족하다 — 제공된 실험에서는 3-layer LSTM/GRU만 비교하고, 참고문헌에 등장하는 GET-Zero, CeDex, D(R,O)Grasp 등 cross-embodiment dexterous grasping 방법과의 정량 비교가 없다 (근거: 4절 Baseline, 참고문헌 [15], [23], [24]) (해석).
  • 성공률의 반복 실행·분산·통계적 유의성이 보고되지 않는다 — Table II–VI은 단일 성공률 수치만 제시하고, seed별 표준편차, confidence interval, paired test 등이 없어 평균 77.50% 같은 우위가 얼마나 안정한지 판단하기 어렵다 (근거: Table II–V, Table VI) (해석).
  • 실세계 성능이 낮고 변형체 결과는 정성적이다 — 실세계 물체별 성공률은 1/5~4/5로 낮으며, DoF 감소 LEAP hand 변형체는 Fig. 15의 정성 이미지만 있고 수치적 성공률/실행 시간이 없다 (근거: 부록 B, Table VI, Fig. 15) (해석).
  • RAPID에서는 history length 증가가 오히려 성능을 떨어뜨린다 — Table III에서 RAPID canonical은 1-step 77.59% 대비 5-step 71.69%, variants도 82.75% 대비 77.09%로 역전된다. 전체 평균은 5-step이 우세하지만, high-DoF embodiment에서는 history conditioning의 이점이 일관되지 않다 (근거: Table III) (해석).
  • 크로스-엠보디먼트 일반화 범위는 같은 kinematic topology family로 제한된다 — 학습 embodiments는 canonical hand의 link length/mass/inertia를 perturb한 morphology variants이며, 한계에서 Isaac Lab 제약으로 topology가 다른 embodiments는 별도 GPU에서 학습한다고 명시한다. 따라서 “cross-embodiment” 주장은 morphology randomization 일반화보다 좁은 범위로 읽힌다 (근거: 2절 Embodiment 생성, 8절 한계) (해석).
  • 보상 설계가 성공 지표와 강하게 결합되어 있어 task 다양성 검증이 제한된다 — rTr^TrT와 rSr^SrS는 목표 자세 추적을 직접 보상하고, 성공도 ∥pgoal−ptarget∥2<0.05\|p^{goal}-p^{target}\|_2<0.05∥pgoal−ptarget∥2​<0.05로 정의되어 reward shaping에 의존하는 성능으로 해석될 수 있다 (근거: 3절, Table I, 4절 성공 지표) (해석).

재현 가능성

  • 제시된 논문 요약에서는 코드/데이터 공개 여부가 확인되지 않으며, Transformer hidden size/head 수, optimizer·learning rate, pmorphp_{\text{morph}}pmorph​ perturbation 범위, automatic domain randomization(자동 도메인 랜덤화, ADR) schedule, reward parameter tuning, 시뮬레이션 pointcloud 생성 파라미터, 실세계 증류 student MLP 구조/loss, wall-clock training time, random seed와 분산 보고가 빠져 있다 (근거: 4절, 6절, 부록 A–B).
