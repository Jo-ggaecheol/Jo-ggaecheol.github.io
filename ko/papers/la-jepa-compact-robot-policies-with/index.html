La-JEPA: Compact Robot Policies with Latent World Modeling

La-JEPA는 사전학습된 V-JEPA 2.1 인코더의 특징 공간에서 정책을 처음부터 학습하는 컴팩트한 월드-액션 모델로, 학습 시 미래 특징 예측을 함께 하고 추론 시에는 동작만 생성한다.

TL;DR

  • 기존 생성형 World-Action Model(WAM)과 Vision-Language-Action(VLA) 정책이 물려받은 큰 Transformer와 높은 추론 비용을 줄이기 위해, V-JEPA 2.1 잠재 특징 위에서 처음부터 학습하는 컴팩트 WAM을 제안한다.
  • World DiT는 관측과 미래 특징으로 잠재 세계 표현을 만들고, Action DiT만 액션 청크를 flow matching으로 디노이징한다. 추론 시 미래 생성은 생략한다.
  • LIBERO-Plus 수정 지시문 기준 La-JEPA L은 88.0%로 NowWAM(86.2%)보다 높고, RoboTwin 2.0 clean-trained B는 평균 60.8%, 실물 정책 호출 지연은 B에서 25.16ms로 Fast-WAM(88.09ms)보다 짧다.

문제 정의

기존 WAM과 VLA 정책들은 영상 생성이나 대규모 언어-시각 모델링을 위해 설계된 Transformer 아키텍처를 로봇 제어에 그대로 상속하는 경우가 많다. 이 구조는 표현력이 크지만, 추론 비용이 높아지고 실제 제어 성능과의 관계가 불분명해질 수 있다. 특히 생성형 백본의 파라미터 대부분이 로봇 액션 예측에 직접 필요하지 않을 수도 있고, 동결된 인코더까지 포함하면 배포 파라미터 수는 빠르게 커진다.

La-JEPA는 이 문제를 “생성형 백본을 그대로 쓰지 않고도, 사전 학습된 잠재 특징 공간에서 처음부터 학습한 컴팩트 정책으로 충분한 제어 성능을 얻을 수 있는가”라는 질문으로 정리한다. 목표는 적은 학습 가능 파라미터로 높은 성공률을 내고, 카메라 변화나 센서 노이즈 같은 분포 이탈에서도 비교적 강건하며, 실물 로봇에서 낮은 지연 시간을 유지하는 것이다.

핵심 아이디어

La-JEPA의 직관은 RGB 영상을 생성하지 않고, V-JEPA 2.1이 만든 관측 특징과 미래 목표 특징을 제어 표현으로 사용하는 것이다. World DiT는 현재 관측 토큰과 미래 특징 토큰을 함께 처리해 잠재 세계 표현을 형성하고, Action DiT는 그 표현에 조건부화되어 액션 청크만 디노이징한다. 액션 토큰은 미래 토큰에 직접 접근하지 못하도록 주의력 마스크를 두어, 학습 중에는 미래 예측 감독으로 World DiT의 표현을 만들고, 추론 시에는 미래 생성 비용을 제거한다. 이 설계는 “미래를 예측하는 세계 모델”과 “액션을 내보내는 정책”을 같은 잠재 공간에서 공유하되, 배포 단계에서는 액션 디코딩만 남기는 구조다.

방법론

관측 인코딩과 조건부 시퀀스

시각 입력은 V-JEPA 2.1 ViT-L 인코더로 처리된 관측 특징 zctxz_{ctx}zctx​와 미래 목표 특징 zfutz_{fut}zfut​를 사용한다. RGB 영상 생성 경로가 없고, 정책 학습은 이 잠재 특징 공간에서 이루어진다. 언어 지시문과 고유감각 상태는 동결된 FLAN-T5-large와 학습 가능한 투영을 거쳐 조건부 시퀀스 zcondz_{cond}zcond​로 변환된다.

공간 토큰 감소는 벤치마크별로 다르다. RoboTwin 2.0에서는 patch grouping을, LIBERO 계열에서는 2x mean pooling을 최종 레시피에 사용한다. 저장된 특징만 사용하는 설정에서는 데모 전체를 사전 인코딩해 두고 학습 중 인코더를 실행하지 않는다. 반면 이미지 증강과 인코더 LoRA를 쓰는 설정에서는 현재 관측 클립은 온라인으로 인코딩하고, 미래 목표는 동결 인코더로 저장된 값을 사용한다.

World DiT와 Action DiT

La-JEPA는 World DiT와 Action DiT의 두 블록을 처음부터 학습한다. World DiT는 관측 토큰과 미래 특징 토큰을 처리하고, Action DiT는 액션 청크를 처리한다. 주의력 마스크에서 액션 토큰은 관측 및 액션 토큰에만 접근할 수 있고, 미래 토큰에는 직접 접근할 수 없다. 따라서 액션 예측은 World DiT가 형성한 잠재 표현을 통해 간접적으로 미래 정보를 이용하게 된다.

이 구조는 학습 시 미래 특징 예측과 액션 예측을 함께 수행하지만, 추론 시에는 미래 토큰 생성을 생략할 수 있게 한다. 모델 크기는 S, B, L 세 가지로 제공되며, 실험 섹션에서 학습 가능 파라미터와 배포 파라미터를 정리한다.

학습 목표

La-JEPA는 flow matching을 학습 목표로 사용한다. 미래 특징과 액션 공간에서 각각 시간 τf\tau_fτf​, τa\tau_aτa​와 노이즈 ϵf\epsilon_fϵf​, ϵa\epsilon_aϵa​를 샘플링하고, 모델은 대응하는 속도 v^f\hat{v}_fv^f​, v^a\hat{v}_av^a​를 예측한다. 손실은 두 속도 예측의 평균 제곱 오차로 정의된다.

L=∥v^f−vf∥22+∥v^a−va∥22\mathcal{L} = \left\| \hat{v}_f - v_f \right\|_2^2 + \left\| \hat{v}_a - v_a \right\|_2^2L=∥v^f​−vf​∥22​+∥v^a​−va​∥22​

여기서 vfv_fvf​와 vav_ava​는 각각 미래 특징과 액션에 대한 flow-matching 속도 목표다. 이 손실은 World DiT의 잠재 표현이 미래 관측을 예측하는 데 유용하도록 만들고, Action DiT가 해당 표현에서 실행 가능한 액션 청크를 생성하도록 유도한다.

추론 절차

추론 시 미래 토큰은 제거된다. 액션 청크는 가우시안 노이즈로 초기화되고, Euler 적분을 반복해 디노이징한다. 이 과정에서 World DiT의 키/값 캐시를 재사용해 액션 디코딩 비용을 줄인다. 정책 호출당 32개 액션을 예측하고, 벤치마크마다 재계획 주기에서 실행하는 액션 수를 달리한다. LIBERO는 재계획당 10개 액션, RoboTwin 2.0은 24개 액션을 실행하는 설정이 사용된다.

최종 레시피와 학습 설정

최종 레시피에는 여러 설계 선택이 포함된다. 액션 예측만 하는 baseline 대비 미래 특징 예측을 함께 수행하는 predictive supervision을 사용하고, Wan2.2 VAE latents 대신 V-JEPA 2.1 특징 공간을 쓴다. 시간 인코딩은 static, tube, tube-motion 중 tube-motion을 선택한다. 강건성 향상을 위해 카메라 드롭아웃과 고유감각 드롭아웃을 확률 0.1로 적용하고, 이미지 증강과 인코더 LoRA를 함께 사용한다.

학습 설정은 AdamW 옵티마이저, 학습률 5×10−45 \times 10^{-4}5×10−4, betas (0.9,0.95)(0.9, 0.95)(0.9,0.95), matrix weight decay 0.01을 사용한다. 150k 업데이트, 5% warmup, cosine decay, 마지막 10% 구간에서 learning rate floor 1%로 고정하는 스케줄을 쓴다. 배치 크기는 LIBERO 128, RoboTwin 400이고, BF16과 EMA decay 0.9999를 사용한다. 액션과 상태는 채널별 백분위 정규화로 [−1,1][-1, 1][−1,1] 범위로 변환하며, RoboTwin은 ±5\pm 5±5로 클램프한다. 특징은 학습 집합 통계로 정규화된다.

실험 결과

평가 프로토콜과 지시문 수정

실험은 LIBERO, LIBERO-Plus, RoboTwin 2.0, 그리고 Franka Panda 기반 실물 로봇 태스크에서 수행된다. 공개 체크포인트 재평가 대상에는 StarVLA, JEPA-WAM, Fast-WAM, Cosmos Policy, ImageWAM, NowWAM, LeapBot-WA, π0\pi_0π0​, π0.5\pi_{0.5}π0.5​-JEPA-WAM 등이 포함되고, Faster-WAM은 clean 데모로 자체 학습한 베이스라인이다. Qwen-RobotManip과 RoboTwin 2.0 리더보드 방법은 보고서 인용 값으로 비교된다.

LIBERO-Plus에서는 공개 평가기의 지시문 문제가 중요하다. 공개된 평가기는 변형 파일명에서 지시문을 유도해 훈련 시 보지 못한 파라미터가 섞인 텍스트를 제공할 수 있다. 이 논문은 비언어 변형에 기본 태스크의 훈련 지시문을 그대로 사용하는 수정 평가를 제안한다. 수정으로 Fast-WAM은 +19.3pp, LeapBot-WA는 +8.1pp, La-JEPA S/B/L은 각각 +6.3/+4.9/+3.9pp 상승했고, NowWAM은 변하지 않았다.

한계

  • 저자는 학습률, 드롭아웃 비율 등 하이퍼파라미터의 체계적 탐색을 수행하지 않았다고 밝힌다.
  • embodied pretraining의 스케일링 효과를 검증하지 않았다.
  • Randomized RoboTwin에서는 embodied pretraining 모델보다 낮은 성능을 보인다는 점을 인정한다.

비판적 검토

강점

  • 구성 요소별 ablation이 체계적으로 설계됨 — 예측 감독, 특징 공간(V-JEPA vs Wan2.2), 시간 인코딩(Static/Tube/Tube-Motion), 토큰 감소(Mean Pooling vs Patch Grouping), 드롭아웃, 증강+LoRA를 각각 독립 변수로 분리하여 성능 기여도를 정량화했다 (근거: 부록 A 전체, Fig 3, Table 6). 특히 예측 감독은 LIBERO-Plus에서 3-seed 비교와 p-value(p<10−3p < 10^{-3}p<10−3)를 보고해 단일 실험의 우연성을 일부 상쇄한다 (근거: 부록 A.1, Table 7).
  • 추론 효율성이 실측으로 뒷받침됨 — 정책 호출 전체(토큰화~디코딩) latency를 소비자 GPU에서 측정하여 La-JEPA B가 25.16ms로 Fast-WAM(88.09ms) 대비 약 3.5배 빠름을 보이고, 실제 로봇 실험에서도 완료 시간에서 경쟁 모델과 동등하거나 우위임을 확인했다 (근거: Appendix C Table 15, Appendix D Table 17).
  • 벤치마크 평가기 결함을 발견하고 수정 프로토콜을 제시 — LIBERO-Plus 공개 평가기가 훈련 시 보지 못한 파라미터를 지시문에 포함시켜 문장을 훼손하는 문제를 식별하고, 비언어 변형에 기본 태스크 지시문을 사용하는 수정안을 적용했다. 이 수정으로 Fast-WAM +19.3pt, LeapBot-WA +8.1pt 등 기존 순위가 변동함을 보여 벤치마크 신뢰도 제고에 기여한다 (근거: Table 4, Table 13, Table 14).

약점·의문

  • Randomized RoboTwin에서 일반화 한계가 뚜렷함 — Clean 86.2% 대비 Randomized 35.4%로 절반 이하로 떨어지며, 저자도 Embodied PT 모델보다 낮음을 인정한다 (근거: Table 2, 한계 섹션). V-JEPA 특징 공간이 시각적 변형에 강건하다는 주장과 이 결과가 상충하며, “컴팩트 정책이 더 큰 생성 기반 모델보다 정확하다”는 결론은 Clean 조건에 한정된 것으로 읽힌다 (해석).
  • 대부분 ablation이 단일 실행으로 통계적 근거가 부족 — 부록 A에서 “단일 실행 결과(예외: 예측 감독의 LIBERO-Plus 3-seed 비교)“라고 명시하고 있어, 특징 공간 비교(+15.9pt), 시간 인코딩(+3.4pt), 드롭아웃(+7.1pt) 등 핵심 설계 결정이 seed 간 변동성 내에서 유의한지 판단할 수 없다 (근거: 부록 A 공통 설정).
  • 체크포인트 선택 기준이 Clean 성능 최적화에 편향됨 — 체크포인트를 1,000 에피소드 Clean 그리드에서 선택하는데, Table 12에서 원본(120k) 대비 수정(150k) 시 Clean은 +5~8pt 상승한 반면 Randomized는 -5~-9pt 하락한다. 이는 Clean 최적화 체크포인트가 OOD 성능을 희생하는 trade-off를 숨길 수 있다 (근거: 부록 B “데이터 및 체크포인트 선택”, Table 12).
  • 베이스라인 비교 조건이 통일되지 않음 — JEPA-WAM은 동일 20개 태스크로 제한하여 비교하지만 La-JEPA는 50개 태스크 전체로 학습했고, 일부 베이스라인(StarVLA, Cosmos Policy 등)은 공개 체크포인트 재평가, 일부(Qwen-RobotManip, RoboTwin 리더보드)는 보고서 인용이라 학습 데이터량·초기화·최적화 조건이 동일하지 않다 (근거: 부록 B “벤치마크 프로토콜”, “베이스라인 출처”).
  • 실제 로봇 실험의 통계적 파워가 낮음 — 태스크당 100개 데모, 4개 태스크, 각 20 trial로 La-JEPA(17.50/20)와 π0.5\pi_{0.5}π0.5​(17.25/20)의 차이는 0.25 trial에 불과하며, 이 차이가 유의한지 판단할 분산 정보가 없다 (근거: Table 5, Appendix D).
  • Flow Matching의 실용적 이점이 불분명 — denoising steps를 기본값에서 3단계로 줄여도 성공률 변화가 미미(L: 82.41% vs 82.26%)하여, flow matching을 채택한 것이 diffusion 대비 실제 효율성 이점을 주는 것인지 확인되지 않는다 (근거: 부록 E.2 Table 19).

재현 가능성

  • 하이퍼파라미터(AdamW LR 5×10−45\times10^{-4}5×10−4, batch size, LoRA rank/α, 증강 확률/강도, 정규화 범위)가 부록 B Table 9·10에 상세히 공개되어 있고, MuJoCo 버전(3.3.2)과 체크포인트 선택 프로토콜까지 명시되어 있어 학습 재현의 문턱은 낮다. 다만 코드·데이터셋 공개 여부는 본문 어디에도 언급되지 않으며, V-JEPA 2.1 인코더와 FLAN-T5-large의 정확한 체크포인트 버전이 지정되지 않아 동일 특징 공간을 재현할 수 있을지 불확실하다 (해석).
