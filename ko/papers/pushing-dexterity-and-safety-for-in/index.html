Pushing Dexterity and Safety for In-Hand Object Pose Reaching That Works Remarkably Well

임의의 손목 자세에서 다지 로봇 손으로 물체를 목표 6D 포즈로 옮기는 인핸드 포즈 리칭 정책을 시뮬레이션에서 학습하고 제로샷으로 실손에 전이하는 레시피를 제시한다. 잔차 안전 필터를 추가해 성능과 안전을 조절하면서 낙하를 크게 줄이는 광범위한 실로봇 평가를 보고한다.

TL;DR

  • 임의 손목(wrist) 방향에서 손 안 물체를 연속 미확인 목표(goal) 자세로 옮기고 낙하(drop)를 줄이는 문제를 풀었다.
  • 시뮬레이션 특권 관찰(privileged observations) 학습, DAgger 증류(distillation), 적응 커리큘럼(curriculum), ResSafe 잔차(residual) 안전 필터를 결합해 실제 LEAP 핸드에 zero-shot 이전했다.
  • 실제 로봇 4,800개 목표 평가에서 상태(state) 정책은 coarse 성공률 95%대를 보였고, 안전 필터는 낙하를 75% 줄였다.

문제 정의

기존 손 안 물체 조작 연구는 주로 단일 손목 방향, 특히 손바닥 위쪽 자세에 국한되는 경우가 많았다. 또한 단순 회전이나 반복 동작 중심이었고, 실제 로봇에서 중요한 안전성, 즉 낙하 방지를 충분히 다루지 않았다. 이 논문은 임의의 손목 방향에서도 손가락 도달 범위 내 거의 모든 위치와 방향으로 물체를 옮기는 연속 목표 시퀀스를 수행하는 문제를 다룬다.

일반 물체는 완전한 SE(3)SE(3)SE(3) 자세 (p∗,R∗)(p^*, R^*)(p∗,R∗)를 목표로 한다. 회전 대칭이 있는 전구(lightbulb)나 와인잔(wineglass)은 위치 p∗p^*p∗와 목표 축 방향 z∗z^*z∗만 지정한다. 오차는 다음과 같이 정의된다.

핵심 아이디어

핵심 직관은 “현실적으로 잡힐 수 있는 그립만 사용해서 학습하고, 배포 가능한 정책으로 증류한 뒤, 위험할 때만 작게 보정하는 안전 필터를 얹는다”는 것이다. SE(3)SE(3)SE(3) 전체에서 균일하게 목표 샘플링을 하지 않고, 오프라인 생성된 그랩(grasp) 데이터셋에서 초기 상태와 목표를 뽑아 학습 효율을 높인다. 시뮬레이션에서는 특권 정보를 가진 교사 정책으로 PPO를 학습하고, 실제 배포용 상태 학생(state student)과 깊이 카메라(depth camera)만 보는 깊이 학생(depth student)으로 DAgger 증류를 한다. 이후 동결된 태스크 정책 위에 ResSafe 잔차 안전 필터를 추가해 낙하 위험이 커질 때 노미널 액션(nominal action)을 제한적으로 보정한다. 이 구조는 시뮬레이션-실제 이전, 시각 입력 다양성, 안전성-성능 트레이드오프를 하나의 파이프라인으로 묶는다.

방법론

로봇 시스템과 시뮬레이션

하드웨어는 LEAP hand와 UR5 암을 사용한다. LEAP hand의 엄지 베이스 조인트 안정화를 위해 팜(palm) 장착부를 재설계했다. 액추에이터(actuator)는 16개 Dynamixel XC330 서보모터이고, 내부 위치 제어기를 사용해 20 Hz로 조인트 위치 목표값을 전송한다. 손끝(fingertip)은 하드 3D 프린팅 플라스틱에 고마찰 3M 그립 테이프를 한 겹 붙였고, 나머지 부분은 저마찰 플라스틱이다. UR5는 손목 방향, 즉 중력 방향을 설정하고 측정하지만 정책은 팔을 제어하지 않고 핸드만 제어한다.

시각 입력은 두 가지다. 상태 정책은 OptiTrack 모션 캡처로 물체 6D 자세와 손 마커를 추적한다. 깊이 정책은 손목에 장착한 Orbbec Gemini 305 스테레오 카메라를 사용하며, Fast FoundationStereo로 30 Hz에서 깊이를 계산하고 160×120160 \times 120160×120으로 다운샘플링한다.

시뮬레이션-실제 이전을 위해 시스템 식별(system identification)을 했다. 액추에이터 모델은 단순 PD 제어 대신 전압 구동 DC 모터 모델인 BAM을 사용했다. 단일 서보 펜듈럼 테스트 벤치 데이터로 파라미터를 피팅한 뒤 16개 액추에이터에 적용했다. 지연(latency)도 실제 핸드와 시뮬레이션에서 동일한 조인트 궤적을 재생해 측정하고 보정했다. 식별된 모델과 지연을 사용하면 시뮬레이션과 실제의 조인트 위치 및 깊이 이미지가 밀접하게 일치한다.

시뮬레이터는 mjlab 기반 MuJoCo Warp를 사용해 GPU 가속으로 돌린다. 물리 엔진은 120 Hz, 정책은 20 Hz로 동작한다. 팔은 시뮬레이션하지 않고 핸드는 자유 공간에 고정하며, 에피소드마다 랜덤 손목 방향을 사용한다. 충돌 메시는 CoACD로 각 물체를 볼록 부분으로 분해해 만든다.

목표·초기 상태 생성과 학습 환경

목표와 초기 상태는 SE(3)SE(3)SE(3) 균일 샘플링 대신 생성된 그랩 데이터셋에서 뽑는다. LightningGrasp로 개체당 100,000개 그랩을 생성하고, DexterityGen의 RRT 방식으로 500,000개로 확장한 뒤 충돌 관통 그립을 제거한다. 최종적으로 물체당 422k~453k 그랩이 남는다. 리셋 시 데이터셋에서 랜덤 그랩을 선택하고 손목 방향은 SO(3)SO(3)SO(3) 균등 분포로 샘플링한다. 에피소드는 20초 타임아웃 또는 물체가 손에서 0.5 m 이상 떨어지면 종료된다.

태스크 정책 학습 파이프라인 (A1–A4)

태스크 정책은 A1부터 A4까지 4단계로 학습한다.

  • A1: 특권 관찰을 가진 교사 정책을 PPO로 학습한다. 크리틱(critic)은 마찰 계수, 목표 상태, 홀드 진행도 등 추가 정보를 사용하는 비대칭 구조를 가진다.
  • A2: DAgger로 배포 가능한 상태 학생 πs\pi^sπs으로 증류한다. 이 정책은 특권 정보 없이 실제에서 사용할 수 있는 관측값을 사용한다.
  • A3: A2의 상태 학생을 PPO로 미세 조정(fine-tuning)한다.
  • A4: DAgger로 깊이 카메라만 보는 깊이 학생 πd\pi^dπd으로 증류한다. 깊이 인코더는 CNN과 spatial softmax keypoints, 채널 평균을 결합하고, 보조 객체 자세(auxiliary object-pose) 헤드 손실도 함께 학습한다.

안전 필터 (B1–B2)

안전 필터는 태스크 정책을 동결한 상태에서 추가한다.

  • B1: A3 상태 정책 위에 ResSafe 잔차 안전 필터를 학습한다. 노미널 액션과 보정 페널티 가중치 www를 입력으로 사용하고, 기본적으로 L2 보정 페널티를 쓴다. 학습 시 노미널 액션에 노이즈를 추가해 필터가 과도하게 보존적으로 변하지 않도록 한다.
  • B2: 상태 기반 안전 필터를 깊이 카메라만 보는 필터로 증류한다. 이 단계는 A4 깊이 정책 위에 연결되어, 모션 캡처 또는 손목 카메라 중 하나만으로 태스크 정책과 안전 필터를 사용할 수 있게 한다.

실험 결과

주요 실제 로봇 평가는 4개 구성, 즉 상태/깊이 정책과 ResSafe 안전 필터 유무(w=0.5w=0.5w=0.5)의 조합을 사용했다. 물체는 전구, 고무오리, 칼, 와인잔 4종이고, 손목 방향은 6가지이다. 실행은 총 96회이며, 실행당 50개 연속 목표를 10초 윈도우로 수행해 총 4,800개 목표, 약 13.3시간을 평가했다. 모든 구성은 같은 held-out 100,000개 그랩 데이터셋에서 동일한 시퀀스를 시도했다. 상태 정책에는 물체 자세를 입력으로 제공했고, 깊이 정책은 손목 카메라만 사용했다. 주요 평가에서는 전구 twist 명령은 0으로 고정했다.

여기서 coarse 성공은 2 cm와 0.4 rad 이내 도달을 의미하고, precise 성공은 더 엄격한 허용 범위에서 계산된다. 상태 정책에서 안전 필터를 적용하면 coarse 성공률이 95.2%에서 91.5%로, precise 성공률이 75.6%에서 67.2%로 낮아지지만 낙하는 16회에서 4회로 줄고 첫 낙하까지 시간이 늘어난다. 깊이 정책에서도 필터는 성능을 일부 희생시키며 낙하를 줄인다. 와인잔을 제외하면 깊이 정책의 낙하는 37회에서 6회로 감소한다.

물체별 깊이 정책 결과는 시뮬레이션과 차이가 있었다. 전구와 고무오리는 coarse 성공률이 각각 약 95%와 88%로 시뮬레이션과 유사했다. 그러나 칼은 실제 54% 대 시뮬레이션 90%, 와인잔은 실제 50% 대 시뮬레이션 84%로 큰 격차가 나타났다. 와인잔은 300개 목표 중 51회 낙하가 발생했다. 이 격차는 깊이 기반 보조 자세 추정 오차의 긴 꼬리로 설명된다.

추가 비교에서는 칼, 전구, 고무오리는 실제 로봇 성공률이 시뮬레이션보다 높았고, 와인잔은 양쪽 모두 약 89%였다. 낙하율은 실제가 0.7~2.3%로 시뮬레이션의 3.7~9.1%보다 낮았다. 논문은 이 차이를 시뮬레이션의 랜덤 손목 방향, 학습 분포 내 목표, 강한 도메인 랜덤화와 실제 평가의 제한된 손목 방향 및 미확인 목표 사용으로 설명한다.

분포 외(out-of-distribution) 난이도 높은 목표 실험에서는 원래 박스보다 1.5배 큰 박스 안에서 그랩을 생성했다. 손바닥 아래(palm down), 상태 정책 기준 coarse 성공률은 물체별 5684%, 즉 50개 중 2842개였다. 필터 사용 시 19~39개였다. 낙하는 와인잔에서만 발생했고, 필터 유무 각각 2회였다. 이는 노미널 정책이 분포 외 목표에서도 비교적 안전하게 작동하고, 안전 필터가 갑작스러운 낙하 교정에 유리함을 보여준다.

전구 회전(spinning) 테스트는 깊이 정책, 축 목표, twist 명령 ±1\pm 1±1 rad/s로 수행했다. 손바닥 위쪽과 아래쪽 각각 50개 목표를 평가했다. 필터 미사용 시 coarse 도달은 위쪽 46개, 아래쪽 44개였고, 평균 회전 수는 각각 1.24 turns와 0.63 turns였다. 필터 사용 시 도달은 43개와 41개, 평균 회전 수는 0.74 turns와 0.36 turns로 줄었지만 낙하는 없었다. 손바닥 아래쪽이 훨씬 어려웠으며, 이는 하드웨어 한계 가능성으로 해석된다.

큰 팔 움직임 중 회전 실험에서는 UR5 손목을 최대 ±85∘\pm 85^\circ±85∘, 피크 2.75 rad/s 사인파 궤적으로 추적하면서 30초 동안 전구와 고무오리를 회전시켰다. 필터 미사용 시 40회 중 32회 유지했고, 필터 사용 시 38회 유지했다. 다만 높은 전구 목표에서는 필터가 회전을 멈추게 하는 사례가 10회 중 3회 발생했다.

모션 캡처 없이 손목 카메라만 사용하는 다운스트림 태스크도 평가했다. 와인잔 뒤집기, 전구 점등, 고무오리 세우기를 하드코딩된 팔 움직임과 함께 수행했고, 필터는 w=1.5w=1.5w=1.5를 사용했다. 결과는 필터 미사용 대비 사용 시 와인잔 7/10 → 6/10, 전구 4/5 → 3/5, 고무오리 7/10 → 3/10으로 낮아졌다. 논문은 학습 범위 이탈과 스크립트 실패가 기여했다고 분석한다.

아블레이션에서는 커리큘럼이 A1 학습에 큰 영향을 줬다. 마찰 커리큘럼은 전구와 고무오리에서 에피소드당 목표 수를 15~64% 증가시켰고, 목표+마찰 커리큘럼은 3개 물체에서 최상위였다. 와인잔은 예외적으로 커리큘럼 없을 때 2.74 goals/episode로, 사용 시 2.20보다 높았다. 특권 액터 관측값도 중요했다. 칼 A1 학습에서 학생의 노이즈·지연 관측값만 보는 액터보다 특권 액터 관측값이 성능 향상에 필수적이었다.

ResSafe 페널티 아블레이션에서는 기본 L2가 coarse 80.4%, 낙하율 3.8%였다. L1은 낙하율을 1.3%로 낮추지만 coarse 성공률이 21.7%까지 급감했다. 노미널 액션 노이즈 없는 L2는 78.6%와 2.5%로 기본과 유사했다. B1 학습 과정에서는 세 변형 모두 unsafe episode rate가 비슷했지만, L1은 태스크를 과도하게 억제해 완료 목표 수를 줄였다.

한계

  • 정책은 물체별로 학습된다. 하나의 정책이 여러 물체를 동시에 다루는 다중 객체(multi-object) 일반화까지 해결하지 않는다.
  • 칼과 와인잔에서는 깊이 기반 시뮬레이션-실제 시각적 갭이 남는다. 보조 자세 추정 오차의 긴 꼬리가 원인으로 지목되며, 더 정확한 깊이 센싱 시스템 식별 또는 더 강한 시각 증강·도메인 랜덤화가 필요하다.
  • 100% 성공률에는 도달하지 못했다. 향후 목표로는 다중 객체 정책과 일반화된 안전 필터 레시피 개발이 제시된다.

비판적 검토

강점

  • 실제 로봇 평가가 충분히 크고 통제됨 — 4개 물체, 6가지 손목 방향(wrist orientation), 96회 실행, 실행당 50개 목표, 총 4,800개 홀드아웃(held-out) 목표를 동일 시퀀스로 비교해 제로샷(zero-shot) 이전과 안전성 주장을 뒷받침한다 (근거: Section VI-B, Table II, Fig. 7).
  • 안전 필터(safety filter)의 이득과 비용을 함께 정량화함 — ResSafe 잔차 안전 필터(residual safety filter)를 적용하면 state policy 낙하가 16회에서 4회로 줄고 거친 성공률(coarse success)은 95.2%에서 91.5%로만 떨어지며, depth policy에서도 낙하가 88회에서 46회로 감소한다 (근거: Table II).
  • 시뮬레이션-실제 갭을 시스템 식별(system identification)과 시각 오차 분석으로 추적함 — BAM 액추에이터 모델과 지연(latency) 보정 후 시뮬레이션/실제 조인트·깊이 이미지가 일치함을 보이고, knife/wineglass의 깊이 포즈 오차 긴 꼬리(long tails)를 분리해 설명한다 (근거: Appendix B, Fig. 16, Appendix K.1/Fig. 26).

약점·의문

  • 외부 기준선(baseline) 비교가 부족해 기여 크기가 불분명하다 — 제공된 메모에는 ResSafe 유무와 HJ 필터 스윕만 있고, 다른 in-hand manipulation 또는 safety filter 방법과의 직접 비교 근거가 없다 (근거: Table II, Table IX; 외부 baseline 보고는 제공된 메모에 없음)(해석).
  • 통계적 유의성과 반복 실행 정보가 제한적이다 — 배포 정책은 단일 실행 결과로 보고되고, 아블레이션(ablation)도 일부 3개 시드, 일부 1개 시드에 그치며 실제 로봇 96회 실험의 분산·유의성 검정이 메모에 없다 (근거: Appendix H, Table II).
  • “임의 손목 방향” 일반화 주장은 실제 평가 범위보다 넓다 — 학습/시뮬레이션은 SO(3)SO(3)SO(3) 균등 손목 방향을 쓰지만, 주요 실제 로봇 결과는 6가지 손목 방향으로 제한되어 있고, 분포 외(OOD) 목표 테스트도 palm down state policy 중심으로 보고된다 (근거: Section VI-B, Fig. 7, Table X)(해석).
  • 안전 필터가 항상 성능과 안전을 동시에 개선하지는 않는다 — 다운스트림 태스크(downstream task)에서 필터 사용 시 duck 성공이 7/10에서 3/10으로 떨어지고, 큰 팔 움직임 중 high lightbulb goal에서는 필터가 회전을 멈추게 하는 사례가 10회 중 3회 보고된다 (근거: Table XIV, Table XIII).
  • depth policy의 일반화 근거는 knife/wineglass에서 약하다 — depth policy 거친 성공률은 71.8%, 정밀 성공률(precise success)은 38.3%이며, knife/wineglass에서는 보조 포즈 추정(auxiliary pose estimation) 오차의 긴 꼬리로 시뮬레이션-실제 갭이 커져 결론이 lightbulb/duck 중심이 되기 쉽다 (근거: Table II, Fig. 26, Appendix K.1)(해석).

재현 가능성

  • 제공된 메모에는 코드·데이터 공개 여부가 명시되지 않았다. 하이퍼파라미터(Table VII/VIII), 학습 시간(부록 H), 하드웨어/깊이 파이프라인(부록 A/B)은 자세히 있으나, 배포 정책 단일 시드와 held-out 100k grasp dataset의 실제 공개 여부만으로는 완전 재현을 확신하기 어렵다.
