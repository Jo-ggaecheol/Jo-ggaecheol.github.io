Pushing Dexterity and Safety for In-Hand Object Pose Reaching That Works Remarkably Well

임의의 손목 자세에서 다지 로봇 손으로 물체를 목표 위치·자세로 옮기는 in-hand object pose reaching 정책을 시뮬레이션에서 학습하고 zero-shot으로 실손에 전이하는 레시피를 제시한다. 잔차 안전 필터를 추가해 낙하를 크게 줄이는 성능·안전 평가를 수행한다.

TL;DR

기존 연구가 단일 손목 방향에 국한되었던 문제와 안전성(낙하) 간과를 해결하기 위해, 시뮬레이션에서 학습된 정책을 실제 LEAP 핸드에 Zero-shot으로 이전하는 방법을 제안한다. 적응형 마찰 커리큘럼과 ResSafe 기반 잔차 안전 필터를 도입하여, 13.3시간의 실제 로봇 평가에서 상태 정책 기준 95.2%의 목표 도달률을 달성하고 낙하 횟수를 75% 감소시켰다.

문제 정의

기존 인핸드 오브젝트 포즈 리칭(In-hand object pose reaching) 연구는 대부분 손바닥이 위를 향하는 단일 손목(wrist) 방향에서만 작동하며, 단순한 회전이나 반복 동작에 국한되어 있다. 또한 물체가 손에서 떨어지는 것(drop)을 방지하는 안전성이 명시적으로 다루어지지 않거나 암묵적으로 처리되는 경향이 있다. 본 논문은 임의의 손목 방향에서도 물체를 원하는 위치와 방향으로 이동시킬 수 있는 정책과, 이를 수행하면서도 낙하를 최소화할 수 있는 안전 메커니즘이 필요함을 지적한다.

핵심 아이디어

시뮬레이션에서 인간 데이터 없이 학습된 정책을 실제 로봇에 적용할 때 발생하는 시뮬레이션-실제(Sim-to-Real) 갭을 줄이고, 동시에 물체 낙하라는 안전 문제를 해결하는 것이 핵심이다. 이를 위해 두 가지 주요 구성 요소를 제안한다. 첫째, 비현실적으로 높은 마찰 계수에서 시작하여 실제 값으로 점진적으로 낮추는 **적응형 마찰 커리큘럼(Adaptive Friction Curriculum)**을 통해 시뮬레이션의 물리적 한계를 극복한다. 둘째, 태스크 정책의 액션 위에 잔차(residual)를 더해 안전성을 보정하는 ResSafe 기반 안전 필터를 도입한다. 이 필터는 보수성 파라미터 www를 조절하여 성능과 안전성 사이의 트레이드오프를 유연하게 관리할 수 있다.

방법론

하드웨어 및 시뮬레이션 환경

UR5 암에 장착된 LEAP 핸드(16개 Dynamixel XC330 서보)를 사용한다. 손끝에는 고마찰 3M 그립 테이프를 부착하고, 나머지 부분은 저마찰 플라스틱으로 구성된다. 시각 입력은 모션 캡처(OptiTrack)와 손목 장착 스테레오 카메라(Orbbec Gemini 305) 두 가지로 나뉜다. 시뮬레이터는 mjlab 기반 MuJoCo Warp를 사용하며, 액추에이터 모델은 BAM(Bio-inspired Actuator Model)을 통해 펜듈럼 테스트 벤치 데이터로 식별한다. 이를 통해 실제 로봇과의 지연(latency) 및 동역학 차이를 최소화한다.

학습 파이프라인

학습은 태스크 정책(Task Policy)과 안전 필터(Safety Filter) 두 트랙으로 진행된다.

  1. 태스크 정책 (A1-A4):
    • A1: 특권 관찰(Privileged observations, 노이즈 없는 상태 정보)을 가진 교사(Teacher) PPO 학습.
    • A2: DAgger를 통해 배포 가능한 상태 기반 학생(Student)으로 증류.
    • A3: 해당 학생 정책을 PPO로 미세 조정(Fine-tuning).
    • A4: DAgger를 통해 깊이 카메라(Depth camera)만 보는 학생으로 증류.
  2. 안전 필터 (B1-B2):
    • B1: 동결된 태스크 정책 위에 ResSafe 기반 잔차 안전 필터 학습.
    • B2: 상태 기반 필터를 깊이 기반 필터로 증류.

아블레이션

  • 마찰 커리큘럼: 마찰 커리큘럼만 적용했을 때 에피소드당 목표 수가 1.87에서 2.14로 증가했으며, 목표+마찰 커리큘럼 조합이 가장 효과적이었다(2.27).
  • 특권 관찰: A1 단계에서 특권 관찰을 가진 액터가 필수적이다. 노이즈 있는 학생 관찰만 사용하는 경우 성능이 절반 수준(2.27 vs 1.12 goals/ep)으로 떨어졌다.
  • 페널티 유형: L2 페널티가 L1 페널티보다 목표 도달률과 낙하율의 균형이 더 좋았다(w=0.5w=0.5w=0.5 시 Coarse 도달률 80.4% vs 21.7%).

한계

저자들은 다음과 같은 한계를 명시했다.

  1. 현재 정책과 필터는 물체별(per object)로 학습되어야 한다. 하나의 정책으로 여러 물체를 다루지 못한다.
  2. 칼(Knife)과 와인잔(Wineglass)에서 시각적 시뮬레이션-실제 갭(visual sim-to-real gap)이 존재한다. 특히 깊이 정책의 경우, 실제 로봇에서의 포즈 추정 오차가 시뮬레이션보다 긴 꼬리(long tails)를 보여 성능 저하를 유발했다.
  3. 100% 성공률과 0 낙하를 달성하지 못했다.

비판적 검토

강점

  • 실제 로봇 평가가 규모 있고 통제됨 — 4개 물체, 6가지 손목(wrist) 방향, 96회 실행, 4,800개 미확인(unseen) 목표를 학습에 쓰지 않은 held-out 그랩(grasp) 데이터셋에서 추출해 평가했고, 물체와 손목 방향이 같으면 모든 구성이 동일한 목표 시퀀스를 시도하도록 설계되어 구성 간 비교가 공정하다 (근거: Section VI-B, Appendix J).
  • 안전 필터의 성능/안전 trade-off를 정량적으로 보여줌 — 잔차 안전 필터(residual safety filter) w=0.5w=0.5w=0.5는 상태 정책(state policy)에서 coarse 성공률을 95.2%에서 91.5%로 낮추되 낙하(drops)를 16회에서 4회로 줄였고, www sweep으로 첫 낙하까지 시간과 목표 도달률의 trade-off 곡선을 제공한다 (근거: Table II, Fig. 5, Table XI).
  • 시뮬레이션-실제 시각 갭(sim-to-real visual gap) 원인을 분리 분석함 — 깊이 정책(depth policy)에 보조 객체 포즈 헤드(auxiliary object-pose head)를 붙여 모션 캡처(motion capture)와 비교했고, 고무오리/전구에서는 시뮬레이션과 유사한 오차(중위 약 1 mm, 1∘1^\circ1∘ 이내)인 반면 칼/와인잔에서만 실물 오차의 긴 꼬리(long tails)가 있음을 보여준다 (근거: Appendix K, Fig. 26).
  • 액추에이터와 지연 보정이 재현 가능한 수준으로 상세함 — 전압 구동 DC 모터 모델(BAM m5) 파라미터, 펌웨어/인코더/전원 설정, 명령 채널 지연을 Table III에 명시하고 chirp 입력 검증에서 실제-시뮬레이션 조인트 RMSE 0.45°를 보고한다 (근거: Appendix B, Table III, Fig. 15–16).

약점·의문

  • HJ 필터 비교가 단일 물체/정책에 국한됨 — ResSafe 우위 주장의 직접 근거인 Hamilton-Jacobi(HJ) 필터(LRSF, HCSF) 비교는 고무오리 상태 정책에서만 수행되었고, 나머지 3개 물체와 깊이 정책에서는 보고되지 않는다 (근거: Table I). 따라서 ResSafe가 모든 구성에서 HJ 필터보다 우월한지는 확인되지 않는다 (해석).
  • 학습 seed 변동성이 실제 로봇 결과에 반영되지 않음 — 배포된 태스크 정책은 개체당 단일 A1–A4 학습 실행 결과이고, 일부 ablation(예: 4개 객체 커리큘럼)은 1개 seed만 사용했다. 실제 로봇 96회 실험은 동일 체크포인트의 반복이지 학습 seed 다양성을 반영하지 않는다 (근거: Appendix H, Section VI-B).
  • 깊이 정책에서 칼/와인잔 시뮬레이션-실제 격차가 크고 필터도 완전히 해소 못 함 — 깊이 정책 coarse 성공률은 칼 54%(시뮬레이션 90%), 와인잔 50%(시뮬레이션 84%)이고, 와인잔 낙하는 51회에서 40회로만 감소했다. 제목의 “works remarkably well”이 이 한계를 과소평가할 수 있다 (근거: Section VI-B, Appendix K).
  • 안전 필터가 다단계 다운스트림 태스크에서 오히려 성능을 떨어뜨림 — w=1.5w=1.5w=1.5에서 고무오리 place 단계 성공률이 7/10에서 3/10으로, 전구 screwed-in이 4/5에서 3/5로 낮아졌다. 필터의 이점이 pose reaching 외에는 항상 보장되지 않는다 (근거: Table XIV).
  • 통계적 유의성/분산 보고가 제한적 — 실제 로봇 결과는 물체당 pooled 300 goals 기준으로 보고되고 p-value나 신뢰구간은 명시되지 않으며, 시뮬레이션 ablation 일부(Fig. 28)에서만 s.e.m. 에러 바를 제공한다 (근거: Table II, Fig. 28).

재현 가능성

  • 코드와 체크포인트는 “공개 예정”으로만 명시되어 있고, 부록에 하드웨어, 시스템 식별, 시뮬레이터 설정, 도메인 랜덤화, 학습 시간/하이퍼파라미터가 상세히 제공된다 (근거: 메모 8, Appendix A–H). 다만 배포 체크포인트의 학습 seed 단일, HJ 필터 비교가 고무오리만, 깊이 갭 해결책 미제시로 완전 재현과 확장에는 한계가 있다.
