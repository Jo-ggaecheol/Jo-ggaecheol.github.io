Robust In-Hand Manipulation via Priors in Reinforcement Learning and Mechanical Design

이 논문은 외부 센서 없이 다지 로봇 손의 손 안 회전 조작을 위해, 고전 그랩 분석 기반 전역 그랩 품질 선지와 손가락 끝 곡률 기반 국소 접촉 기하 선지를 강화학습 보상과 이방성 손가락 끝 형상에 결합한다. 이를 통해 회전 효율, 그랩 안정성, 외란 거부 성능, 시뮬레이션-실제 전이가 개선된다.

TL;DR

  • 외부 센서 없이 고유감각(proprioception)만으로 손 안 회전(in-hand rotation)을 수행하는 강화학습 문제를 다룬다.
  • 전역 그립 품질(global grasp quality)을 보상 형상화에, 이방성 손가락 끝 곡률을 기계 설계에 선행지식으로 결합한다.
  • 기본 팁+GQ 대비 정렬 팁을 추가하면 요약 성공률이 56%에서 83%로, 원기둥 누적 회전은 2.29회까지 개선된다.

문제 정의

이 논문은 촉각이나 시각 같은 외부 센서 없이 고유감각만으로 손 안 물체 회전을 수행하는 문제를 다룬다. 기존 계산 알고리즘 기반 방법은 정확한 시스템 식별과 접촉 모델링에 의존하기 때문에 현실의 불확실성과 고자유도 손으로 확장하기 어렵고, 기존 강화학습(RL) 접근법은 회전 동작 자체에는 강하지만 안정적인 그립 유지에는 소홀할 수 있다. 또한 시뮬레이션-실세계(sim-to-real) 전이 연구는 모션 캡처나 촉각 센서 등 추가 하드웨어에 의존하거나, 시뮬레이션 전용 특권 정보(privileged information)를 근사하는 데 초점을 맞추는 경우가 많다. 이 논문은 이러한 한계를 줄이기 위해 학습 보상과 기계적 설계라는 두 층위에 물리 선행지식(physics prior)을 넣고, 다양한 손 방향과 대상물에서 강건한 인핸드 조작을 목표로 한다.

핵심 아이디어

직관은 “회전을 잘하게 만드는 것”과 “그립이 무너지지 않게 만드는 것”을 분리해서 설계한다는 것이다. 전역 그립 품질은 접촉 위치만으로 계산할 수 있는 고전적 그립 분석 지표를 학습 보상 형상화에 쓴다. KKK개 접촉점의 힘 f\mathbf{f}f가 생성하는 웬치(wrench)를 w=Gf\mathbf{w}=\mathbf{G}\mathbf{f}w=Gf로 표현하고, 그람 행렬(Gramian) M=GG⊤\mathbf{M}=\mathbf{G}\mathbf{G}^\topM=GG⊤의 최소 고유값을

qgrasp=λmin⁡(M)q_{\mathrm{grasp}}=\lambda_{\min}(\mathbf{M})qgrasp​=λmin​(M)

으로 정의한다. 이 값이 크면 특정 웬치 방향에 덜 취약하다는 의미다. 국소 접촉 기하학 선행지식은 손가락 끝 곡률을 설계해 작업 방향의 롤링은 허용하고 오프축 운동은 억제하는 것이다. 특히 정렬 실린더(aligned cylindrical) 팁은 원기둥 물체를 회전시키는 방향에는 상대 곡률이 크고, 그립을 불안정하게 만드는 수직 접선 방향에는 곡률을 0에 가깝게 만든다.

방법론

RMA 기반 학습 파이프라인

실험 플랫폼은 Franka Research 3 팔에 Allegro Hand를 장착한 구성이다. 손은 활성 자유도 16개를 가지며, 정책은 16차원 목표 관절 위치를 출력하고 PD 컨트롤러가 이를 추적한다. 시뮬레이션은 Isaac Gym에서 병렬 환경으로 학습되며, 정책 쿼리는 20 Hz, 제어 디메이션(decimation)은 6, 에피소드 길이는 400 스텝이다.

학습은 RMA(Rapid Motor Adaptation) 프레임워크를 따른다. Stage I에서는 teacher 정책이 고유감각 관찰 ot\mathbf{o}_tot​와 특권 정보에서 만든 잠재 변수 zt\mathbf{z}_tzt​를 함께 사용해 PPO로 학습한다. 특권 정보에는 물체 자세, 스케일, 질량, 마찰계수, 질량중심 오프셋 등이 포함된다. Stage II에서는 adaptation module이 최근 30프레임의 고유감각 히스토리만으로 z^t\hat{\mathbf{z}}_tz^t​를 추정하고, student 정책은 (ot,z^t)(\mathbf{o}_t,\hat{\mathbf{z}}_t)(ot​,z^t​)로부터 동작을 만든다. 배포 시에는 특권 정보 없이 고유감각만 사용한다.

초기 그립 캐시는 정준 자세 변형을 필터링해 생성한다. 3개 이상 손가락 끝 접촉, 대상물 근접 조건, 그리고 팔 축 기준 90∘90^\circ90∘ 회전에서도 안정적인 그립을 유지하는 구성을 남긴다. 물체 스케일당 약 50,000개의 초기 그립이 만들어진다. 학습은 손 방향 커리큘럼으로 진행되며, 팜 틸트(palm tilt)를 0∘0^\circ0∘, 45∘45^\circ45∘, 90∘90^\circ90∘, 180∘180^\circ180∘ 단계로 늘려 중력 유도 섭동에 점진적으로 노출한다. 리셋 시마다 물체 스케일, 질량, 마찰, 질량중심 오프셋, PD 게인을 랜덤화하고 짧은 외부 힘도 적용한다. 실세계에서는 RealSense D435와 AprilTag로 사후 자세만 측정하며, 이 정보는 정책 입력으로 사용하지 않는다.

보상 설계

보상은 태스크 항, 그립 품질 형상화 항, 정규화 항으로 구성된다. 태스크 항은 물체 각속도를 목표 회전 축의 평행 성분과 수직 성분으로 나누어, 원하는 방향 회전을 보상하고 오프축 회전을 억제한다.

그립 품질 형상화 항은 앞서 정의한 qgraspq_{\mathrm{grasp}}qgrasp​를 손 좌표계 기준 접촉 위치로 계산해 사용한다. 힘 센싱이 필요 없으며, 적응 스케일과 클리핑을 통해 제한된 단조 증가 보상으로 변환된다. 이 항은 정책이 단순히 빠르게 돌리는 것보다 웬치 저항이 큰 그립 구성을 유지하도록 유도한다.

정규화 항은 대상물 이동, 초기 그립 캐시에서의 이탈, 토크와 일(work)을 억제한다. 전체 보상은 세 항의 합으로 정의된다.

손가락 끝 설계와 제작

손가락 끝은 flat, spherical, aligned cylindrical, orthogonal cylindrical 네 가지 형태로 설계된다. 외형 치수, 길이, 마운팅 방식은 동일하고 접촉면 기하학만 다르다. 곡률 반경은 R=40R=40R=40 mm, 즉 κf=1/R=25 m−1\kappa_f=1/R=25\ \mathrm{m}^{-1}κf​=1/R=25 m−1이다.

국소 접촉 기하학에서는 상대 곡률을 K=Ko+KfK=K_o+K_fK=Ko​+Kf​로 본다. 원기둥 물체 기준 aligned cylindrical 팁은 작업 방향(XcX_cXc​)에는 높은 상대 곡률을 제공해 롤링을 지원하고, 오프축 방향(YcY_cYc​)에는 곡률을 0으로 만들어 면 외 운동을 수동적으로 억제한다. spherical과 orthogonal 형태는 YcY_cYc​ 방향에도 곡률이 존재해 오프축 롤링을 허용할 수 있다.

제작은 재사용 가능한 멀티파트 몰드를 이용한 실리콘 캐스팅으로 수행된다. PLA 3D 프린팅 몰드에 샌딩과 릴리스 에이전트 코팅을 한 뒤, Smooth-On Dragon Skin 30 실리콘을 주조한다. 경화 후 탈형된 손가락 끝에는 Allegro Hand 원위 관절에 마운팅하기 위한 황동 나사 인서트가 통합된다.

실험 결과

평가 지표는 Rot(누적 회전량), TTT(에피소드 지속시간), SR(성공률)이다. 성공은 10초 이상 그립 유지와 최소 0.15회전 달성을 함께 요구하는 gated success rate로 정의된다. 각 조건은 시드 3개와 롤아웃 3회로 평가했다.

시뮬레이션 아블레이션에서는 두 선행지식을 결합한 설계가 가장 강했다.

실세계에서는 GQ 선행지식이 그립 유지 시간과 성공률을 크게 높였다. 논문 요약에 제시된 대표 수치는 다음과 같다.

GQ 보상을 포함해 학습한 정책으로 손가락 끝 형태를 비교하면 정렬 실린더가 전반적으로 우세했다.

한계

저자가 논문에서 직접 밝힌 한계는 다음과 같다.

  • 이동(transport)이나 재그립(regrasp) 등 다른 작업 범주는 평가하지 않았다.
  • 직접적인 외부 섭동에 대한 정량적 평가가 부족하다.
  • 시뮬레이션-실세계 전이에 각 구성 요소가 얼마나 기여하는지 정량적으로 분리하지 못했다.

비판적 검토

강점

  • 두 물리 선행지식의 효과를 분리할 수 있는 실험 구조 — 전역 그립 품질(GQ) 보상 유무 비교와 고정 정책 하 fingertip 교체 비교가 있어, “학습 보상 선행지식”과 “기계 기하학 선행지식”의 기여를 각각 평가하고 있다. (근거: Table 1, Appendix Table 7; Table 2, Appendix Table 8; Table 9)
  • 물리 기하 해석이 실험 결과와 정합 — 상대 곡률과 접선 구동성(mobility) 분석에서 aligned cylindrical fingertip이 작업 방향 롤링을 허용하고 오프축 운동을 억제한다고 예측하며, 실세계 결과에서도 aligned가 성공률(SR), 지속 시간(TTT), 누적 회전량(Rot)에서 우세하다. (근거: Sec 2.3, Table 4, Fig 6; Table 8, Table 9)
  • 고유감각(proprioception) 전용 zero-shot 실세계 평가와 실패 모드 분석 — 카메라는 사후 자세 측정에만 사용되고, palm tilt과 물체 종류를 다양화하며, gated SR과 종료 분해로 단순 홀딩을 성공에서 제외하고 있다. (근거: Appendix C, Appendix E; Fig 12, Fig 13; Table 7–8)
  • 재현에 필요한 훈련·제작 정보가 비교적 상세 — RMA(Rapid Motor Adaptation) 단계, 관찰/잠재 변수 구조, 도메인 랜덤화 범위, 보상 함수, 네트워크와 최적화 하이퍼파라미터, 실리콘 fingertip 재료와 치수가 제시되어 있다. (근거: Appendix C Table 5–6, Eq 12–16; Appendix D)

약점·의문

  • 실세계 반복 실행의 통계적 근거가 약함 — 주요 실세계 결과는 소수 시드와 롤아웃 평균으로 보고되고, Table 1과 Table 2에는 표준편차·신뢰구간·통계적 유의성 검정이 명시되지 않아 개선 폭이 노이즈 범위인지 판단하기 어렵다. (근거: Sec 4 “시드 3개, 롤아웃 3회 평균”; Table 1, Table 2; Table 9에만 일부 Std)
  • 선행 연구 대비 우월성을 직접 비교하지 않음 — 관련 연구는 서술하지만, 촉각/시각 기반 방법이나 기존 sim-to-real in-hand RL 정책과 같은 외부 baseline과의 동일 조건 비교가 없어 “기존 RL 접근법보다 안정적”이라는 주장의 강도가 제한된다. (근거: Appendix A; Sec 4에서는 GQ/tip 내부 ablation만 제시)
  • 평가 대상이 제한되어 일반화 결론에 주의 필요 — 원기둥·직육면체·구, Allegro Hand + Franka Research 3, 고정된 palm tilt 자세, 재그립/이동/외부 섭동에 대한 정량 평가가 없어 “robust in-hand manipulation”의 범위를 넓게 해석하기는 어렵다. (근거: Sec 5–6 한계; Appendix E 물체 목록; Fig 5)
  • sim-to-real 전이와 RMA 구성 요소의 기여도가 정량적으로 분리되지 않음 — zero-shot 실세계 성공은 보고되지만, Stage I/II, 도메인 랜덤화, 특권 잠재 변수 추정 없이 단순 정책 학습 시 성능이 어떻게 달라지는지 ablation이 없어 전이 개선의 원인이 불명확하다. (근거: Appendix C RMA/DR 설정; Sec 5–6에서 한계로 언급)
  • 국소 기하 선행지식의 설계 공간 탐색이 제한적 — 4가지 fingertip만 비교하고, 곡률 반경·소재 경도·마찰 특성 변화가 aligned 효과에 미치는 영향은 평가되지 않아 “aligned cylindrical”이 최적인지 일반화하기 어렵다. (근거: Sec 3.3; Appendix D; Table 2/8)
  • GQ 선행지식의 물리적 완전성과 민감도 확인이 불충분 — 그립 품질 지표는 마찰 원(cone)을 고려하지 않은 최소 고유값으로 정의되고, 적응 스케일·EMA·클리핑 등 보상 형상화 파라미터의 민감도 실험도 없어 GQ 효과가 특정 reward shaping에 의존하는지 알기 어렵다. (근거: Sec 2.2; Appendix C Eq 13–14, Table 6)

재현 가능성

  • 제공된 논문 요약에는 코드·데이터 공개 여부가 명시되어 있지 않다.
  • Appendix C/D에 훈련 하이퍼파라미터, 도메인 랜덤화 범위, 보상 함수, fingertip 제작 치수·재료가 있어 재현 출발점은 명확하지만, 실세계 실험의 시드·롤아웃 수·성공률 집계 방식과 코드 공개 여부는 확인되지 않는다.
