SliceIt! - A Dual Simulator Framework for Learning Robot Food Slicing

SliceIt!은 실제 절단 데이터로 고충실도 절단 시뮬레이터를 보정하고 로봇 시뮬레이터와 결합한 이중 시뮬레이션 환경에서 강화학습 기반 컴플라이언스 제어 정책을 학습해 실제 로봇에 배포하는 real2sim2real 프레임워크다.

Cristian C. Beltran-Hernandez, Nicolas Erbetti, Masashi Hamaya

TL;DR

  • 로봇이 칼로 음식을 자르는 작업을 실제 환경에서 학습하면 위험하고 음식 낭비가 크므로, 시뮬레이션에서 안전하게 학습하는 문제를 다룬다.
  • 절단 물리를 담당하는 DiSECt와 로봇 동역학을 담당하는 Gazebo를 ROS로 연결한 듀얼 시뮬레이션 환경을 만들고, 실제 절단 데이터 몇 건으로 보정한 뒤 SAC 기반 강화학습과 FDCC 컴플라이언스 컨트롤을 학습한다.
  • 실로봇 평가에서 Gazebo 단독 베이스라인보다 모든 식품에서 접촉력이 낮았고, 학습에 쓰지 않은 당근에서도 더 낮은 접촉력을 보였다.

문제 정의

음식 절단 작업은 칼이라는 위험한 도구를 다루면서도 재료와 도마에서 발생하는 반력 상황에 맞춰 정밀하게 움직여야 한다. 기존 모델 기반 제어나 학습 기반 방법은 다양한 식품의 물성 변화에 적응하려면 실제 상호작용이 많이 필요할 수 있고, 음식 절단에서는 불필요한 음식 낭비로 이어질 수 있다. 또한 로봇이 칼을 들고 랜덤 탐색을 하는 방식은 실세계에서 위험하다.

시뮬레이션에서 학습하면 탐색이 안전하지만, 시뮬레이션과 실세계 차이인 리얼리티 갭 때문에 정책이 실로봇에서 제대로 동작하지 않을 수 있다. 최근 DiSECt 같은 고충실도 절단 시뮬레이터가 등장했지만, 기존 절단 시뮬레이터는 주로 칼과 대상물 사이의 물리적 상호작용에 집중하고, 로봇이 실제로 그 칼 운동을 실현할 수 있는지는 충분히 고려하지 않는다. 이 논문은 절단 시뮬레이터와 로봇 시뮬레이터를 결합해 실로봇 평가와 학습을 동시에 가능하게 하는 프레임워크를 제안한다.

핵심 아이디어

SliceIt!은 서로 강점이 다른 두 시뮬레이터를 함께 쓰는 구조다. DiSECt 기반 CutSim은 연질 재료 절단과 접촉력을 더 현실적으로 모델링하고, Gazebo 기반 RoboSim은 로봇 동역학과 ROS 통합에 유리하다. 먼저 실제 로봇으로 식품을 몇 번 자른 운동과 접촉력 데이터를 모으고, 이 데이터로 CutSim의 파라미터를 보정한다. 이후 RL 에이전트는 칼의 기준 궤적뿐 아니라 컴플라이언스 컨트롤러의 제어 파라미터도 함께 학습한다. 이렇게 학습한 정책을 실로봇에 배포하면, 재료의 강성 변화와 도마 접촉에 맞춰 접촉력을 낮추며 절단 동작을 수행할 수 있다.

방법론

시스템 개요

전체 흐름은 real2sim2real 구조를 따른다. 먼저 실제 로봇으로 식품을 자르는 데이터를 수집하고, 이 데이터로 듀얼 시뮬레이션 환경을 보정한다. 다음으로 보정된 시뮬레이션 환경에서 RL로 제어 정책을 학습한 뒤, 실로봇에 배포한다. ROS는 두 시뮬레이터, 실로봇, RL 정책, 저수준 컴플라이언스 컨트롤러를 연결하는 중간층 역할을 한다.

CutSim: DiSECt 보정

CutSim에는 DiSECt를 사용한다. DiSECt는 유한요소법 기반 절단 시뮬레이션에 signed distance field 기반 연속 접촉 모델과 손상 모델을 결합해 연질 재료 절단을 표현한다. 이 시뮬레이터는 미분 가능하기 때문에 파라미터 추정에 그래디언트 기반 최적화를 사용할 수 있다.

논문은 보정을 두 단계로 수행한다. 먼저 그래디언트 기반 방법이 아닌 Tree-structured Parzen Estimator를 Optuna로 사용해 초기 파라미터를 빠르게 찾는다. 이후 Adam 알고리즘으로 파라미터를 정밀하게 조정한다. 목표는 로봇 절단 운동과 접촉력을 시뮬레이션에서 재현하고, 실제와 유사한 힘 프로파일을 얻는 것이다.

RoboSim: Gazebo와 ROS 통합

RoboSim에는 Gazebo를 사용한다. Gazebo를 선택한 이유는 ROS와의 호환성이 높고, 로봇 시스템 구성 요소들을 쉽게 통합할 수 있기 때문이다. 이 논문에서는 Gazebo가 시뮬레이션된 로봇의 칼 운동을 생성하고, ROS 메시지를 통해 CutSim과 정보를 교환한다.

시뮬레이터 브리지

두 시뮬레이터를 함께 쓰는 이유는 계산 비용 차이와 역할 분담 때문이다. CutSim은 더 작은 시간 단계가 필요해 논문에서는 dt=1.0×10−5dt = 1.0 \times 10^{-5}dt=1.0×10−5가 가장 좋은 결과를 주었다고 보고한다. RoboSim은 dt=1.0×10−4dt = 1.0 \times 10^{-4}dt=1.0×10−4로 동작할 수 있어 계산 비용이 상대적으로 낮다.

두 시뮬레이터는 일정한 시간 구간을 번갈아 실행하는 interleaving 방식으로 병렬 구동된다. 실제 제어 주기는 Universal Robots UR5e의 최고 제어 주기에 맞춰 2.0×10−32.0 \times 10^{-3}2.0×10−3 초로 사용된다. RoboSim은 로봇 기준 칼의 위치 x\mathbf{x}x와 속도 x˙\dot{\mathbf{x}}x˙를 보내고, CutSim은 컴플라이언스 컨트롤러가 사용할 접촉력 Fext\mathbf{F}_{ext}Fext​를 반환한다.

RL 기반 절단 학습

절단 작업은 유한 시간 단계 TTT를 가진 episodic Markov Decision Process로 정의된다. 상태 공간 S\mathcal{S}S, 행동 공간 A\mathcal{A}A, 전이 확률 함수 P\mathcal{P}P, 보상 함수 R\mathcal{R}R, 할인율 γ\gammaγ로 구성된다. 에이전트는 상태 st\mathbf{s}_tst​를 관찰하고 정책 π\piπ에 따라 행동 at\mathbf{a}_tat​를 선택하며, 다음 상태 st+1\mathbf{s}_{t+1}st+1​과 보상 rtr_trt​를 받는다.

학습 알고리즘은 soft actor-critic, 즉 SAC를 사용한다. SAC는 오프폴리시 액터-크리틱 기반 최대 엔트로피 강화학습 알고리즘으로, 기대 보상을 최대화하면서 탐색을 장려하는 엔트로피 항도 함께 최적화한다. 리플레이 버퍼를 사용해 이전 경험의 재사용이 가능하고, 논문은 우선순위 경험 재생으로 확장할 수 있다고 언급한다.

RL 에이전트의 관측값에는 목표 위치 기준 칼 위치, 속도, jerkiness, 이전 행동, 그리고 센서에서 얻은 nnn개 힘-토크 읽기 값의 히스토리가 포함된다. 액터 네트워크는 TCN과 fully connected network를 조합한다. TCN은 힘-토크 히스토리를 처리하고, fully connected network는 나머지 관측값을 처리하며, 두 출력은 64차원 특징으로 연결된 뒤 추가 fully connected network로 이어진다.

에이전트의 행동은 FDCC에 전달되는 기준 궤적 xc\mathbf{x}^cxc와 제어 파라미터 [Kc,Kp,Kd][K^c, K^p, K^d][Kc,Kp,Kd]이다. 이 값들은 낮은 제어 주기로 제공되고, FDCC는 로봇의 최고 가능 제어 주기로 관절 명령을 생성한다.

컴플라이언스 컨트롤

접촉이 많은 음식 절단 작업에는 Forward Dynamics Compliance Control, 즉 FDCC를 사용한다. FDCC는 임피던스 제어, 어드미턴스 제어, 힘 제어를 하나의 카티시안 컴플라이언스 전략으로 결합한다. 가상 모델의 forward dynamics와 forward kinematics을 이용해 카티시안 입력을 관절 제어 명령으로 직접 매핑하기 때문에 특이점 근처에서도 안정성이 좋다고 설명된다.

컨트롤러는 로봇 엔드 이펙터의 카티시안 위치 x\mathbf{x}x, 관절 위치, 측정 접촉력 Fext\mathbf{F}_{ext}Fext​, 목표 자세와 wrench xd\mathbf{x}^dxd, Fd\mathbf{F}^dFd, 명령 wrench Fc\mathbf{F}^cFc를 사용한다. 가상 모델의 forward dynamics와 forward kinematics은 각각 H−1JTH^{-1}J^TH−1JT와 FK(q)FK(q)FK(q)로 표현된다. 컨트롤러는 강성 KcK^cKc와 PD 이득 KpK^pKp, KdK^dKd로 파라미터화된다.

보상 함수는 칼의 높이, 접촉력, 움직임의 jerkiness를 기반으로 정의된다. 칼 높이는 도마 기준 xcutx_{cut}xcut​이고, 접촉력은 Fext\mathbf{F}_{ext}Fext​이며, jerkiness는 x...\dddot{\mathbf{x}}x...​로 표현된다.

r=w1tanh⁡(∣xcut∣)−w21+e∥Fext∥−w3∥x...∥+Pr = w_1 \tanh(|x_{cut}|) - \frac{w_2}{1 + e^{\|\mathbf{F}_{ext}\|}} - w_3 \|\dddot{\mathbf{x}}\| + \mathfrak{P}r=w1​tanh(∣xcut​∣)−1+e∥Fext​∥w2​​−w3​∥x...​∥+P

논문은 작업 완료, 도마 충돌, 정의된 워크스페이스 이탈, 시간 초과를 episode 종료 조건으로 정의한다고 설명한다.

실로봇에서 수행한 네 가지 식품의 절단 접촉력을 비교한다. 오이, 토마토, 감자, 당근 모두에서 제안 방법이 베이스라인보다 낮은 접촉력을 보인다고 설명된다.

그림 8. 실제 로봇에서의 평가: 오이를 두 번 슬라이싱하는 동안 칼에 작용하는 수직 접촉 힘. 회색 영역은 채소를 자르는 구간을 나타내며, 노란 영역은 도마와의 접촉을 나타낸다. (출처: 원 논문)

오이를 두 번 자를 때 칼에 작용하는 정규 방향 접촉력을 보여준다. 회색 영역은 식품 절단 구간이고, 노란 영역은 도마 접촉 구간이다. 재료와 도마 사이의 갑작스러운 강성 변화에 더 잘 대응하는 모습을 확인할 수 있다.

실험 결과

실로봇 플랫폼은 두 개의 Universal Robots UR5e 팔로 구성된다. 각 팔에는 병렬 그리퍼와 힘-토크 센서가 장착되며, 절단용 팔의 Robotiq 85 병렬 그리퍼에는 주방 칼을 부착할 수 있는 커스텀 핑거 어댑터가 설치된다. 실험에서는 한 팔이 식품을 고정하고 다른 팔이 단일 슬라이스 절단 동작을 수행한다.

보정에는 세 가지 식품이 사용됐다. 토마토는 낮은 강성, 오이는 중간 강성, 감자는 높은 강성을 대표한다. 실제 데이터 수집 시 칼 속도는 일정하게 유지했다. 검증에는 오이, 토마토, 감자, 당근 네 가지가 사용됐고, 이 중 당근은 보정에 쓰이지 않은 식품으로 일반화 성능을 평가하는 데 활용됐다.

베이스라인은 Gazebo 단독 환경에서 절단 동작을 시뮬레이션하고 정책을 학습하는 방식이다. 베이스라인에서는 압축 스프링을 prismatic joint로 모델링하고, Error Reduction Parameter와 Constraint Force Mixing 파라미터를 조정한다. 조정 목표는 스프링이 최대까지 눌릴 때 필요한 힘이 실제 힘 프로파일의 최대 힘과 일치하도록 하는 것이다.

두 환경 모두 보정 후 RL 에이전트를 80K time steps 동안 학습했다. 학습 중에는 보정된 식품 중 하나를 CutSim에 로드하는 domain randomization을 수행하고, 시뮬레이션 파라미터에 작은 균일 분포 노이즈를 주입했다. 베이스라인에도 유사한 노이즈가 적용됐다. 논문은 학습이 약 60K time steps에서 수렴한다고 보고한다.

실로봇 평가에서는 음식 낭비를 줄이기 위해 각 식품 하나씩만 사용했다. 실험 조건은 다음과 같다.

절단 접촉력 비교에서 제안 방법은 모든 식품에서 베이스라인보다 더 낮은 접촉력을 보였다. 특히 보정에 포함되지 않은 당근에서도 제안 방법이 더 좋은 결과를 나타냈다. 오이 절단 실험에서는 재료와 도마 사이의 갑작스러운 강성 변화 구간에서 제안 방법이 더 부드럽게 대응하는 경향이 관찰됐다.

한계

저자가 직접 밝힌 주요 한계는 계산 시간 증가다. 고충실도 절단 시뮬레이터 DiSECt를 사용하면 단순한 Gazebo 단독 환경보다 RL 정책 학습에 더 많은 시간이 필요하다. 논문에서는 듀얼 시뮬레이션 환경 사용 시 약 40시간, Gazebo 단독 사용 시 약 4시간이 걸렸다고 보고한다. 이 차이는 DiSECt의 각 시뮬레이션 시간 단계가 더 높은 계산 요구를 가지기 때문이라고 설명된다. 저자는 추가 계산 시간이 실로봇 성능 향상으로 정당화된다고 보면서도, 향후 계산 시간을 줄이는 방법을 연구할 가치가 있다고 언급한다.

비판적 검토

강점

  • 이중 시뮬레이터 구성의 실용성 — CutSim(DiSECt)의 절단 접촉 물리와 RoboSim(Gazebo/ROS)의 로봇 동작을 병렬로 연결해, 절단 물리만 다루는 기존 시뮬레이터와 실제 로봇 실행 가능성을 동시에 고려한다는 점이 명확하다 (근거: 1절, 3.B절, 그림 1·2).
  • 실제 로봇에서 baseline 대비 접촉력 감소 — Gazebo-only baseline과 비교해 오이·토마토·감자·당근 모두에서 실제 절단 접촉력이 낮게 보고되고, 학습에 쓰지 않은 당근에서도 같은 경향이 보인다 (근거: 4.B절, 그림 7).
  • RL로 FDCC 파라미터까지 학습 — 로봇 동작뿐 아니라 compliance controller의 Kc,Kp,KdK^c,K^p,K^dKc,Kp,Kd를 RL agent가 출력하도록 설계해 수동 튜닝 부담을 줄이는 방향이 명확하다 (근거: 3.C.3절, 그림 4).

약점·의문

  • baseline이 단순하고 비교가 제한적 — baseline은 Gazebo에서 압축 스프링으로 최대 힘만 맞추는 방식이라, 제안법의 우위가 이중 시뮬레이터 효과인지, 아니면 더 정교한 캘리브레이션/RL 튜닝 때문인지 분리하기 어렵다 (근거: 4.A.2절, 그림 6·7) (해석).
  • 실제 실험의 통계적 근거가 부족 — 식품당 1개만 사용하고 슬라이스 횟수도 5~15회로 적으며, 표나 본문에 평균·분산·성공률·유의성 검정이 없어 “일관되게 우수하다”는 주장이 강하게 뒷받침되지 않는다 (근거: 표 2, 4.B절, 그림 7·8) (해석).
  • 일반화 범위가 제한적 — 검증은 단면 절단 1회, 일정 칼 속도, 유사한 채소 4종에 머물러 있고, “unseen objects” 주장도 당근 하나만 근거로 삼아 다른 형상·경도·연질 식품으로 확장하기는 이르다 (근거: 2.A절, 4.A.3절, 표 2) (해석).
  • 캘리브레이션의 정량적 검증이 부족 — DiSECt 파라미터 범위만 제시하고 최종 값, 실측 힘 프로파일과의 오차 지표, TPE+Adam 반복 횟수/수렴 기준을 보고하지 않아 “고충실도 시뮬레이션”이라는 전제가 충분히 확인되지 않는다 (근거: 3.B.1절, 표 1, 그림 6).
  • 안전성·성공 지표가 접촉력에 편중 — reward에는 task completion/collision이 있지만 실제 평가는 주로 접촉력 곡선이고, 절단 성공률, 두께 일관성, 실패 사례, 안전 한계 초과 여부 등이 없어 “safe/accurate” 결론으로 연결되기 어렵다 (근거: 3.C.4절, 4.B절) (해석).

재현 가능성

  • 본문은 오픈소스임을 주장하지만, 코드 저장소·실측 데이터셋·최종 캘리브레이션 파라미터가 논문에 제시되지 않아 재현에 부족하다 (근거: 1절, 표 1).
  • SAC/TCN 구조, reward 가중치 w1,w2,w3w_1,w_2,w_3w1​,w2​,w3​, 임계값, domain randomization 노이즈 범위, 계산 환경이 명시되지 않아 80K step 학습과 40h 대비 4h 결과를 재현하기 어렵다 (근거: 3.C절, 4.A.3절, 5절).

내 생각

관련 논문

  • DiSECt [4]: 연질 재료 절단을 위한 미분 가능 시뮬레이터로, 파라미터 추정과 로봇 절단 제어에 사용된다.
  • RoboNinja [15]: 다종 재료 절단을 위한 시뮬레이터와 적응형 절단 정책 학습을 제안한 선행 연구다.
  • DeepMPC [2] 및 데이터 기반 MPC 기반 음식 절단 연구 [11]: 복잡한 접촉 작업에 학습된 모델 예측 제어를 적용한 접근이다.
  • DMP 기반 데모스트레이션 학습 [12]과 deep segmented DMP [13]: 인간 데모스트레이션에서 절단 동작을 학습하거나 일반화하는 방법이다.
  • RL 기반 compliant vegetable cutting [14]: 강화학습을 이용해 채소 절단 시 컴플라이언스 동작을 학습한 연구다.
  • variable compliance control [24]와 rigid position-controlled robot force control [34]: RL로 힘 제어 또는 가변 컴플라이언스 정책을 학습한 관련 작업이다.
  • FDCC [33]: 이 논문에서 저수준 컴플라이언스 컨트롤러로 사용한 forward dynamics 기반 카티시안 컴플라이언스 방법이다.
  • SAC [31], prioritized experience replay [32], TCN [35]: RL 알고리즘, 경험 재생 확장, 시계열 관측 처리에 인용된 주요 방법론이다.
  • dual simulator approach [25]: 리얼리티 갭을 줄이기 위해 두 시뮬레이터를 사용한 선행 연구다.
  • Gazebo [5]와 ROS [29]: 로봇 시뮬레이션과 시스템 통합에 사용된 오픈소스 소프트웨어 기반이다.
