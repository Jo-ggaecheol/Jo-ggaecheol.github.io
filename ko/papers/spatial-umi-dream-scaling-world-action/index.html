Spatial-UMI-Dream: Scaling World Action Models with Metric Geometry for UMI Manipulation

Spatial-UMI-Dream은 RGB·metric depth·action을 함께 예측하는 5B 월드 액션 모델로, 605시간 UMI 데이터에서 두 단계 사전학습을 수행한다. RoboTwin-UMI 시뮬레이션 벤치마크와 실세계 이두 조작 작업에서 in-domain 성능과 환경·로봇 embodiment 일반화 성능을 평가한다.

Weiduo Yuan, Ze Yuan, Sihan Liu, Jionghao Wang, Liang Heng, Zhenyu Zhao, Yue Wang, arXiv, 2025

TL;DR

  • UMI 데모의 이동 손목 카메라가 객체 운동과 얽히고, 로봇 엠보디먼트(embodiment)·환경 변화 평가가 부족하다는 문제를 다룬다.
  • RGB와 메트릭 깊이(metric depth), 액션을 함께 예측하는 5B world-action model Spatial-UMI-Dream을 605시간 UMI 데이터로 학습한다.
  • RoboTwin-UMI 인도메인 성공률 79.10%, 엠보디먼트+환경 시프트 72.15%, 실세계 6개 태스크 평균 85.0%를 보고한다.

문제 정의

Universal Manipulation Interface(UMI)는 로봇에 독립적으로 데모를 수집할 수 있지만, 그립퍼에 장착된 카메라가 물체 근처에서 이동하기 때문에 카메라 운동과 객체 운동이 서로 얽힌다. RGB 관측만으로는 메트릭 기하학이 암시적으로만 표현되므로, 정밀한 접촉·정렬·양손 협응이 필요한 작업에서 거리 정보가 약해진다.

또한 기존 UMI 기반 정책은 로봇 엠보디먼트 변화와 조명 같은 환경 변화에 대한 통제된 평가가 부족하다. 이 논문은 명시적 메트릭 깊이를 도입하고, 세계 모델과 액션 예측을 결합하는 Spatial-UMI-Dream을 제안하며, RoboTwin-UMI 벤치마크로 크로스-엠보디먼트와 환경 일반화를 평가한다.

핵심 아이디어

Spatial-UMI-Dream은 UMI 관측을 RGB와 메트릭 깊이가 나란히 배치된 캔버스로 변환하고, 세계 모델이 미래 영상과 액션을 동시에 예측하게 한다. 이동 카메라의 운동과 객체 운동을 명시적 깊이로 분리하면, 정밀 조작에 필요한 거리·정렬 정보가 강화되고 엠보디먼트나 조명 변화에도 견고해진다. 모델은 과거 시각 토큰 Z<iZ_{<i}Z<i​, 현재 상태 sis_isi​, 텍스트 ℓ\ellℓ에 조건부하여 미래 시각 토큰과 액션을 결합 분포에서 생성한다:

방법론

메트릭 RGB-D 관측 구성

UMI 그립퍼 하나에는 3개의 카메라가 장착된다. 중앙과 오른쪽 카메라를 보정하고 정렬한 뒤 Fast FoundationStereo로 메트릭 깊이를 추정한다. 이후 원래 중앙 fisheye 좌표계로 역매핑하여 RGB와 정렬된 깊이 DteD_t^eDte​를 만든다.

깊이는 Marigold에서 영감을 받은 인코딩을 사용한다. 고정 경계값 dmin⁡=0.01 md_{\min}=0.01\,\text{m}dmin​=0.01m, dmax⁡=1.5 md_{\max}=1.5\,\text{m}dmax​=1.5m로 정규화한 뒤 Turbo 컬러 매핑 ϕ\phiϕ를 적용한다.

두 그립퍼의 RGB와 인코딩된 깊이는 2×22\times 22×2 캔버스로 배치한다. 각 패널은 160×160160\times 160160×160으로 리사이즈되어 전체 프레임은 320×320320\times 320320×320이 된다.

결합 world-action 모델

Wan VAE가 시각 토큰을 생성하고, 텍스트 인코더가 cross-attention을 통해 언어 토큰을 제공한다. 공유 transformer는 block-causal attention을 사용해 과거 시각 히스토리에 조건부화하며, 미래 RGB-D 관측과 액션을 함께 디노이즈한다.

앞에서 소개한 결합 분포는 flow-matching 목적함수로 학습된다. 청정 타겟 xxx와 가우시안 노이즈 ϵ\epsilonϵ으로 xτ=(1−τ)x+τϵx_\tau=(1-\tau)x+\tau\epsilonxτ​=(1−τ)x+τϵ를 구성하고, 속도 ϵ−x\epsilon-xϵ−x를 예측한다.

LFM=E[w(τ)∥vθ(xτ,τ;c)−(ϵ−x)∥22]\mathcal{L}_{\mathrm{FM}} = \mathbb{E}\left[ w(\tau)\left\|v_\theta(x_\tau,\tau;c)-(\epsilon-x)\right\|_2^2 \right]LFM​=E[w(τ)∥vθ​(xτ​,τ;c)−(ϵ−x)∥22​]

전체 손실은 RGB-D 세계 예측 손실 Lworld\mathcal{L}_{\mathrm{world}}Lworld​와 액션 손실 λaLaction\lambda_a\mathcal{L}_{\mathrm{action}}λa​Laction​의 합이다. joint world-action training과 fine-tuning에서는 λa=1\lambda_a=1λa​=1을 사용한다.

2단계 학습

모델은 Wan2.2-TI2V-5B에서 초기화된다. 전체 diffusion transformer는 학습되고, 텍스트 인코더·이미지 인코더·비디오 VAE는 고정된다.

  1. World-only adaptation
    액션 브랜치를 비활성화하고 로봇 상태 조건부화를 해제한 뒤 Lworld\mathcal{L}_{\mathrm{world}}Lworld​만 최적화한다. 목적은 이동하는 UMI fisheye 관측과 RGB-D 캔버스 레이아웃에 백본을 적응시키는 것이다.

  2. Joint world-action training
    Stage 1 체크포인트로 초기화하고, 액션 인코더/디코더와 로봇 상태 조건부화를 추가한다. 이후 Lworld+λaLaction\mathcal{L}_{\mathrm{world}}+\lambda_a\mathcal{L}_{\mathrm{action}}Lworld​+λa​Laction​을 최소화한다.

학습은 605시간 분량의 RGB-D UMI 데이터로 수행된다. 각 단계는 30,000 steps이며, NVIDIA RTX PRO 6000 GPU 24개를 사용한다. 옵티마이저는 AdamW이고, 학습률은 10−510^{-5}10−5, cosine schedule과 첫 5% warmup을 사용한다.

데모 필터링과 배포 보상

데모 데이터는 Dexmate Vega1 역운동학 풀이 후 ManiSkill에서 리플레이하여 검증한다. 로봇 운동학적 한계를 위반하는 에피소드는 제거한다. 속도·가속도·jerk의 99th percentile을 초과하는 에피소드도 전체 삭제한다.

배포 시 그립퍼 명령 보상을 적용한다. 그립퍼 응답을 지연 δ\deltaδ와 시간상수 τ\tauτ를 가진 1차 응답 모델로 근사하고, 이를 역산하여 명령을 전진 보정한다.

uk=clip⁡(rk+1+δ−αrk+δ1−α,0,wmax⁡)u_k= \operatorname{clip}\left( \frac{r_{k+1+\delta}-\alpha r_{k+\delta}}{1-\alpha}, 0, w_{\max} \right)uk​=clip(1−αrk+1+δ​−αrk+δ​​,0,wmax​)

여기서 rkr_krk​는 측정된 그립퍼 상태이고, α=exp⁡(−h/τ)\alpha=\exp(-h/\tau)α=exp(−h/τ), wmax⁡w_{\max}wmax​는 최대 개폐도이다. 이 보상으로 연속 목표 궤적에서 평균 절대 추적 오차가 12.49 mm에서 2.85 mm로 감소한다.

RoboTwin-UMI 벤치마크

RoboTwin-UMI는 기존 RoboTwin 태스크를 유지하면서 UMI 관측과 그립퍼에 맞게 조정한다. Aloha-AgileX와 ARX-X5 두 로봇 엠보디먼트에 UMI 그립퍼와 손목 fisheye 카메라를 장착하고, 조명을 랜덤화할 수 있다.

시뮬레이션 렌더링에서는 4개의 공동심 핀홀 뷰를 사용해 fisheye 이미지를 만든다. 전방 뷰 시야각은 92∘92^\circ92∘, 보조 뷰는 106∘106^\circ106∘이다. Kannala-Brandt(KB4) 모델로 광선 추적한 뒤 가장 가까운 광축을 가진 카메라에서 샘플링한다.

평가 설정은 태스크당 Aloha-AgileX 클린 데모 50개를 사용하고, 조명(청정/랜덤화)과 로봇(Aloha/ARX-X5)을 독립적·결합적으로 변경하는 4가지 조건으로 구성된다. 각 태스크당 100개 에피소드를 평가한다.

비판적 검토

강점

  • UMI 관측의 카메라 운동과 객체 운동을 분리하는 메트릭 깊이 표현 — 이동하는 UMI fisheye RGB에서 암시적으로 섞인 카메라/객체 운동을 명시적 metric depth로 변환해 World Action Model에 주입한다 (근거: 1절, 2A, Fig. 3).
  • UMI 관측과 시프트 평가를 표준화하는 벤치마크 — RoboTwin-UMI가 fisheye 렌더링, 두 로봇 종족(Aloha-AgileX/ARX-X5), 조명·종족 결합 시프트, 태스크별 스텝 한계를 통제 가능하게 제공한다 (근거: 2E, Fig. 6, Table IV).
  • 핵심 구성 요소의 기여를 정량적으로 분리 — RGB-only 대비 RGB-D가 인도메인 +5.75%p, 결합 시프트 +8.25%p, 실세계 80.8% → 85.0%를 보이고, 2단계 학습이 39.50% → 61.25% → 79.10%로 기여함을 보여준다 (근거: Fig. 9, 3D).
  • 데이터 품질과 그립퍼 제어 신호 보정 — 역운동학/리플레이 기반 필터링과 1차 응답 모델 보정으로 그립퍼 추적 오차를 12.49mm → 2.85mm로 줄인다 (근거: 2D, Fig. 4, Fig. 5).

약점·의문

  • 베이스라인의 학습 비용 불균등 가능성 — Spatial-UMI-Dream은 605시간 RGB-D UMI pretraining과 2단계 학습을 받았지만, π0.5\pi_{0.5}π0.5​, RDT2-FM, Fast-WAM, LingBot-VA가 동일한 pretraining 데이터·규모·학습 단계로 준비되었는지 제공된 자료에서 확인 불가하다 (근거: 3A, Table III; 부록 메모).
  • 통계적 유의성 미보고 — 시뮬레이션은 태스크당 100 에피소드, 실세계는 20 에피소드로 평가하지만 표준편차·신뢰구간·반복 실행 수·시드 분포가 제공된 자료에 없어 +4.65%p, +7.20%p 등 차이가 노이즈 범위인지 판단 불가하다 (근거: 3B, 3C, Table I/II; 부록 메모).
  • 일반화 평가 축이 제한적 — RoboTwin-UMI에서 조명만 랜덤화하고 배경·클러터·테이블 높이·카메라 랜덤화는 비활성화하며, 두 로봇 종족과 UMI fisheye 관측 외의 시프트는 평가되지 않아 “robot-independent” 또는 광범위한 일반화 주장에 비해 근거가 제한적이다 (근거: 2E, 부록 메모 randomized-lighting).
  • 구성 요소 아블레이션이 부족 — metric depth와 2단계 학습만 있고, 깊이 인코딩 방식 Φ(D)\Phi(D)Φ(D)(식 1), stereo vs monocular/learned depth, robot state conditioning, λa\lambda_aλa​, 텍스트 조건부화 등 다른 설계 선택의 효과는 제공된 자료에서 확인 불가하다 (근거: 3D, Fig. 9; 부록 메모).
  • 재현에 필요한 데이터·파라미터가 불완전 — 코드/데이터 공개 여부가 제공된 자료에 명시되지 않으며, 605시간 데이터 출처, 스테레오 보정/Fast FoundationStereo 파라미터, fisheye 역매핑 세부, 데모 필터링 임계값(99th percentile 기준)이 재현에 필요한데 부록에 일부만 있다 (근거: 2A, 2D; 제공된 자료에서 코드/데이터 공개 언급 없음).
  • 추론·배포 비용 미보고 — 학습 GPU 수와 steps는 있지만 총 학습 시간, 추론 지연, 정책 실행 속도, test-time future imagination 비용이 제공된 자료에 없어 WAM의 실제 조작 배포 영향이 불명확하다 (근거: 2C, Table III; 부록 메모).

재현 가능성

  • 코드·데이터 공개 여부는 제공된 요약에서 확인 불가. 학습 단계별 batch/GPU/학습률 등은 Table III과 부록에 있으나, 605시간 데이터 출처, 깊이 재구성 파이프라인 세부 파라미터, 데모 필터링 임계값이 재현에 필요한데 불완전하다.
