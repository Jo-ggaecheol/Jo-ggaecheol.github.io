Vision-Language-Action or World-Action? Just Action Models

VLA와 WAM의 차이를 백본 초기화·미래 관측 목표·추론 모듈로 분리하고, 시각 생성 없이 동결된 미래 표현을 예측하는 foresight loss만 추가한 Just Action Model(JAM)을 제안한다. LIBERO/LIBERO-Plus/RoboTwin에서 대응 FastWAM/ImageWAM보다 성공률을 유지하거나 높이고, 캐시된 목표는 FastWAM 대비 온라인 학습 FLOPs를 73% 줄인다.

Yonghao Yu, Runyi Li, Lang Huang, Toshihiko Yamasaki, arXiv, 2026

TL;DR

  • Just Action Model(JAM)은 시각-언어-액션(Vision-Language-Action, VLA)과 세계-액션(World-Action, WAM)을 구분하는 백본 초기화, 미래 관측 목적 함수, 추론 모듈 세 선택을 분리한다.
  • 학습 전용 고정된 미래 앵커(frozen future anchor)로 현재 특징이 미래 표현을 예측하도록 직관 손실(foresight loss)을 추가하고, 추론 시 이 분기를 폐기한다.
  • 동일 조건에서 WAM 대비 LIBERO-Plus를 최대 14.7%p 개선하고, 캐시된 목표 사용 시 온라인 FLOPs를 최대 73% 줄인다.

문제 정의

VLA와 WAM 커뮤니티는 로봇 제어 정책의 사전 학습 지식 출처가 비전-언어 모델인지, 시각 생성기인지에 대해 논쟁해 왔다. 그러나 기존 논의는 실제로 독립적인 세 가지 선택을 하나의 대립으로 압축한다.

첫째, 백본 초기화(backbone initialization)다. 둘째, 기록된 미래 관측값에 적용하는 목적 함수(objective on future observations)다. 셋째, 추론 시 유지하는 모듈(machinery kept at inference)이다. VLA는 보통 액션 플로우 매칭(flow matching) 손실만 사용하고, WAM은 시각 생성 손실을 추가한다. 일부 WAM은 생성된 미래 관측을 다시 액션 전문가(action expert)에 입력하기도 한다.

이 논문이 풀려는 문제는 이 세 선택을 분리해서 평가하는 것이다. JAM은 시각 생성 없이도 미래 관측 정보가 정책 표현을 개선할 수 있는지, 그리고 그 개선이 추론 비용 증가 없이 유지되는지 확인한다.

핵심 아이디어

JAM의 직관은 “미래를 생성하지 않고도 미래를 예측하도록 특징을 훈련한다”는 것이다. 학습 시에는 기록된 미래 관측을 고정된 미래 앵커로 인코딩하고, 현재 관측에서 나온 정책 특징이 그 미래 표현을 예측하도록 작은 예측 헤드를 붙인다. 이 감독은 시각 픽셀을 복원하는 생성 손실이 아니라, 표현 공간에서의 코사인 유사도 기반 직관 손실을 사용한다.

핵심 목적 함수는 다음과 같다.

LJAM=Lact+λFLF\mathcal{L}_{\mathrm{JAM}} = \mathcal{L}_{\mathrm{act}} + \lambda_{\mathrm{F}} \mathcal{L}_{\mathrm{F}}LJAM​=Lact​+λF​LF​

여기서 Lact\mathcal{L}_{\mathrm{act}}Lact​는 액션 생성 손실이고, LF\mathcal{L}_{\mathrm{F}}LF​는 직관 손실이다. 학습이 끝나면 미래 앵커 분기와 예측 헤드를 제거하고, 배포에는 백본과 액션 전문가만 남는다.

방법론

문제 공식화

데이터 샘플은 현재 관측 f0f_0f0​, 로봇 상태 s0s_0s0​, 지시어 ccc, 액션 청크 a1:Ha_{1:H}a1:H​, 기록된 미래 관측 f1:Tf_{1:T}f1:T​로 구성된다. 배포 인터페이스는 f0,s0,cf_0, s_0, cf0​,s0​,c로부터 a1:Ha_{1:H}a1:H​를 예측한다.

VLA와 WAM의 차이는 미래 관측에 대한 목적 함수로 정리할 수 있다. VLA는 액션 손실만 사용하고, WAM은 시각 생성 손실을 추가한다. JAM은 이 둘 대신 직관 손실을 사용하며, 학습과 추론 모두에서 시각 생성을 수행하지 않는다.

직관 감독

시각 백본은 f0f_0f0​를 인코딩하고, 텍스트 조건이 지원되면 ccc도 함께 사용한다. 액션 전문가는 시각 컨텍스트, ccc, s0s_0s0​, 노이즈된 액션 청크 a~1:H\widetilde{a}_{1:H}a1:H​를 입력으로 받는다.

백본의 ℓ\ellℓ번째 블록에서 현재 관측 토큰을 h(ℓ)∈RN×D\mathbf{h}^{(\ell)} \in \mathbb{R}^{N \times D}h(ℓ)∈RN×D로 표기한다. 고정된 미래 앵커 EφE_{\varphi}Eφ​는 기록된 미래 f1:Tf_{1:T}f1:T​를 처리하고, 읽기 오프셋(readout offset) kkk에 해당하는 목표 특징 gk∈RN×Dg\mathbf{g}_k \in \mathbb{R}^{N \times D_g}gk​∈RN×Dg​를 만든다. 학습 가능한 예측 헤드 ppp는 정책 토큰 h(ℓ)\mathbf{h}^{(\ell)}h(ℓ)를 목표 공간으로 매핑해 g^k\hat{\mathbf{g}}_kg^​k​를 생성한다.

직관 손실은 다음과 같다.

LF=1∣K∣∑k∈KEn[1−cos⁡(g^k,n,sg⁡[gk,n])]\mathcal{L}_{\mathrm{F}} = \frac {1}{| \mathcal {K} |} \sum_ {k \in \mathcal {K}} \mathbb {E} _ {n} \left[ 1 - \cos \left(\hat {\mathbf{g} } _ {k, n}, \operatorname{sg} [ \mathbf{g} _ {k, n} ]\right) \right]LF​=∣K∣1​k∈K∑​En​[1−cos(g^​k,n​,sg[gk,n​])]

여기서 K\mathcal{K}K는 감독 대상 오프셋 집합이고, nnn은 공간 토큰 인덱스이며, sg⁡\operatorname{sg}sg는 그라디언트 정지(stop gradient)를 뜻한다. 목표 특징에는 그래디언트가 전달되지 않는다.

오프셋 [0]은 현재 위치를, [1] 이상은 미래 위치를 가리킨다. FastWAM 계열에서는 4개 환경 스텝을 하나의 VAE 라텐트 위치로 묶어 [1]이 스텝 4~16, [2]가 스텝 20~32에 대응한다. 다른 백본은 보통 16스텝 앞 단일 프레임을 [1]로 사용한다.

사전 학습 패밀리별 구현

  • 생성기 기반: Wan2.2-5B, Yak18/Ovis-U1, FLUX.2 계열을 사용할 수 있다. JAM에서는 백본이 깨끗한 현재 프레임만 보고, 미래 앵커는 사전 학습 VAE 또는 랜덤 초기화 백본으로 대체할 수 있다.
  • 자기 감독 기반(self-supervised): DINOv2-B/L은 언어 입력과 생성 헤드를 사용하지 않는다. 액션 전문가는 백본 트랜스포머 블록을 미러링하고, 별도 텍스트 인코더가 지시어 특징을 제공한다.
  • 비전-언어 모델(Vision-Language Model, VLM): Qwen3.5-2B는 이미지와 텍스트를 동시에 처리한다. 액션 전문가는 백본 블록을 미러링하고, 이미지·텍스트·액션 토큰에 대한 인과적 토큰 믹싱(causal token mixing)을 사용한다.

학습 비용과 배포

학습 후 앵커 분기와 예측 헤드를 제거한다. 배포 시 백본이 f0f_0f0​와 ccc를 한 번 인코딩하고, 액션 전문가는 플로우 매칭 샘플링 단계에서 컨텍스트를 재사용한다.

직관 목표를 캐시하면 온라인 훈련 계산이 줄어든다. 구체적인 감소폭은 실험 결과에서 정리한다.

실험 결과

벤치마크는 LIBERO(Spatial, Object, Goal, Long), LIBERO-Plus, RoboTwin 2.0이다. LIBERO는 40개 태스크를 각 50회 롤아웃하고, LIBERO-Plus는 ImageWAM의 15% 서브셋 프로토콜을 따라 스위트별 시드를 고정해 1,506개 교란된(perturbed) 태스크 매니페스트를 각 1회 평가한다. RoboTwin 2.0은 clean/randomized 설정의 50개 양손 조작(bimanual manipulation) 태스크를 사용한다. 비교 정책은 데이터, 정책 아키텍처, 옵티마이저, 훈련 예산, 평가자를 공유한다.

LIBERO에서는 FastWAM 레시피 20k 업데이트(batch size 128), ImageWAM 레시피 21.7k 업데이트(batch size 128)를 사용한다. RoboTwin 2.0에서는 FastWAM 5 epoch·29,355 업데이트(batch size 1,024), ImageWAM 레시피 69,900 업데이트(batch size 384)를 사용한다.

비판적 검토

강점

  • VLA/WAM을 세 독립 변수로 분리하는 개념 정리 — 백본 초기화, 미래 관측 목적 함수, 추론 시 유지되는 모듈을 구분하고 JAM을 공통 프레임워크로 제시해 기존 논쟁의 혼선을 줄인다 (근거: Figure 1, 2.1절).
  • 동일 조건 비교와 폭넓은 ablation — 동일 데이터·정책 아키텍처·훈련 예산 하에서 FastWAM/ImageWAM baseline과 JAM을 비교하고, anchor 초기화, readout depth, loss weight, prediction-head capacity, action-only control, shared weights, training budget까지 검증한다 (근거: 3.2절, Appendix C Table 10–16).
  • 핵심 결과에 통계적 유의성과 실행 간 분산 보고 — LIBERO/LIBERO-Plus에서 JAM 우위를 bootstrap confidence interval과 McNemar test로 보고하고, 독립 3-run의 평균±표준편차도 제공한다 (근거: Appendix D Table 20, Table 21).
  • 학습 비용 절감의 정량화 — cached foresight targets 사용 시 FLOPs와 GPU 시간을 baseline 대비 측정해 효율성 주장을 수치로 뒷받침한다 (근거: Appendix B Table 9).

약점·의문

  • 실물/오픈월드 일반화는 제한적 — 실험이 LIBERO, LIBERO-Plus, RoboTwin 2.0 시뮬레이션에 집중되어 있고, 실물 로봇이나 더 다양한 작업·환경으로의 확장성은 제공된 메모에서 확인되지 않는다 (근거: 3.1절, Table 4–6) (해석).
  • 대안 VLA/WAM 방법과의 직접 비교 부족 — FastWAM/ImageWAM 레시피와 비교하지만, 부록 E에 언급되는 π0\pi_0π0​/π0.5\pi_{0.5}π0.5​, V-JEPA 2-AC 등 다른 대표 정책과 같은 조건에서 직접 비교된 표는 제공된 메모에 없다 (근거: Appendix E, Table 4–6) (해석).
  • 모든 백본·교란 카테고리에서 일관된 이득은 아님 — LIBERO-Plus 카테고리별 분석에서는 Background/Robot-state 등에서 baseline이 우세한 경우가 있고, RoboTwin 2.0에서도 일부 비교의 향상폭이 작다 (근거: 4.4절, Figure 6, Table 4) (해석).
  • ablation의 백본 간 균형 — depth, loss weight, prediction-head capacity ablation은 주로 Wan 기준이고, action-only/shared-weight 분석은 Qwen3.5-2B/DINOv2-L 중심으로 되어 있어 모든 백본에서 동일한 민감도를 보였는지 확인하기 어렵다 (근거: Appendix C Table 10–15) (해석).
  • LIBERO-Plus 평가 횟수 — LIBERO-Plus는 교란 매니페스트당 1회 평가로, bootstrap CI가 제공되더라도 단일 rollout 기반 결과의 변동성 해석에는 주의가 필요하다 (근거: 3.1절, Appendix D Table 20) (해석).
  • 코드·데이터 공개 여부 불명 — 하이퍼파라미터와 비용 분석은 상세하지만, 코드 리포지토리, 데이터셋 접근, 체크포인트, seed/평가 스크립트 등 재현에 필요한 공개 여부는 제공된 메모에서 확인되지 않는다 (근거: Appendix A–B; 제공된 메모에 코드 공개 언급 없음) (해석).

재현 가능성

  • 학습률, 옵티마이저, batch size, updates 수, readout 위치, λF\lambda_{\mathrm{F}}λF​, prediction-head 구조, FLOPs 측정 방식은 상세히 제시되지만, 코드·데이터·체크포인트 공개 여부와 LIBERO-Plus 15% 서브셋 매니페스트 생성 스크립트/seed 설정은 제공된 메모에서 확인되지 않는다 (근거: Appendix A–B; 제공된 메모에 코드 공개 언급 없음) (해석).

내 생각

관련 논문

  • FastWAM, ImageWAM: WAM baseline으로, 각각 test-time future imagination과 image editing/video generation 문제를 다룬다.
  • π0\pi_0π0​ / π0.5\pi_{0.5}π0.5​: open-world generalization을 위한 VLA flow model 계열 연구다.
  • V-JEPA 2(-AC): self-supervised video model, latent prediction, planning/MPC 관련 연구다.
  • Motus: unified latent action world model이다.
  • DINOv2, Wan, Qwen3.5, FLUX.2: JAM 구현에 사용된 백본 계열이다.
  • LIBERO / LIBERO-Plus, RoboTwin 2.0: 평가에 사용된 로봇 조작 벤치마크다.
  • REPA, AGRA, Video-Mirai: 시각 생성과 표현 정렬을 함께 다루는 연구다.
  • FLARE, FRAPPE, VLAFlow: action policy 안에 future/state/action token이나 LoRA stream을 결합하는 예측 표현 연구다.
  • VPP, Seer: 예측 시각 특징을 제어에 연결하는 video-based policy 계열이다.
  • Burda et al., Sarnthein et al., Bojanowski & Joulin, Grill et al.: random encoder, noise target, EMA encoder 등 frozen/adaptive target 관련 선행 연구다.
