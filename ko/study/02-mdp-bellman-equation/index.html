01큰 그림: 한 층씩 쌓기

02 전체는 구성 요소를 하나씩 얹는 흐름이다. 각 층은 아래 층을 그대로 품는다.

02Markov chain

P( St+1 = s' | St, St−1, …, S0 ) = P( St+1 = s' | St ) Markov 성질: 현재를 알면 과거는 미래 예측에 도움이 안 된다 (과거 정보가 이미 현재에 다 담겨 있다)

전이 확률이 시간과 무관하면(time-homogeneous, "어제의 규칙 = 오늘의 규칙") 행렬 하나 Pss'로 쓰고, 각 행의 합은 1이다. 고정된 건 규칙 P이고, 상태 분포 μt는 계속 변할 수 있다.

예: 로봇 2-상태 체인

현재 \ 다음작업(W)충전(C)
작업(W)0.90.1
충전(C)0.50.5
μt+1 = μt P  ⇒  μt = μ0 Pt,    μ* = μ* P 분포의 시간 발전 · 정상분포 = 한 번 더 전이해도 안 변하는 분포 (고유값 1의 왼쪽 고유벡터)

정상분포에서는 들어오는 흐름 = 나가는 흐름이다. 예에서 0.1·μW = 0.5·μC → μ* = (5/6, 1/6). 로봇은 장기적으로 시간의 83%를 작업한다.

언제 존재하고, 유일하고, 수렴하나 (유한 상태)

조건의미보장
irreducible모든 상태끼리 서로 도달 가능정상분포가 유일
+ aperiodic정확히 주기적으로만 돌아오지 않음어떤 μ0에서든 μt → μ*
  • 둘 다면 ergodic: "시간 평균 = 분포 평균". 한 궤적만 오래 따라가도 μ*를 추정할 수 있다. MC/TD가 궤적으로 기댓값을 추정해도 되는 근거다.
  • 쌍마다 흐름이 같을 필요는 없다(detailed balance는 더 강한 조건). 1→2→3→1로만 도는 체인도 정상분포 (⅓, ⅓, ⅓)를 가진다.

현실은 시간 균질이 아니지 않나

현실모델
규칙 자체가 시간에 따라 변함시간 비균질 체인 Pt, nonstationary MDP
머무는 시간이 들쭉날쭉semi-Markov, 연속시간 Markov chain
센서가 일부만 보여줌POMDP (10장)
숨은 파라미터(마찰, 질량)hidden-parameter MDP, meta-RL
비정상성은 대개 상태에 빠진 변수다. 모터 온도, 배터리, 마모를 상태에 넣으면 다시 "같은 상태에서는 같은 규칙"이 된다.

03🤖 Markov는 상태 표현의 성질이다

  • 로봇팔: 관절각 θ만으로는 Markov가 아니고, (θ, θ̇)면 2차 동역학(F = ma)에서 Markov다.
  • 원칙: 상태 = 미래 예측에 필요한 과거의 충분통계량. 과거를 상태에 붙이면(state augmentation) 무엇이든 Markov로 만들 수 있다.
  • DQN이 Atari 프레임 4장을 쌓는 이유, 로봇 정책이 관측 history를 받는 이유가 이것이다. 센서가 상태의 일부만 보여주면 POMDP가 된다(10장).

04에피소드와 종료 상태

에피소드: 초기 상태 S0 ~ μ0에서 시작해 종료 상태에 도달할 때(시각 T, 확률변수)까지의 궤적 하나. 끝나면 리셋하고 다음 에피소드를 시작한다. 종료가 있으면 episodic task, 끝이 없으면 continuing task(γ < 1로 합을 유한하게)다.

용어이 태스크에서
step제어 주기 1번
state관절각·각속도, 그리퍼, 물체 pose
action관절 목표값 또는 토크
terminal성공(z ≥ 30cm), 실패(떨어뜨림, 충돌, 관절 한계)
truncation200 step 안에 못 끝내서 강제로 끊음
truncation ≠ termination. gymnasium이 terminated/truncated를 따로 주는 이유다. 시간 제한으로 끊긴 상태의 가치를 0으로 두면 학습이 틀어진다(05, 07에서 다시).

bandit은 "한 번 당기기 = 길이 1의 에피소드"로 볼 수 있다. 상태는 확률 1로 자기 자신으로 돌아오고, 무작위성은 보상에만 있다.

05MRP: return, 할인율, 가치 함수

Gt = Rt+1 + γRt+2 + γ²Rt+3 + ⋯ = Σk γk Rt+k+1,    Gt = Rt+1 + γ Gt+1 MRP = (S, P, R, γ) · return은 앞으로 받을 보상의 할인 합 · 재귀 구조에서 Bellman 방정식이 나온다

할인율 γ: 얼마나 먼 미래까지 볼 것인가

γ < 1을 쓰는 이유: ① 끝없는 과제에서도 |G| ≤ Rmax/(1−γ)로 유한 ② 먼 미래는 불확실 ③ "빨리 끝내라"는 압력(확인 문제 3).

가치 함수와 Bellman 방정식

V(s) = E[ Gt | St = s ] = R(s) + γ Σs' Pss' V(s') 지금 가치 = 바로 받는 보상 + γ × 다음 상태 가치의 평균 · E[Gt+1 | St+1 = s'] = V(s')가 되는 데 Markov 성질이 쓰인다
V = R + γPV  ⇒  V = (I − γP)−1 R γP의 고유값 크기가 모두 γ 이하라 항상 가역 · 비용 O(n³), 상태가 많으면 반복으로 (9장)

숫자 예: 그림 2의 체인에 작업 보상 1, 충전 보상 0, γ = 0.9를 붙이면 VW ≈ 8.59, VC ≈ 7.03이다. 충전 중이어도 0이 아니다. 곧 작업으로 돌아가서 벌 것까지 반영된다. V는 미래까지 포함한 평가다. 스텝당 평균 보상 μ*W = 5/6에 시야 10스텝을 곱한 8.3 근처가 나오는 것도 정상분포와의 연결이다.

큰 흐름: 미래 보상이 지금의 판단이 되기까지

① 평가 : 미래 보상을 끌어와 지금 상태의 점수 V(s)로 만든다      ← MRP (지금)
② 선택 : 행동마다 "그 뒤에 갈 상태의 점수"를 비교한다          ← MDP의 Q(s,a) (7장)
③ 개선 : 더 좋은 쪽을 고르도록 정책을 바꾼다                  ← 03 DP
   ↺ 정책이 바뀌면 점수도 바뀐다 → ①로 = GPI
우변 R + γV(s')는 05 TD의 target이다. 01에서 "target만 바뀐다"고 했던 그 target이고, 이번엔 자기 추정치 V(s')를 포함한다(bootstrapping). 05·06의 불안정성 이야기가 여기서 시작된다.

06보상 설계: shaping과 hacking

Reward shaping: 길 안내용 보상을 얹기

"성공 +1, 나머지 0"(sparse)이면 랜덤 로봇은 평생 0만 보고 아무것도 못 배운다. 중간 단계마다 힌트 보상을 얹는다.

단계힌트 보상
손이 물체에 가까워짐+ (거리 감소량)
파지 성공+0.5
물체 높이 증가+ (상승량)
30cm 도달+10 (진짜 목표)
F(s, s') = γΦ(s') − Φ(s)  ⇒  G' = G − Φ(s0) potential-based shaping (Ng et al., 1999): 망원급수로 소거되어 상수 하나만 빠진다 → 정책 사이 순위 불변

Reward hacking: 의도가 아니라 숫자를 최대화

  • 물체 세우기: z를 물체 중심 높이로 재면 긴 물체를 세우기만 해도 올라간다.
  • CoastRunners (OpenAI, 2016): 보트가 결승 대신 아이템 재생성 구역을 빙빙 돌았다.
  • 시뮬레이터 버그: 물리 엔진 충돌 오류로 튀어 오르며 "전진".
  • RLHF: 보상 모델의 취향(긴 답, 아부)을 파고든다(10).
보상은 단순하게, 종료/실패 조건은 명확하게, 학습된 행동은 반드시 영상으로 확인한다. return 숫자만 보면 속는다.

무한대 보상, exponential 보상은?

시도문제
성공 보상 ∞성공 확률이 0만 아니면 모든 정책의 V = ∞ → 정책을 비교할 수 없다. 수치적으로 inf/NaN
아주 큰 유한값보상 전체를 c배 해도 최적 정책은 그대로다. 중요한 건 비율. 너무 크면 shaping이 묻혀 sparse와 같아지고, return 분산이 커져 불안정 → 실전은 오히려 reward scaling / clipping(DQN [−1, 1])
exp(z)바닥 근처 신호가 거의 0이라 초반 학습이 안 되고, 꼭대기 근처 스텝당 보상이 커져 떠 있기 hacking이 심해진다
exp(−‖오차‖²/σ)좋은 exponential. (0, 1]로 유계, 목표에서 1. 보행 로봇 속도 추종 보상 등에서 표준

07MDP: 정책, Vπ, Qπ

MDP = (S, A, p, R, γ),   p(s' | s, a),   π(a | s) = P(At = a | St = s) 이제 다음 상태와 보상이 행동에 따라 달라진다 · 정책은 확률적일 수도, 결정적(a = π(s))일 수도 있다

정책을 고정하면 MDP는 MRP가 된다

Pπ(s' | s) = Σa π(a|s) p(s'|s,a),   Rπ(s) = Σa π(a|s) R(s,a)
⇒  Vπ = (I − γPπ)−1 Rπ
  • 상태와 동역학 p는 환경이 정한다. 우리가 고르는 건 정책이다. 정책을 고른다 = 어떤 Markov chain을 만들지 고른다. 좋은 정책은 보상 높은 상태에 오래 머무는 체인을 만든다.
  • "수렴"은 두 가지다: ① 학습의 수렴(정책이 더 안 바뀜 → 체인 고정 → 학습 곡선 평평) ② 고정 정책 아래 분포의 수렴(μt → dπ). 곡선이 평평해도 최적이라는 보장은 없다.

Vπ와 Qπ

질문비유
Vπ(s) = Eπ[Gt | St=s]이 상태에서 앞으로 π를 따르면 얼마를 버나이 칸의 점수
Qπ(s,a) = Eπ[Gt | St=s, At=a]이 상태에서 일단 a를 하고 이후 π를 따르면이 칸에서 이 문으로 나가는 점수

V만 있으면 행동을 비교하려고 p(s'|s,a)가 필요하다. Q는 행동별 점수를 직접 들고 있어서 모델 없이 고를 수 있다 → Q-learning(05), DQN(07).

Vπ(s) = Σa π(a|s) Qπ(s,a),    Qπ(s,a) = R(s,a) + γ Σs' p(s'|s,a) Vπ(s') 서로 대입하면 Bellman expectation 방정식 · 내 선택에 대한 평균과 환경의 무작위성에 대한 평균이 번갈아 나온다

숫자 예: 복도에 행동 붙이기

그림 6에서 정책을 "랜덤"으로 두면 아래 값이 나온다(γ = 0.9, S0에서 ←는 제자리).

S0S1S2S3
Vπ0.2750.3360.4720.712
Qπ(s, ←)0.2470.2470.3020.425
Qπ(s, →)0.3020.4250.6411.000
동전 던지는 랜덤 정책의 Q만 봤는데 모든 칸에서 →가 크다. "Q가 큰 행동을 고르자"로 바꾸면 바로 "항상 →" = 최적 정책. 이게 policy improvement다. 항상 좋아지거나 같다는 보장(policy improvement theorem)은 03에서 증명한다.
Aπ(s,a) = Qπ(s,a) − Vπ(s) advantage: 이 행동이 평소보다 얼마나 나은가 · S1에서 A(→) = +0.089, A(←) = −0.089 · 08 policy gradient, PPO의 GAE가 쓴다
  • PPO (Schulman et al., 2017): advantage가 양수인 행동의 확률은 올리고 음수면 내리되, 새/옛 정책 확률비를 [1−ε, 1+ε]로 clip해서 한 번에 너무 크게 안 바뀌게 한다. 로봇 보행과 RLHF의 표준(09).
  • POMDP: 진짜 상태 대신 관측만 보는 MDP(10장).
🤖 로보틱스 연결 · p(s'|s,a)는 물리 법칙이고 시뮬레이터가 바로 이 p다. π(a|s)는 정책 신경망으로, 관절 명령의 분포(가우시안)를 출력한다. Vπ(s)는 "이 자세와 파지 상태면 성공할 가능성이 얼마나 되나", Qπ(s,a)는 "지금 위로 당기면 vs 그리퍼를 열면"이다. 행동이 연속이라 Q 표를 다 계산하고 max를 고를 수는 없다 → 08, 09.

08최적성: V*, Q*, Bellman optimality

V*(s) = maxπ Vπ(s),   Q*(s,a) = maxπ Qπ(s,a),   π*(s) = argmaxa Q*(s,a) 유한 MDP에는 모든 상태에서 동시에 최선인 결정적 정책 π*가 항상 존재 · Q*만 알면 한 스텝만 보고 고르면 된다

기호 정리

기호읽기뜻
Qπ큐 파이정책 π(지금 습관)를 따를 때의 진짜 점수
Q*큐 스타이후 최적으로 행동할 때의 진짜 점수 (= Qπ*)
Q큐알고리즘이 들고 있는 추정치 (표, 신경망)
Q′큐 프라임별개 표기. 다음 상태의 Q(s′, a′) 또는 DQN target network

항상 Qπ(s,a) ≤ Q*(s,a)다. 위첨자 없는 Q는 대개 "지금 학습 중인 추정치"다.

예: 출근길 (보상 = −분)

왜 행렬 한 번으로 못 푸나

max는 비선형이다. 어떤 행동이 최선인지가 V*에 달려 있고, V*는 또 어떤 행동이 최선인지에 달려 있다. 그래서 반복으로 푼다: value iteration, policy iteration(03), LP.

검산: 복도 V* = (0.729, 0.81, 0.9, 1). S1에서 max(0.9 × 0.729 = 0.656, 0.9 × 0.9 = 0.81) = 0.81 ✓. 랜덤 정책의 Vπ(S1) = 0.336은 평균이지 최댓값이 아니라서 이 방정식을 만족하지 않는다. 최선이 아닌 정책을 걸러내는 기준이다.

🤖 로보틱스 연결 · 연속 시간·연속 상태 버전이 최적 제어의 HJB 방정식이다. 선형 시스템 + 이차 비용이면 V*가 이차식으로 딱 떨어진다 → LQR(03). 그리고 최적은 "주어진 보상에 대해" 최적이다. 보상이 떠 있기를 이득으로 만들면(그림 7) 최적 정책은 정확히 떠 있기다.

09Contraction: 왜 반복하면 반드시 수렴하나

(T*V)(s) = maxa [ R(s,a) + γ Σs' p(s'|s,a) V(s') ],   V* = T*V*,   Vπ = TπVπ Bellman 연산자 = 점수표를 받아 한 스텝 갱신한 점수표를 내놓는 "기계" · Bellman 방정식 = 기계의 고정점
‖TV − TU‖∞ ≤ γ ‖V − U‖∞,    ‖V‖∞ = maxs |V(s)| 기계를 한 번 통과할 때마다 두 추측 사이의 거리가 γ배 이하로 줄어든다

증명

  • Tπ: |(TπV − TπU)(s)| = γ|Σs' Pπss'(V − U)(s')| ≤ γ‖V − U‖∞. R은 빼면 사라지고, P의 행은 가중 평균이라 최댓값을 넘지 못한다.
  • T*: 추가로 |max f − max g| ≤ max |f − g|. max는 비선형이지만 수축성을 깨지 않는다.

꼭 가져갈 세 가지

문제 1그림 2의 체인에서 충전→작업 확률을 0.5에서 0.1로 바꾸면 μ*와 |λ2|는?

μ* = (½, ½), λ2 = 0.8. 한 상태에 오래 머무는 "끈적한" 체인이 되어 섞이는 속도가 느려진다(그림 2의 "끈적한 체인" 버튼). 짧은 궤적으로 장기 평균을 추정하면 오차가 크다.

문제 2자율주행차의 상태를 "현재 카메라 이미지 한 장"으로 잡으면 Markov인가?

아니다. 속도, 가려진 물체를 알 수 없다. 프레임 여러 장, 속도·IMU, RNN 같은 belief 표현을 추가해야 한다.

문제 35장 체인 예에서 γ = 0이면 VW, VC는? 들어 올리기에서 "성공 +1, 나머지 0, γ = 1"이면 무슨 문제가 생기나?

V = R = (1, 0). 충전이 미래 작업으로 이어진다는 가치가 사라진다. 두 번째는 언제 성공하든 G = 1이라 빨리 할 이유가 없다. γ < 1이면 k스텝 뒤 성공의 가치가 γk라 빨리 끝낼수록 좋다(또는 스텝당 시간 패널티).

문제 4정책이 결정적이면 Vπ(s)와 Qπ(s, π(s))의 관계는? V만 학습하면 행동을 고르는 데 무엇이 더 필요한가?

같다. V만 있으면 환경 모델 p(s'|s,a)가 필요하다(계획: 03, 10). 모델이 없으면 Q를 직접 배운다(05, 07).

문제 5복도에서 γ = 1이면 V*와 최적 정책은? Q*(s, a₁) = Q*(s, a₂)면 최적 정책은 하나뿐인가?

모든 칸에서 V* = 1. 헤매다 도착하는 정책도 최적이 되어 빨리 갈 이유가 사라진다. 두 번째: 최적 정책은 여러 개(섞는 확률적 정책도 최적)지만 V*는 유일하다(9장).

문제 6그림 10에서 V0 = 0이 정확히 4번 만에 끝나는 이유는?

전이가 결정적이고 경로 길이가 최대 4로 유한하다. k번 반복 = k스텝 앞까지의 최적값이 정확히 계산된다. 확률적 전이나 순환이 있으면 무한히 근사해 간다.

문제 7100Hz, γ = 0.98로 잘 동작하던 정책을 25Hz로 낮추려면 γ는? 질량을 모르는 들어 올리기에서 현재 관측만 보는 정책과 1초 history를 보는 정책 중 어느 쪽이 유리한가?

γ = 0.98⁴ ≈ 0.922, 시야는 둘 다 0.5초(그림 12로 확인). history 쪽: 같은 힘에 물체가 얼마나 올라오는지로 질량을 추론할 수 있다(belief 역할). meta-RL, RMA의 아이디어다.

Q1전이확률이 시간과 무관하다는 건 어제와 오늘의 전이확률이 같다는 의미야?02 · Markov chain

Q3분포의 시간 발전이라는 건 어떤 Markov chain이든 다 수렴한다는 뜻이야? 수렴 조건이 있다는 뜻이야?02 · Markov chain
  • 시간 발전은 μt+1 = μtP로 분포가 매 스텝 바뀐다는 사실일 뿐이다. 수렴은 별도 조건이 필요하다.
  • 유한 상태: irreducible + aperiodic이면 어떤 μ0에서든 유일한 μ*로 수렴한다.
  • 반례 ① 주기적 P = [[0,1],[1,0]]: 영원히 진동. ② 흡수 상태 두 개: 수렴은 하지만 시작점에 따라 도착지가 다르다. → 그림 2의 버튼들
Q4정상분포는 한 번 더 전이해도 안 변하는 분포니까, 빠져나가는 흐름과 들어오는 흐름이 같다는 거지?02 · 정상분포
  • 맞다(global balance). 모든 상태에서 들어오는 흐름 총합 = 나가는 흐름 총합. μ* = μ*P를 상태별로 풀어 쓴 것이다.
  • 쌍마다 같을 필요는 없다(detailed balance는 더 강한 조건). 1→2→3→1 순환 체인도 정상분포는 균등하다.
Q5"Markov는 상태 표현의 성질" 설명이 어렵다. 더 쉽게 설명해줘.03 · Markov 성질
  • 던진 공의 사진 한 장(위치만)으로는 올라가는지 내려가는지 모른다. 이전 사진이 도움이 된다 → Markov가 아니다.
  • (위치, 속도)로 잡으면 이전 사진이 줄 정보가 없다 → Markov다. → 그림 3
  • 같은 세상인데 상태 정의에 따라 Markov이기도, 아니기도 하다. 그래서 상태 설계가 RL 문제 설정의 일부다. 정보가 부족하면 과거 관측을 붙인다(프레임 스택, RNN).
Q6RL은 policy를 만드는 학습인데, 그 policy가 결국 Markov chain의 상태와 전이확률을 찾는 거야? 보상이 수렴한다는 건 체인 구조가 더 이상 안 변한다는 뜻이야?07 · MDP 미리보기

Q8그러면 bandit은 상태가 하나고, 확률에 따라 다시 자기 자신으로 돌아오는 구조야?04 · 에피소드
  • 상태 1개는 맞다. 다만 확률 1로 항상 자기 자신으로 돌아온다(P = [1]). 전이에는 무작위성이 없다.
  • 무작위성은 보상에만 있다. 행동은 보상만 바꾸고 다음 상태는 못 바꾼다. "한 번 당기기 = 길이 1의 에피소드"로 볼 수도 있다.
Q9한 에피소드는 태스크 한 번을 끝내고 완료(흡수) 상태로 오면 끝나는 거야? 로봇이 물체를 들어 올릴 때, 올린 높이가 안 바뀌면 흡수 상태라 끝나는 거고?04 · 에피소드
  • 큰 그림은 맞다: 리셋 → 시도 → 종료 조건 = 에피소드 1개. → 그림 4
  • 수정: "높이가 안 바뀜"은 종료가 아니다. 들고 가만히 있는 것도 여전히 움직일 수 있는 평범한 상태다. 종료는 설계자가 정한다: 성공(z ≥ 30cm), 실패(떨어뜨림, 충돌).
  • 흡수 상태는 수학적 장치(종료 후 자기 자신으로만 가고 보상 0). 시간 제한은 truncation.
  • 함정: 매 스텝 z 보상 + 성공 시 종료면, 목표 바로 아래에서 떠 있는 게 이득일 수 있다(reward hacking). → 그림 7
Q10reward shaping과 reward hacking이 뭐야?06 · 보상 설계
  • shaping: sparse 보상만으로는 학습이 안 되니 중간 보상(접근, 파지, 높이)을 더해 길을 안내하는 것. 목표와 어긋나면 최적 정책이 바뀐다. 안전한 형태는 potential-based F = γΦ(s') − Φ(s)(정책 순위 불변).
  • hacking: 에이전트는 의도가 아니라 숫자를 최대화한다. 예: 29cm에서 떠 있기, 물체 세우기, CoastRunners 보트 빙빙 돌기, 시뮬 물리 버그, RLHF 아부.
  • 대응: 보상은 단순하게, 종료 조건 명확히, 학습된 행동은 영상으로 확인.
Q11할인율은 얼마나 먼 미래(스텝)까지 고려할지 정하는 거야?05 · 할인율
  • 맞다. 다만 딱 잘리지 않고 γk로 부드럽게 줄어든다. γ = 0.9면 10스텝 뒤 0.35, 22스텝 뒤 0.1. 대략 1/(1−γ)스텝 앞까지 본다. → 그림 5
  • 반감기 = ln 0.5 / ln γ (0.9 → 6.6스텝, 0.99 → 69스텝).
Q12미래까지 얻는 보상이 지금 상태에 반영되는 거야? 정책을 바꾸는 거야? 어떤 행동을 할지 정하는 거야? 큰 예시로 설명해줘.05 · 큰 흐름
  • 셋 다 맞고 순서가 있다. ① 평가: 미래 보상을 끌어와 V(s)로(Bellman) ② 선택: 행동마다 갈 상태의 점수 비교(Q) ③ 개선: 그대로 정책 수정 → 다시 ① (GPI).
  • 복도 예: G 도착 +1, γ = 0.9, "항상 오른쪽" → V = 0.729, 0.81, 0.9, 1. 보상이 뒤로 번져 오르막 지형이 생기고, S1에서 왼쪽(0.729) vs 오른쪽(0.9) → 오른쪽. → 그림 6
  • γ = 0.5면 0.125, 0.25, 0.5, 1 → 멀리서는 목표가 거의 안 느껴진다.
  • 🤖 로봇은 "30cm 도달 +10"이라는 미래를 V(s)로 압축해 두고, 매 순간 점수가 높아지는 쪽만 고른다.
Q1330cm 도달 시 점수를 무한대로 주거나, 높이에 따라 exponential로 주면 어때?06 · 보상 설계
  • 무한대: 성공 확률이 0만 아니면 모든 정책의 V = ∞ → 비교 불가. 수치적으로 inf/NaN.
  • 아주 큰 유한값: 보상 전체를 c배 해도 최적 정책은 그대로. 중요한 건 비율. 너무 크면 shaping이 묻히고 분산이 커져 불안정 → reward scaling, clipping.
  • exp(z): 바닥 근처 신호가 약해 초반 학습이 느리고, 꼭대기 근처에서 떠 있기 hacking이 심해진다.
  • 좋은 exponential: 오차 커널 exp(−‖오차‖²/σ) ∈ (0, 1]. 보행 로봇 속도 추종 보상 등에서 표준.
  • 떠 있기 방지: 성공 시 종료 + 보너스, 스텝당 시간 패널티, potential-based shaping.
Q14PPO랑 POMDP가 뭐야? (용어만)07 · 용어
  • PPO (Proximal Policy Optimization, 2017): policy gradient 계열. advantage가 양수인 행동의 확률은 올리고 음수면 내리되, 확률비를 [1−ε, 1+ε]로 clip해서 한 번에 너무 크게 안 바뀌게 한다. 로봇 보행, RLHF의 표준(09).
  • POMDP: 진짜 상태 대신 관측 o ~ O(o|s)만 보는 MDP. 카메라 가림, 센서 노이즈, 안 보이는 질량·마찰. belief state b(s)로 바꾸면 다시 MDP. 실전은 history, RNN. → 그림 11
Q15"Q*만 알면 다 안다"고 했는데, Q와 Q*(큐프라임?)가 각각 뭘 의미해? 큰 예시로.08 · 최적성
  • 표기: Q*는 "큐 스타" = 최적. Q′(프라임)은 다음 상태의 Q나 target network를 가리키는 별개 표기.
  • Qπ(s,a): 지금 a를 하고 이후 현재 습관대로. Q*(s,a): 지금 a를 하고 이후 최선으로.
  • 출근길: 습관 π는 갈림길 B에서 늘 시내(20분). A에서 고속도로(10분) vs 국도(25분). Qπ(고속도로) = −30 < Qπ(국도) = −25로 국도가 나아 보이지만, Q*(고속도로) = −18이 정답. → 그림 9
  • Qπ는 이후 습관 때문에 첫 선택까지 오판하게 할 수 있다. Q*는 이후 최선을 전제하므로 argmax만 하면 된다.
  • B의 습관을 Qπ로 고치고(우회 −8 > 시내 −20) 재평가하면 A의 판단도 바뀐다 → Q*.
Q16그러니까 Q와 Q* 기호의 의미는 "보통의 점수" vs "최적 행동을 할 때의 점수" 차이야?08 · 최적성
  • 맞다. 셋으로 구분하면 정확하다: Qπ = 정책 π를 따를 때의 진짜 점수, Q* = 최적으로 행동할 때의 진짜 점수(= Qπ*), Q = 알고리즘의 추정치(표, 신경망).
  • 항상 Qπ ≤ Q*. 논문/코드에 위첨자 없는 Q는 대개 "지금 학습 중인 추정치"다. 01의 Q(a)도 q*(a)의 추정치였다.

✓헷갈렸던 개념

  • 시간 균질: 규칙 P가 고정. 분포 μt는 변해도 된다. Q1
  • 비정상성 = 빠진 상태 변수: 온도, 마모, 시간을 상태에 넣으면 다시 균질. Q2
  • 수렴은 조건부: irreducible + aperiodic. 주기적이면 진동, 가약이면 시작점 의존. Q3
  • 정상분포 = 흐름 균형: 들어오는 흐름 = 나가는 흐름. Q4
  • Markov는 상태 표현의 성질: 공 사진 한 장 vs (위치, 속도). Q5
  • 정책 선택 = 체인 선택: 동역학은 환경, 정책은 내가. Pπ = Σ π p. Q6
  • 에피소드와 종료: 종료는 설계자가 정의. truncation ≠ termination. 높이가 안 변한다고 종료가 아니다. Q7 · Q9
  • bandit 전이는 확률 1로 제자리: 무작위성은 보상에만. Q8
  • shaping vs hacking: 길 안내 vs 숫자의 허점 파기. potential-based면 안전. Q10
  • γ = 부드러운 시야: 가중치 γk, 시야 ≈ 1/(1−γ). Q11
  • 평가 → 선택 → 개선: 미래 보상이 V로 번지고, Q로 고르고, 정책을 바꾼다. Q12
  • 보상은 크기보다 비율과 모양: ∞ 불가, 유계 커널 exp(−오차²). Q13
  • Qπ / Q* / Q: 습관의 진짜 점수 / 최선의 진짜 점수 / 내 추정치. Q′는 별개. Q15 · Q16
