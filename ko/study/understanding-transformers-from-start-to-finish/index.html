01왜 트랜스포머가 나왔나

언어를 이해한다는 건 결국 어떤 단어가 어떤 단어와 관련 있는지 아는 것이다.

"그 동물은 길을 건너지 않았다. 왜냐하면 그것이 너무 피곤했기 때문이다."
"그것"을 이해하려면 앞의 "그 동물"과 연결해야 한다.

예전에 많이 쓰던 RNN은 문장을 한 단어씩 순서대로 읽는다. 메모장 한 장에 요약을 계속 덧쓰는 것과 비슷해서, 문장이 길어지면 앞 내용을 잊어버리고, 앞 단어가 끝나야 다음으로 갈 수 있어서 느리다.

트랜스포머(2017, Attention Is All You Need)의 아이디어는 단순하다. 모든 단어가 다른 모든 단어를 한 번에 직접 보게 하자. 어디에 얼마나 집중할지 정하는 것이 어텐션이다.

RNN트랜스포머
읽는 방식한 단어씩 순서대로전체를 한 번에
먼 단어와의 관계점점 잊음어텐션으로 바로 연결
속도병렬 처리 어려움병렬 처리 가능 (GPU에 적합)

02토큰과 임베딩

컴퓨터는 숫자만 계산할 수 있으니, 문장을 숫자로 바꾸는 단계가 필요하다.

"나는 고양이를 좋아해"
  ↓ 토큰화      ["나", "는", "고양이", "를", "좋아", "해"]
  ↓ 토큰 ID     [312, 45, 8821, 67, 1590, 23]
  ↓ 임베딩      [[0.2, -1.3, 0.8, ...], ...]   (토큰마다 768개 숫자)
  • 토큰: 모델이 다루는 글자 조각. 자주 나오는 건 크게, 드문 건 잘게 자른다(BPE 등).
  • 토큰 ID: 사물함 번호일 뿐, 숫자가 가깝다고 의미가 비슷한 게 아니다.
  • 임베딩: 토큰을 의미를 담은 벡터로 바꾼 것. 의미가 비슷하면 벡터도 가깝다. 각 숫자의 뜻은 사람이 정하지 않고 학습으로 정해진다.
  • 구현은 (토큰 수 × 768) 크기의 표 하나. ID번째 줄을 꺼내면 그 토큰의 벡터다.

03셀프 어텐션 (Q, K, V)

각 단어가 문장 속 다른 단어들을 보고 자기 벡터를 문맥에 맞게 고치는 과정이다. 도서관 검색에 비유하면 각 단어는 세 가지 역할을 동시에 한다.

역할비유의미
Query (Q)검색창에 치는 검색어나는 이런 정보가 필요해
Key (K)책 표지의 키워드나는 이런 정보를 갖고 있어
Value (V)책의 실제 내용나를 고르면 이걸 줄게

예시: "배를 타고 바다로 갔다"에서 "배"의 Q가 각 단어의 K와 비교된 결과.

Attention(Q, K, V) = softmax(QKᵀ√dk) V

"셀프"인 이유는 Q, K, V가 모두 같은 문장에서 나오기 때문이다.

직접 눌러보기: 이 단어는 어디를 볼까?

단어를 누르면 그 단어의 Query 기준으로 다른 단어에 주는 어텐션 가중치를 색 진하기와 막대로 보여준다. 이해를 돕기 위한 예시 값이고, 실제 모델의 값은 아니다.

04멀티헤드 어텐션

"철수가 어제 공원에서 산 빨간 공을 던졌다"에서 "던졌다"는 누가(철수), 무엇을(공), 언제(어제)를 동시에 알고 싶다. 어텐션 한 번으로는 이 관계들이 평균내져 흐려진다.

그래서 어텐션을 여러 개(헤드) 나란히 돌린다. 헤드마다 자기만의 W_Q, W_K, W_V를 가져서 다른 관계를 잡고, 역할 분담은 학습으로 저절로 생긴다.

입력 (768)
 ├─ 헤드 1  (64) ─┐
 ├─ 헤드 2  (64) ─┤
 ├─ ...           ├─ 이어 붙이기 (12 × 64 = 768) → W_O → 출력 (768)
 └─ 헤드 12 (64) ─┘

768을 12개가 64씩 나눠 쓰니 전체 계산량은 어텐션 한 번과 비슷하다. 입력과 출력이 모두 768이라 여러 층을 쌓을 수 있다.

05위치 인코딩

어텐션은 모든 단어를 한 번에 보기 때문에 순서를 모른다. "Dog bites man"과 "Man bites dog"이 같은 단어 주머니로 보인다. 그래서 순서 정보를 따로 넣어준다.

최종 입력 = 토큰 임베딩 + 위치 인코딩 (둘 다 768 크기라 그대로 더할 수 있다)

1, 2, 3을 그대로 넣으면 값이 커져서 단어 의미를 덮어버린다. 원 논문은 빠르기가 다른 sin/cos 파동을 쓴다. 시계의 초침·분침·시침처럼, 여러 파동 값을 같이 보면 위치가 하나로 정해진다. 값은 항상 -1~1 사이다.

방식설명쓰는 모델
sin/cos (고정)공식으로 계산, 학습 안 함원 논문
학습형 위치 임베딩위치별 벡터를 표로 만들어 학습BERT, GPT-2
RoPE더하는 대신 Q, K를 위치만큼 회전LLaMA 등 요즘 LLM

지금까지의 부품을 하나로 조립한 것이 트랜스포머 블록이고, 이것을 N개 쌓은 것이 Q4의 "N번 반복"이다.

잔차 연결원래 입력 x를 결과에 더한다. 층은 "변화량"만 학습. 깊어져도 정보와 학습 신호가 잘 전달된다원본에 수정 메모 붙이기

07인코더 · 디코더 · 마스킹

원 논문은 번역기였다. 원문을 읽고 이해하는 인코더와 번역문을 한 단어씩 쓰는 디코더로 이루어져 있다.

마스크: 미래 훔쳐보기 금지

학습할 때는 정답 문장이 통째로 들어간다. 뒤를 볼 수 있으면 정답을 그냥 베낀다. 그래서 각 단어는 자기와 앞 단어만 보게 한다. 어텐션 점수의 미래 자리를 −∞로 바꾸면 softmax 후 0이 된다.

종류잘하는 일대표 모델
인코더만이해 · 분류BERT
디코더만생성GPT, LLaMA, Claude 등 대부분의 LLM
인코더 + 디코더변환 (번역, 요약)T5, BART

08학습과 생성

벡터를 다음 토큰으로

마지막 위치의 벡터(768) → 출력 행렬(768 → 사전 크기) → 토큰별 점수(logit) → softmax → 확률 → 하나 고르기. 임베딩의 반대 방향이다.

고르는 방법과 temperature

greedy는 항상 1등을 고르고, sampling은 확률대로 뽑는다. temperature는 확률 분포를 조절하는 손잡이다.

생성: 한 토큰씩 뽑아서 다시 넣기

"반복"어디서내용
층 N개 (Q4)모델 안블록 1 → 블록 2 → … (예측 한 번마다)
생성 루프모델 밖토큰 뽑고 → 붙이고 → 다시 실행
학습 스텝 (Q5)학습할 때예측 → 오차 → 가중치 수정

학습: 다음 토큰 맞히기 (Q2, Q5)

  1. 모든 가중치(임베딩, 모든 층의 W_Q·W_K·W_V·W_O, FFN, 출력 행렬)가 랜덤으로 시작한다.
  2. 사람이 쓴 대량의 텍스트가 문제이자 정답이다. 따로 정답을 달 필요가 없다.
  3. 마스크 덕분에 문장 하나로 모든 위치를 동시에 예측한다.
  4. 정답 토큰에 준 확률이 낮을수록 오차가 크다(크로스 엔트로피).
  5. 역전파로 오차를 출력층 → 블록 N → … → 임베딩까지 거꾸로 보내고 모든 가중치를 동시에 조금씩 고친다.
  6. 수십만~수백만 번 반복하면 임베딩 의미, 어텐션 관계, 헤드 역할, 층별 역할이 저절로 생긴다.
  7. 이후 파인튜닝(SFT), RLHF 등으로 대화형 비서로 다듬는다. 구조는 그대로이고 가중치만 바뀐다.

09전체 흐름 한 장 정리

Q&A질문 & 답변

공부하면서 직접 했던 질문들. 답을 먼저 떠올려 본 뒤 펼쳐보자.

Q1임베딩 차원 768은 특별한 이유가 있나?2단계 · 토큰과 임베딩
  • 수학적으로 특별한 의미는 없다. 사람이 정하는 하이퍼파라미터(d_model)다.
  • BERT-base, GPT-2 small이 써서 유명해졌다.
  • 크면 표현력이 좋아지지만 계산량과 메모리가 늘어나는 트레이드오프가 있다.
  • 실용적인 이유: 헤드 수로 나누어 떨어져야 한다(12헤드 × 64 = 768). 64·128의 배수가 GPU 연산에 효율적이다.
  • 다른 모델: BERT-large 1024, LLaMA-7B 4096, GPT-3 12288.
Q2W_Q, W_K, W_V 같은 행렬은 미리 큰 모델이 학습해둔 건가? 사람이 만든 텍스트로?3단계 · 셀프 어텐션
  • 다른 모델이 만들어 주는 게 아니다. 이 행렬들은 트랜스포머 자기 자신의 파라미터다.
  • 처음엔 랜덤이다. 사람이 쓴 대량의 텍스트로 "다음 토큰 맞히기"를 반복하며 역전파로 고쳐진다 → 사전학습.
  • 임베딩 표, W_Q/W_K/W_V, 이후 층들까지 모두 함께 학습된다(end-to-end).
  • 학습이 끝나면 값이 고정되고, 모델을 쓸 때(추론)는 계산만 한다. → 그림 13
Q3Q·K 값을 어텐션이라고 부르나?3단계 · 셀프 어텐션

일부만 맞다. 단계마다 이름이 다르다.

단계이름의미
Q·Kᵀ / √d_k어텐션 점수관련도 원점수
softmax 후어텐션 가중치합이 1인 비율. "어텐션 맵"은 보통 이것
가중치 × V까지어텐션 (연산 전체)결과: 문맥이 반영된 벡터
Q4"어텐션을 N번 반복한다(for문)"는 게 헤드가 병렬로 처리하는 것, 즉 같은 어텐션이 반복하며 자리를 찾아가는 것인가?4단계 · 멀티헤드 어텐션
  • 아니다. 두 개념이 섞였다. → 그림 6
  • 헤드: 같은 층 안에서 옆으로 나란히(병렬) 돈다. 서로 독립적이다.
  • N번 반복: 층(블록)을 위로 N개 쌓은 것이다. 1층 출력이 2층 입력이 되는 순차 구조라 for문으로 쓴다.
  • 층마다 서로 다른 가중치를 가진다. 수렴할 때까지 도는 게 아니라 정해진 수만큼 통과한다.
  • "점점 자리를 찾아간다"는 감각은 층에 대해서는 맞다. 아래층은 문법·인접 관계, 위층은 의미·지시 관계를 잡는 경향이 있다.
x = embed(tokens)
for layer in layers:   # ← "N번 반복" (층)
    x = layer(x)       #   안에서 헤드들은 동시에 계산
Q5층마다 각자 W_Q 등을 가진다면, 그 값들은 어디서 학습된 건가?5단계 이후 · Q2 재질문
  • 사전학습 한 번에 모든 층이 동시에 학습된다. 층별로 따로 학습하지 않는다.
  • 학습 1스텝: 순전파(1층 → … → N층 → 예측) → 오차 계산 → 역전파(N층 → … → 1층) → 모든 층의 가중치를 동시에 수정. → 그림 13
  • 층마다 값이 다른 이유: 처음 랜덤 값이 다르고, 받는 입력과 위치가 달라 맡는 일이 달라진다.
  • 누가: 모델을 만드는 회사·연구팀이 GPU 수천 장으로 몇 주~몇 달 학습한다. 결과물은 가중치 파일이다.
Q6잔차 연결은 residual을 더하는, 즉 원본 어텐션을 더해주는 부분인가?6단계 · 트랜스포머 블록
  • 큰 그림은 맞지만 원본과 residual이 반대다. → 그림 8
  • 출력 = x + 어텐션(x)
  • x = 블록에 들어온 원래 입력. 우회로로 와서 더해지는 원본이다.
  • 어텐션(x) = 층이 계산한 변화량 = residual(잔차).
  • 잔차 = "출력 − 입력"의 차이. 층은 결과 전체가 아니라 얼마나 바꿀지만 학습한다.
  • FFN 뒤도 x + FFN(x)로 똑같다. skip connection, shortcut이라고도 하고 ResNet(2015)에서 유명해졌다.

✓헷갈렸던 개념

  • 임베딩 차원(d_model): 하이퍼파라미터이고, 헤드 수로 나누어 떨어지는 GPU 친화적 크기다. Q1
  • 가중치의 출처: 별도 모델이 아니라 모델 자신이 사전학습으로 한꺼번에 학습한다. Q2 · Q5
  • 어텐션 용어: 점수 / 가중치 / 어텐션 출력으로 구분한다. Q3
  • 헤드 vs 층: 헤드는 병렬·독립이고, "N번 반복"은 서로 다른 가중치를 가진 층을 순차로 쌓은 것이다. Q4
  • 잔차 연결: 원본 = 입력 x, residual = 층이 만든 변화량이다. Q6
